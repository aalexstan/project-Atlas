# Project Atlas

[English version](README.md)

[![Validate Atlas](https://github.com/aalexstan/project-Atlas/actions/workflows/validate-atlas.yml/badge.svg)](https://github.com/aalexstan/project-Atlas/actions/workflows/validate-atlas.yml)

> **Независимая аналитика API для обоснованных технических и бизнес-решений.**

Project Atlas — независимая база знаний, которая помогает находить, проверять, сравнивать и выбирать API на основе подтверждаемых фактов.

Atlas — не очередной каталог с названиями и ссылками. Он помогает разработчикам, архитекторам, продуктовым командам и компаниям отвечать на более важный вопрос:

> **Какой API выбрать для нашей задачи и почему?**

## Что делает Atlas

Atlas превращает разрозненную документацию поставщиков в исследование, пригодное для принятия решений:

- проверяет, существует ли API и поддерживается ли его документация;
- объясняет авторизацию, тарифы, лимиты, покрытие и коммерческие ограничения;
- выявляет преимущества, недостатки, риски и подходящие сценарии;
- сравнивает конкурирующие API для конкретной задачи;
- сохраняет источники и даты проверки;
- отслеживает важные изменения.

## Чем Atlas отличается

Обычный каталог помогает **найти** API.

Atlas помогает:

1. понять, подходит ли API под задачу;
2. сравнить его с реальными альтернативами;
3. оценить ограничения интеграции и эксплуатации;
4. принять обоснованное техническое или коммерческое решение.

Каталоги, включая API Portal, могут использоваться как источники обнаружения. Они не считаются окончательным источником истины. Существенные утверждения следует проверять по официальной документации, тарифам, спецификациям, объявлениям поставщика и другим первичным источникам.

## Основная модель продукта

Главная публичная сущность Atlas — **карточка API**.

Вспомогательные сущности:

- поставщики;
- задачи и потребности пользователей;
- сравнения;
- наборы данных, доступные через API;
- доказательства и записи о проверке;
- история изменений.

Наборы данных остаются важными, но помогают оценивать API, а не заменяют его как центральную сущность проекта.

## Для кого Atlas

- Разработчики, выбирающие внешний сервис.
- Архитекторы, оценивающие зависимости и риски поставщика.
- Продуктовые команды, рассчитывающие реализуемость и стоимость.
- Компании, сравнивающие поставщиков перед закупкой.
- Исследователи рынков API и цифровой инфраструктуры.

## Типы материалов

### Карточки API

Структурированные независимые профили: назначение, лучшие сценарии, авторизация, тарифы, лимиты, SDK, юридические ограничения, преимущества, недостатки, альтернативы, доказательства и дата проверки.

### Сравнения

Сравнения вокруг конкретной задачи: API проверки компаний, геокодирования, платежей, сообщений и доставки. Сравнение должно завершаться рекомендациями по сценариям, а не объявлением одного универсального победителя.

### Исследования и история изменений

Исследовательские журналы сохраняют путь к выводам. История изменений фиксирует существенные изменения тарифов, документации, версий, лимитов и доступности продуктов.

## Уровни готовности

1. **Discovered / Обнаружено** — найден официальный поставщик или страница продукта.
2. **Verified / Проверено** — основные факты проверены по первичным источникам.
3. **Reviewed / Проанализировано** — добавлены независимый анализ, преимущества, недостатки и риски.
4. **Compared / Сравнено** — API включено хотя бы в одно содержательное сравнение.
5. **Gold / Эталон** — карточка с высокой уверенностью, которая регулярно поддерживается.

Уровень зрелости не является оценкой качества самого API. Он отражает полноту исследования Atlas.

## Принципы исследования

- Сначала официальные источники.
- Факты важнее мнений.
- Каждое существенное утверждение должно быть проверяемым.
- Неизвестное должно оставаться неизвестным.
- Сравнение ценнее простого описания.
- Качество важнее размера каталога.
- Коммерческие отношения не могут покупать рейтинги и редакционные выводы.
- Даты имеют значение: тарифы, лимиты и документация меняются.

## Направление структуры репозитория

```text
apis/            Независимые карточки API
comparisons/     Сравнения вокруг пользовательских задач
providers/       Контекст о поставщиках
needs/           Задачи пользователей и карты решений
research/        Журналы исследований и рабочие доказательства
changes/         Существенные изменения API
templates/       Шаблоны карточек и сравнений
docs/            Правила, методология и стратегия проекта
legacy/          Исторические материалы после завершения миграции
```

Существующие папки не требуется удалять сразу. Миграция должна быть постепенной и сохранять полезное происхождение исследований.

## Начальный охват

Atlas начинает с небольшого числа ценных категорий:

- данные о компаниях и контрагентах;
- адреса и геокодирование;
- закупки;
- платежи и финансы;
- сообщения и уведомления.

Первая эталонная карточка, **DaData**, уже опубликована. Первое сравнение API для получения информации о компаниях и контрагентах также опубликовано.

## Направления монетизации

Деньги должны появляться как следствие доверия:

- платные исследования по подбору API;
- Atlas Pro: расширенные сравнения, экспорт, уведомления и история изменений;
- мониторинг API для компаний;
- приватные каталоги внутренних API;
- прозрачно обозначенные партнёрские программы.

Atlas не продаёт хорошие места в рейтингах.

## Текущий статус

Atlas находится на этапе создания фундамента. Текущая цель — поддерживать повторяемый стандарт исследования, улучшать первую эталонную карточку и сравнение, а также расширять покрытие без потери качества доказательств.
