# Provider: Seldon

Дата исследования: 2026-06-23
Статус: мигрировано из Pass #1; документация требует проверки

## Общая информация

- Provider: Seldon.
- Официальный сайт: не подтвержден в Pass #1.
- Сайт, указанный API Portal: http://www.api-seldon.ru/
- Тип: поставщик данных для проверки контрагентов и закупочной аналитики, по карточкам API Portal.

## Какими именно данными владеет

Неизвестно. Seldon распространяет агрегированные данные, но права на первичные источники не установлены.

## Какие данные агрегирует

Подтверждено по API Portal:

- Данные о контрагентах.
- Данные о взаимодействующих с контрагентами компаниях.
- Данные о финансовой состоятельности.
- Данные об аффилированности.
- Данные о соответствии правовым нормам.
- Извещения о торгах.
- Протоколы торгов.
- Контракты.
- Участники торгов.
- Ценовые предложения.
- Документы торгов.
- Данные из более чем 7000 официальных источников для Seldon.Tenders.

## Какие данные продает

Подтверждено:

- Доступ к данным Seldon.Basis через API.
- Доступ к данным Seldon.Tenders через API.
- Стоимость в API Portal указана `от 1 000 руб.` для Seldon.Basis и Seldon.Tenders; детали не проверены.
