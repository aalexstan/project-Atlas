# Provider: Credinform

Дата исследования: 2026-06-23
Статус: мигрировано из Pass #1

## Общая информация

- Provider: Credinform.
- Официальный сайт: https://credinform.ru/ и https://globas.credinform.ru/
- Тип: поставщик бизнес-информации и системы Глобас.

## Какими именно данными владеет

Неизвестно. Credinform распространяет агрегированный слой через систему Глобас, но точные права на первичные данные не установлены.

## Какие данные агрегирует

Подтверждено:

- Контрагентские данные.
- Данные о российских организациях и ИП.
- Данные о зарубежных компаниях, по описанию API Portal.
- Данные для мониторинга изменений портфеля контрагентов.
- Данные для массовой проверки контрагентов.
- Данные для обогащения и верификации клиентских баз.

Не подтверждено:

- Полный список первичных источников.
- Наличие судебных, санкционных, финансовых и бенефициарных данных.

## Какие данные продает

Подтверждено:

- Доступ к данным Глобас через ГЛОБАС.API на условиях `по запросу`.

Неизвестно:

- Тарифы.
- Условия хранения.
- Условия перепродажи.
- Условия использования в SaaS.
- Условия использования для обучения ИИ.

## Какие данные получает от партнеров

Неизвестно.

## Известные способы распространения

- ГЛОБАС.API.

## Коммерческие и лицензионные ограничения

- Коммерческое использование: неизвестно.
- Хранение: неизвестно.
- Перепродажа: неизвестно.
- SaaS: неизвестно.
- Обучение ИИ: неизвестно.

## Риски

- Не найдена полная схема данных.
- Неизвестны первичные источники.
