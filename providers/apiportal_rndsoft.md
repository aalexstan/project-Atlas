## Какими именно данными владеет

Подтверждено:

- Метаданные карточек API в каталоге API Portal.
- Категории, отрасли, поставщики, типы тарификации и ссылки на документацию, опубликованные в каталоге.

Неизвестно:

- Юридические права на метаданные каталога.
- Права на описания API, если они предоставлены поставщиками.

## Какие данные агрегирует

- Сведения о сторонних API.
- Сведения о поставщиках API.
- Категории и отрасли сторонних API.
- Стоимость или тип тарификации сторонних API.
