# Procurement and Tender Data

[Русская версия](README.ru.md)

## The user question

Should we build on official EIS procurement data or use a commercial aggregated API for tender workflows?

## Quick paths

| Scenario | Initial route | Main caveat |
|---|---|---|
| Own primary data platform | EIS integration | Machine interface and rights need confirmation |
| Filtered CRM workflow | Seldon.Tenders API | Endpoint, schema, limits and price unknown |
| Commercial selection | Compare both through RFP | No common benchmark or quote yet |

Start with the [comparison](../../comparisons/procurement-tender-data/README.md), then use the [procurement kit](../../procurement/procurement-api-selection/README.md).

Legacy research remains at [procurement tender contracts](../../datasets/procurement_tender_contracts.md).
