# Данные о закупках и тендерах

[English version](README.md)

## Вопрос пользователя

Строить собственную базу на официальных данных ЕИС или использовать коммерческий агрегированный API для тендерного процесса?

## Быстрые пути

| Сценарий | Первичный маршрут | Главная оговорка |
|---|---|---|
| Собственная первичная база | Интеграция ЕИС | Machine interface и права нужно подтвердить |
| Фильтрованный процесс в CRM | Seldon.Tenders API | Endpoint, schema, limits и цена неизвестны |
| Коммерческий выбор | Сравнить оба через RFP | Общего benchmark и quote пока нет |

Начните с [comparison](../../comparisons/procurement-tender-data/README.ru.md), затем используйте [procurement kit](../../procurement/procurement-api-selection/README.ru.md).

Legacy-исследование сохранено в [карточке закупок и тендеров](../../datasets/procurement_tender_contracts.md).
