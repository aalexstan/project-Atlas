# Выбор источника данных о недвижимости или кадастре

[English version](README.md)

## Начните с требуемого результата

| Задача | С чего начать | С чем не путать |
|---|---|---|
| Подтвердить официальные реестровые факты | Выписка ЕГРН | Кадастровая карта или enrichment response |
| Запрашивать много официальных выписок | Пакетный доступ к ФГИС ЕГРН | Undocumented scraping |
| Изучать границы и контекст территории | НСПД | Юридически значимая выписка |
| Нормализовать адрес и получить кадастровое enrichment | DaData Address API | Проверка прав на объект |
| Построить свою адресную базу РФ | ФИАС/ГАР | Данные ЕГРН о правах и обременениях |

## Вопросы до внедрения

1. Должен ли результат быть юридически значимым?
2. Нужны адрес, кадастровый номер, геометрия, характеристики, права или обременения?
3. Это один объект, регулярный портфель или bulk dataset?
4. Можно ли хранить и показывать результат клиентам?
5. Есть ли automated decision-making?
6. Что делать при задержке или недоступности official source?

## Текущие ограничения

Atlas не подтвердил public unattended REST API Росреестра, current package pricing, quotas, SLA и commercial reuse rights. Live request и платная выписка не выполнялись.
