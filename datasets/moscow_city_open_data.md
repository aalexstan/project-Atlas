# Dataset: Открытые городские данные Москвы

Дата исследования: 2026-06-23
Статус: мигрировано из Pass #1; требует декомпозиции на отдельные наборы

## Название

Открытые городские данные Москвы.

## Описание

Коллекция открытых наборов данных и справочников, опубликованных на Портале открытых данных города Москвы. В текущей базе этот Dataset пока описан как крупная коллекция, потому что полный список отдельных наборов не был исследован.

## Какие именно данные входят

Подтвержденные данные:

- Более 1000 наборов данных и справочников.
- Сведения от объектов городской инфраструктуры до расписаний ближайших мероприятий в Москве.
- Сведения с Портала открытых данных Правительства Москвы.

Не найдено:

- Полный список наборов данных.
- Поля каждого набора.
- Владельцы каждого набора.
- Частота обновления каждого набора.
- Форматы выгрузки каждого набора.

## Кто является владельцем данных

Правительство Москвы / городские органы и подведомственные системы. Точное распределение владельцев по наборам не исследовано.

## Кто собирает данные

Правительство Москвы и городские информационные системы. Конкретные владельцы и сборщики по каждому набору не исследованы.

## Кто распространяет

Портал открытых данных города Москвы: https://data.mos.ru/.

## Частота обновления

Зависит от набора. Не исследовано.

## Коммерческие ограничения

- Коммерческое использование: неизвестно; требуется проверка условий открытых данных Москвы.
- Хранение данных: неизвестно.
- Перепродажа: неизвестно.
- Использование в SaaS: неизвестно.
- Использование для обучения ИИ: неизвестно.

## Открытость

Открытые данные, по названию и описанию источника. Конкретная лицензия и условия повторного использования не найдены.

## Качество

- Потенциально высокое доверие как к государственному городскому источнику.
- Полнота и актуальность зависят от конкретного набора.
- Текущая карточка слишком крупная и должна быть декомпозирована на отдельные Dataset.

## Надежность

Выше средней как у официального домена `data.mos.ru`, но документация в первом проходе не была проверена из-за таймаута.

## Известные поставщики

- Правительство Москвы.

## Известные API

- API Портала открытых данных города Москвы.

## Альтернативные способы получения

- Open Data: подтверждено.
- REST API: подтверждено по API Portal.
- Веб-портал: подтверждено.
- CSV, JSON, XML: не подтверждено в текущей базе.
- FTP, Webhook, GraphQL: не найдено.

## Неизвестные места

- Условия API-ключей.
- Лимиты запросов.
- Форматы ответа.
- Полная лицензия.
- Полный каталог наборов.
- Частота обновления по наборам.

## Риски

- Риск слишком широкой карточки: `городские открытые данные` должны быть разбиты на отдельные Dataset.
- Риск непроверенной лицензии.
- Риск временной недоступности документации.
