# Dataset: Реестр компаний и контрагентов

Дата исследования: 2026-06-23
Статус: мигрировано из Pass #1

## Название

Реестр компаний и контрагентов.

## Описание

Набор данных о компаниях, ИП, контрагентах, связанных организациях и изменениях в контрагентских портфелях. В первом проходе этот Dataset был обнаружен через ГЛОБАС.API и API Seldon.Basis.

## Какие именно данные входят

Подтвержденные данные:

- Актуальная информация по контрагентам в базе пользователя.
- Сведения о российских организациях и ИП.
- Сведения о зарубежных компаниях, по описанию API Portal для ГЛОБАС.API.
- Информация о контрагентах и взаимодействующих с ними компаниях.
- Изменения портфеля контрагентов.
- Данные для массовой проверки контрагентов.
- Данные для автоматического заполнения реквизитов.
- Данные для обогащения собственной клиентской базы.
- Данные для верификации.
- Данные для проверки партнеров и конкурентов на финансовую состоятельность.
- Данные для проверки аффилированности.
- Данные для проверки соответствия правовым нормам.
- Доступ к официальным источникам через единый интерфейс, по описанию Seldon.Basis.
- По строке API Portal для ГЛОБАС.API: сведения о 28 млн организаций и ИП России и 400 млн компаний по всему миру.

Не подтверждено в текущей базе:

- Полный перечень полей.
- Историческая глубина.
- Наличие судебных данных.
- Наличие санкционных списков.
- Наличие лицензий.
- Наличие исполнительных производств.
- Наличие бенефициаров.
- Наличие финансовой отчетности.
- Полный список первичных источников.

## Кто является владельцем данных

- Credinform / система Глобас владеет или распространяет агрегированный слой данных; точные права на первичные данные неизвестны.
- Seldon владеет или распространяет агрегированный слой данных; права на первичные источники неизвестны.
- Первичные владельцы отдельных государственных и официальных данных не установлены.

## Кто собирает данные

- Credinform / Глобас собирает данные из множества источников.
- Seldon агрегирует официальные источники.
- Конкретные первичные источники и способы сбора не найдены.

## Кто распространяет

- Credinform через ГЛОБАС.API и систему Глобас.
- Seldon через API Seldon.Basis.

## Частота обновления

- ГЛОБАС.API: указано автоматическое обновление, точная частота не найдена.
- Seldon.Basis: данные обновляются после отражения изменений в государственных базах, точная частота неизвестна.

## Коммерческие ограничения

- Коммерческое использование: неизвестно.
- Хранение данных: неизвестно.
- Перепродажа: неизвестно.
- Использование в SaaS: неизвестно.
- Использование для обучения ИИ: неизвестно.

## Открытость

Коммерческий агрегированный Dataset. Открытый доступ к полному набору не найден.

## Качество

- Потенциально высокая полнота из-за агрегирования множества источников.
- Качество невозможно подтвердить без схемы полей, списка первичных источников и SLA.
- Сведения о 28 млн организаций и ИП России и 400 млн компаний по всему миру подтверждены только как строка API Portal, не как независимая официальная спецификация.

## Надежность

Средняя. Dataset ценен, но документация, лицензии и первичные источники пока недостаточно подтверждены.

## Известные поставщики

- Credinform.
- Seldon.

## Известные API

- ГЛОБАС.API.
- API Seldon.Basis.

## Альтернативные способы получения

- REST API: подтверждено по API Portal для обоих поставщиков.
- Партнерство / заявка / тестовый доступ: найдено для Глобас, применимость именно к API требует проверки.
- Прямой сбор из первичных официальных источников: требует исследования; список источников в текущей базе не найден.
- CSV, XML, FTP, Webhook, GraphQL: не найдено.

## Неизвестные места

- Полная схема данных.
- Документация Seldon вне сомнительного домена `api-seldon.ru`.
- Условия хранения и повторного использования.
- Возможность использовать данные в SaaS.
- Возможность использовать данные для обучения ИИ.
- Стоимость масштабирования.

## Риски

- Высокий лицензионный риск из-за неизвестных условий повторного использования.
- Риск устаревшей документации Seldon.
- Риск смешения собственных, государственных, партнерских и агрегированных данных без понятной правовой модели.
