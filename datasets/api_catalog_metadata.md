# Dataset: Метаданные каталога API

Дата исследования: 2026-06-23
Статус: мигрировано из Pass #1

## Название

Метаданные каталога API.

## Описание

Набор данных о сторонних API, поставщиках, категориях, отраслях, документации и стоимости, опубликованный в веб-каталоге API Portal.

## Какие именно данные входят

Подтвержденные данные:

- Карточки API.
- Название API.
- Краткое описание API.
- Поставщик.
- Тип API.
- Тип доступа.
- Категория.
- Отрасль.
- Дата обновления карточки.
- Ссылка на документацию.
- Стоимость или тип тарификации.
- Фильтры по поставщикам.
- Фильтры по категориям.
- Фильтры по отраслям.
- Фильтры по типу тарификации.
- Фильтры по интегратору.
- Пагинация каталога; в первом проходе видна пагинация до страницы 81.

Не найдено:

- Полный машиночитаемый экспорт каталога.
- API самого каталога.
- Методология модерации карточек.

## Кто является владельцем данных

Неизвестно. В футере API Portal указано `Разработано © RNDSOFT`, но юридический владелец каталога не найден.

## Кто собирает данные

Неизвестно. Возможны оператор каталога и/или поставщики API, но это предположение не подтверждено.

## Кто распространяет

API Portal через веб-каталог https://apiportal.ru/catalog/.

## Частота обновления

Неизвестно. В карточках есть даты обновления, но общая частота обновления каталога не найдена.

## Коммерческие ограничения

- Коммерческое использование: неизвестно.
- Хранение данных: неизвестно.
- Перепродажа: неизвестно.
- Использование в SaaS: неизвестно.
- Использование для обучения ИИ: неизвестно.

## Открытость

- Просмотр каталога: общедоступен через HTML.
- Официальный экспорт: не найден.
- API каталога: не найден.

## Качество

- Полезность высокая: каталог обнаруживает поставщиков и рынки данных.
- Полнота неизвестна: каталог не является исчерпывающим рынком данных.
- Часть внешних ссылок требует повторной проверки.

## Надежность

Средняя. Каталог полезен как слой обнаружения, но не должен считаться финальным источником лицензий, документации и актуальности.

## Известные поставщики

- API Portal / RNDSOFT.

## Известные API

- API самого каталога: не найден.

## Альтернативные способы получения

- Веб-каталог: подтверждено.
- Парсинг HTML: технически возможен, но не подтвержден как официальный способ.
- Партнерство или контакт с оператором: возможность не подтверждена.

## Неизвестные места

- Юридический владелец.
- Условия использования данных каталога.
- Процесс попадания API в каталог.
- Проверка карточек перед публикацией.
- Возможность полного экспорта.

## Риски

- Карточки могут быть устаревшими.
- Внешние ссылки могут вести на нерелевантные или недействующие домены.
- Лицензионные условия по самим данным API в карточках обычно не раскрыты.
