# Dataset: Адресный реестр России

Дата исследования: 2026-06-23
Статус: мигрировано из Pass #1; требует повторной валидации

## Название

Адресный реестр России.

## Описание

Набор адресных данных России, найденный через карточку API ФИАС в API Portal. В текущей базе подтверждено описание облачного API к ФИАС, но официальный статус указанной документации не подтвержден.

## Какие именно данные входят

Подтвержденные данные по API Portal:

- Актуальная база всех почтовых адресов России.
- Адресные объекты.
- Связи между родительскими и дочерними адресными элементами.
- Названия объектов.
- Коды связанных родительских или дочерних элементов.
- Населенные пункты как родительский контекст для поиска улиц.
- Улицы как родительский контекст для поиска строений.
- Данные для интеграции с сайтом и устранения ошибок при написании адресов.

Не найдено:

- Полный перечень объектов и полей.
- Идентификаторы и классификаторы.
- Источник обновлений.
- Форматы ответа.
- Официальный оператор конкретного API.

## Кто является владельцем данных

Неизвестно для конкретного API. Источник заявляет ФИАС как базу адресов. Связь `kladr-api.ru` с официальным государственным ФИАС не подтверждена.

## Кто собирает данные

Неизвестно для конкретного API.
