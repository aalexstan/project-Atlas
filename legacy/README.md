# Legacy Materials

[Русская версия](README.ru.md)

Legacy means preserved provenance, not discarded work.

These materials may contain useful facts, source notes, risks, and historical context. They are not the active Atlas methodology or current public structure. Old numerical ratings are not Atlas Score.

## How To Use Legacy Content

- Preserve source notes and verification history.
- Reuse useful facts only after checking their current evidence status.
- Mark stale or uncertain claims explicitly.
- Do not treat old ratings as current recommendations.
- Migrate facts into active API profiles or comparisons when they are rechecked.
