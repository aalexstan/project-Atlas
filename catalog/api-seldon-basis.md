# API Seldon.Basis

Статус: **Legacy / source-risk history**

Эта карточка сохранена как исторический материал Pass #1 и фиксирует риск ссылки `api-seldon.ru`, найденной через API Portal. Активная API-first карточка Seldon.Basis находится в `../apis/seldon-basis/README.ru.md` и использует официальные источники `seldongroup.ru`.

Дата исследования: 2026-06-23
Статус: первичная карточка

## Общая информация

- Название: API Seldon.Basis
- Компания: Seldon
- Сайт: http://www.api-seldon.ru/ указан в API Portal, но требует проверки
- Документация: API Portal указывает `http://www.api-seldon.ru/` и файл руководства `.docx`; официальный статус ссылки не подтвержден
- Категория: ВЫПИСКИ
- Отрасли: ПРОВЕРКА КОНТРАГЕНТОВ, КОМПЛАЕНС

## Что содержит источник

Подтвержденные данные:

- Запрос сведений в Seldon из клиентской системы.
- Актуальная и полная информация о контрагентах и взаимодействующих с ними компаниях.
- Проверка партнеров и конкурентов на финансовую состоятельность.
- Проверка аффилированности.
- Проверка соответствия правовым нормам.
- Автоматическое заполнение реквизитов.
- Массовая проверка контрагентов.
- Доступ к официальным источникам информации через единый интерфейс.
- Обновление данных после отражения изменений в государственных базах.

Неизвестно:

- Полный перечень эндпоинтов и полей.
- Историческая глубина.
- Наличие сведений о судебных делах, санкциях, лицензиях, исполнительных производствах, бенефициарах и финансовой отчетности не подтверждено в этом запуске.
- Доступность официальной документации вне API Portal не подтверждена.

## Вывод

Стоит ли включать в долгосрочную базу знаний: Да, с пометкой о проверке документации.

Причина: источник относится к высокоценному сегменту проверки контрагентов и комплаенса. Но официальный канал документации требует повторной валидации: домен `api-seldon.ru`, указанный API Portal, при проверке открыл нерелевантный контент.
