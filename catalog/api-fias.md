# API ФИАС

Дата исследования: 2026-06-23
Статус: первичная карточка

## Общая информация

- Название: API ФИАС
- Компания: ФИАС указан как поставщик в API Portal
- Сайт: https://kladr-api.ru/docs указан как документация в API Portal, но требует проверки
- Документация: https://kladr-api.ru/docs, официальный статус не подтвержден
- Категория: КАРТЫ, МАРШРУТЫ, НАВИГАЦИЯ
- Отрасль: ГЕОДАННЫЕ

## Что содержит источник

Подтвержденные данные:

- Доступ к ФИАС в облаке.
- Актуальная база всех почтовых адресов России, по описанию API Portal.
- Интеграция с сайтом для устранения ошибок при написании адресов.
- Поиск объектов по названию.
- Поиск объектов по коду связанного родительского или дочернего элемента.
- Поиск по названию осуществляется по шаблону начала строки.
- Для поиска улицы по названию нужно указать код населенного пункта.
- Для поиска строения по названию нужно указать код улицы.

Неизвестно:

- Кто фактически оператор конкретного API, указанного в API Portal.
- Связь между `kladr-api.ru` и официальным государственным ФИАС не подтверждена.
- Полный перечень объектов и полей.
- Форматы ответа.
- Ограничения и SLA.
- Условия лицензии.

## Вывод

Стоит ли включать в долгосрочную базу знаний: Да, но только как источник, требующий повторной валидации.

Причина: адресные данные России важны для почти любых сервисов с доставкой, CRM, геокодированием и проверкой адресов. Но текущая карточка не подтверждает официальный статус API и документации, поэтому нельзя полагаться на него без отдельной проверки владельца и лицензии.
