## Что содержит источник

Подтвержденные данные:

- Актуальная информация по контрагентам в базе пользователя.
- Мониторинг изменений портфеля контрагентов.
- Массовая проверка контрагентов.
- Создание собственной автоматически обновляемой клиентской базы.
- Дополнение собственной базы сведениями по компаниям из Глобас.
- Обновление по заданным полям.
- Верификация данных.
- Сохранение архивов.
- Автоматическое обновление больших баз данных по контрагентам.
- Сбор данных из множества источников.
- По строке каталога API Portal: сведения о 28 млн организаций и ИП России и 400 млн компаний по всему миру.

Неизвестно:

- Полный перечень полей API.
- Поддерживаемые страны и глубина международного покрытия.
- Наличие финансовой отчетности, санкционных списков, судебных данных, связей, бенефициаров и исторических срезов не подтверждено в этом запуске.
- Список первичных источников данных не найден в проверенной части страницы.
