# API Seldon.Tenders

Статус: **Legacy / source-risk history**

Эта карточка сохранена как исторический материал Pass #1 и фиксирует риск ссылки `api-seldon.ru`, найденной через API Portal. Отдельная активная API-first карточка Seldon.Tenders пока не создана; связанные факты могут быть использованы как supporting research после проверки официальных источников.

Дата исследования: 2026-06-23
Статус: первичная карточка

- Документация: API Portal указывает `http://www.api-seldon.ru/` и файл руководства `.docx`; официальный статус ссылки не подтвержден
- Категория: ВЫПИСКИ

## Что содержит источник

Подтвержденные данные:

- Данные о государственных и коммерческих торгах.
- Извещения: основные сведения о процедуре и условиях проведения.
- Протоколы: итоги процедур, участники и ценовые предложения.
- Контракты: информация о заключенных контрактах.
- Активность компании: участие в торговых процедурах с учетом роли организации.
- Документы: ссылки на закупочную документацию, технические задания, протоколы, контракты.
- Рекомендованные процедуры: тендеры с высокой вероятностью победы клиента.
- Подбор поставщиков: компании, поставляющие закупаемый товар или оказывающие нужную услугу.
- Данные об участниках и победителях торгов для лидогенерации.
- Архивные данные для маркетинговых и отраслевых исследований.
- Анализ конкурентной среды по тендерам, в которых участвуют конкуренты.
- Более 7000 официальных источников, по описанию API Portal.

Неизвестно:

- Полный перечень источников торгов.
- Географическое покрытие.
- Форматы ответа.
- Полный список фильтров.
- Лимиты запросов и история хранения.
