## Что содержит источник

Подтвержденные данные:

- API позволяет получать сведения с Портала открытых данных Правительства Москвы.
- Портал открытых данных Правительства Москвы был запущен 29 января 2013 года.
- На портале опубликовано более 1000 наборов данных и справочников.
- Тематическое покрытие включает сведения от объектов городской инфраструктуры до расписаний ближайших мероприятий в Москве.

Неизвестно:

- Полный список наборов данных.
- Форматы ответа API.
- Наличие и условия API-ключей.
- Лимиты запросов.
- Частота обновления каждого набора.
- Точная лицензия и условия коммерческого использования.
