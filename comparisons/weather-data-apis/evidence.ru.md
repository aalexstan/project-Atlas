# Доказательства сравнения погодных API

[English version](evidence.md)

| Утверждение | Источник | Статус |
|---|---|---|
| Разделение free/commercial Open-Meteo документировано | https://open-meteo.com/en/pricing | verified |

Сравнение использует три ограниченные live-test записи: [Open-Meteo](../../research/open-meteo-api/live-test-2026-08-24.ru.md), [WeatherAPI.com](../../research/weatherapi-com-api/live-test-2026-08-24.ru.md) и [OpenWeather](../../research/weather/openweather-live-test-2026-08-24.ru.md). Доступность endpoint, response shapes и ограниченные ошибки помечены `observed`; цена, quota, SLA, accuracy и права остаются `provider_reported` или `unknown`.
