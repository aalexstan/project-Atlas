# API маршрутизации и логистики

[English version](README.md)

## Назначение

Сравнение разделяет расчёт маршрута, матрицы расстояний и логистическое планирование. Геокодирование, places, map tiles и routing являются разными закупочными решениями.

## Быстрый выбор

| Сценарий | Первичный shortlist | Почему | Главный риск |
|---|---|---|---|
| Маршрут между точками | Yandex Maps, 2GIS, OSRM | У всех документированы route services | Покрытие, traffic и права нужно тестировать |
| Матрица расстояний / ETA | Yandex Maps, 2GIS, OSRM | Есть matrix или несколько пар точек | Лимиты и семантика ETA пока не сопоставимы |
| Закрытый контур 2ГИС | 2GIS Routing API | Документирован on-premise вариант | Границы договора, инфраструктура и SLA |
| Собственная инфраструктура | OSRM | Self-hosted движок и контроль оператора | Импорт OSM, обновления, лицензия и эксплуатация |
| Оптимизация доставки | Отдельный scope Yandex Routing или 2GIS Route Planner | Расчёт маршрута не равен оптимизации | Граница продукта и коммерческое предложение |

## Вывод

Универсального победителя нет. Выбор зависит от типа маршрута, географии, traffic, размера матрицы, ограничений транспорта, модели размещения и прав хранения/показа результатов. Перед закупкой используйте [procurement kit](../../procurement/routing-api-selection/README.ru.md).
