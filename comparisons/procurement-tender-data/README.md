# Procurement and Tender Data Routes

[Русская версия](README.ru.md)

## Purpose

This comparison separates an official procurement information route from a commercial aggregated API. It is not a vendor ranking.

| Scenario | Initial route | Why | Main risk |
|---|---|---|---|
| Primary provenance and own data platform | EIS integration | Official source and interaction-format route | Current machine interface and rights need confirmation |
| Filtered tender discovery in CRM | Seldon.Tenders API | Provider describes filters and CRM integration | Endpoint, schema, source coverage and price unknown |
| Commercial decision | Both, with RFP | Routes solve different jobs | No common benchmark, quotes or legal review yet |

See the [need route](../../needs/procurement-tender/README.md), [comparison data](comparison.json) and [procurement kit](../../procurement/procurement-api-selection/README.md).
