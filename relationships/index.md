## Правило чтения графа

Главная сущность: Dataset.

Provider распространяет, агрегирует или владеет Dataset.

Access Method описывает, как Dataset можно получить. API является частным случаем Access Method.

Documentation, Cost и License относятся не только к API, а к конкретному способу доступа и поставщику.

## Что пока отсутствует

- Альтернативные поставщики по большинству Dataset.
- Подтвержденные лицензии.
- Подтвержденные форматы ответа.
- Полные схемы полей.
- Официальные OpenAPI/Swagger.
