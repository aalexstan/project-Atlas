# Ревью: публичный live test Open-Meteo

[English version](open-meteo-live-test-2026-08-24.md)

## Объём ревью

Человекочитаемое pre-merge ревью первой записи `research/<slug>/live-test-YYYY-MM-DD.md`.

## Чеклист

- [x] Использована отдельная ветка.
- [x] Core claims зафиксированы до запросов и связаны с профилем.
- [x] Core claims покрывают identity/purpose, response contract и commercial/limits block.
- [x] Срок действия live-test зафиксирован.
- [x] Условия публичного/free доступа проверены, тест остался в заявленной границе.
- [x] Только public free endpoints; credentials и платный customer endpoint не использовались.
- [x] Три реалистичных успешных запроса и один намеренно ошибочный.
- [x] Сохранены raw payload, HTTP-коды и latency.
- [x] Поведение rate limit зафиксировано без исчерпания квоты.
- [x] Непреднамеренный 429 сохранялся бы как finding, а не скрывался повторными попытками.
- [x] Наблюдения сопоставлены с claims карточки.
- [x] Maturity оставлен `reviewed`; `live_tested` отделён.
- [x] Есть английская и русская версии evidence и ссылки из профиля.
- [x] Нет секретов, персональных данных и изменений бинарных файлов.

## Вывод ревью

Формат доказательств достаточно читаем и воспроизводим, чтобы стать первым прецедентом live-test. Тест поддерживает `live_tested: true` для ограниченных публичных форм запросов, но не поддерживает повышение `reviewed` до `verified`, поскольку квота, accuracy, SLA и коммерческие права не проверены либо являются договорными.

Это процедурное self-review, а не независимое ревью для Gold.

## Рекомендация по merge

Одобрять evidence и изменения методологии/шаблона только после того, как человек прочитает staged diff. Не выполнять merge автоматически в рамках исследовательского запуска.
