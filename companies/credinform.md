# Credinform

Дата исследования: 2026-06-23
Статус: первичная карточка

## Общая информация

- Компания: Credinform
- Официальный сайт: https://credinform.ru/ и https://globas.credinform.ru/
- Страна/регион: Россия, по контактам на сайте указаны российские телефоны
- Тип организации: поставщик бизнес-информации и системы Глобас

## Чем занимается

Подтвержденные факты:

- Предоставляет систему Глобас и сервис ГЛОБАС.API.
- ГЛОБАС.API предназначен для обновления и мониторинга данных о контрагентах в приложениях и корпоративных системах.
- На официальной странице указаны сервисы: Глобас.API, модуль санкционного комплаенса, модуль портфель, модуль иностранных справок.

Неизвестно:

- Полная юридическая структура компании.
- Все источники данных.
- Наличие публичного OpenAPI/Swagger.

## Какие данные собирает

- Контрагентские данные.
- Данные о российских организациях и ИП.
- Данные о зарубежных компаниях, по описанию API Portal.
- Данные для мониторинга изменений портфеля контрагентов.
- Данные для санкционного комплаенса, по названию отдельного модуля; детали не исследованы.

## Какие API предоставляет

- ГЛОБАС.API.
