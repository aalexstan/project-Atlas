## Чем занимается

Подтвержденные факты по API Portal:

- Предоставляет API Seldon.Basis для контрагентских и комплаенс-данных.
- Предоставляет API Seldon.Tenders для данных о торгах, контрактах, протоколах, участниках и документах.
- Использует официальные источники информации, по описанию API Portal.

Риск:

- Домен `api-seldon.ru`, указанный API Portal как документация, при проверке открыл нерелевантный контент. До подтверждения официального сайта нельзя считать эту ссылку надежной.

## Какие данные собирает

- Данные о контрагентах.
- Данные о взаимодействующих с контрагентами компаниях.
- Финансовая состоятельность, аффилированность и соответствие правовым нормам, по описанию Seldon.Basis.
- Извещения, протоколы, контракты, участники, ценовые предложения и документы торгов, по описанию Seldon.Tenders.
- Данные из более чем 7000 официальных источников для Seldon.Tenders, по API Portal.

## Какие API предоставляет
