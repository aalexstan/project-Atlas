# API Portal / RNDSOFT

Дата исследования: 2026-06-23
Статус: первичная карточка

## Общая информация

- Компания/организация: API Portal; RNDSOFT указан в футере как разработчик
- Официальный сайт: https://apiportal.ru/
- Страна/регион: не найдено
- Тип организации: цифровой маркетплейс API

## Чем занимается

Подтвержденные факты:

- Поддерживает каталог API с фильтрами по поставщикам, категориям, отраслям, типу тарификации и интегратору.
- Публикует карточки API с описаниями, характеристиками, ссылками на документацию и стоимостью.
- В каталоге указан интегратор `RNDSOFT (208)`.
- В футере указано `Разработано © RNDSOFT`.

Неизвестно:

- Юридический владелец API Portal.
- Условия размещения поставщиков в каталоге.
- Модель верификации карточек.
- Наличие API для самого каталога.

## Какие данные собирает

- Метаданные о сторонних API.
- Данные о поставщиках API.
- Категории, отрасли, тарифы и ссылки на документацию.

## Какие API предоставляет

- API самого каталога не найден.
- API Portal предоставляет каталог сторонних API и форму заказа API.
