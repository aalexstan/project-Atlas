## Чем занимается

Подтвержденные факты по API Portal:

- Предоставляет API-доступ к ФИАС в облаке.
- API предназначен для быстрого ввода и проверки почтовых адресов на сайте.
- Позволяет искать объекты по названию или по коду связанного родительского/дочернего элемента.

Риск:

- Официальный статус `kladr-api.ru` для API ФИАС не подтвержден.
- При проверке корневого домена был обнаружен нерелевантный контент, поэтому документацию нужно валидировать отдельно.

## Какие данные собирает

- Почтовые адреса России, по описанию API Portal.
- Адресные объекты и связи между родительскими/дочерними элементами, по описанию поиска.

Неизвестно:

- Оператор конкретного облачного API.
- Источник обновлений.
- Соответствие официальному государственному адресному реестру.
