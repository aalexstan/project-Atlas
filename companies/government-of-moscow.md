# Правительство Москвы

Дата исследования: 2026-06-23
Статус: первичная карточка

## Общая информация

- Компания/организация: Правительство Москвы
- Официальный сайт: https://data.mos.ru/
- Страна/регион: Россия, Москва
- Тип организации: государственный поставщик открытых данных

## Чем занимается

Подтвержденные факты:

- Публикует Портал открытых данных города Москвы.
- Портал открытых данных Правительства Москвы был запущен 29 января 2013 года.
- Предоставляет API для получения сведений с портала.

## Какие данные собирает

- Более 1000 наборов данных и справочников, по описанию API Portal.
- Данные по различным направлениям: от объектов городской инфраструктуры до расписаний ближайших мероприятий в Москве.

Неизвестно:

- Точные владельцы каждого набора.
- Полный список наборов.
- Частота обновления каждого набора.

## Какие API предоставляет
