# RFP для API закупок

[English version](RFP.md)

Попросите отдельно ответить по интеграции ЕИС и коммерческому агрегированному API:

- границы продукта, объекты и field matrix: извещения, лоты, участники, протоколы, контракты, документы и изменения;
- список официальных источников, способ агрегации, актуальность и глубина истории;
- endpoint или file-feed catalog, base URL, authentication и onboarding;
- форматы запросов/ответов, schemas, versioning, identifiers и error model;
- фильтрация по номеру извещения/контракта, заказчику, региону, категории, дате и участнику;
- full, delta, batch и asynchronous delivery; webhooks или polling;
- update cadence, quotas, rate limits, availability, SLA, support и incidents;
- цена API, minimum commitment, overage и тарификация документов/downloads;
- storage, caching, показ клиентам, redistribution, resale, SaaS и analytics rights;
- персональные данные, security, retention, DPA и трансграничная обработка;
- changelog, deprecation и breaking-change policy;
- разрешённый доступ к синтетическому или публичному benchmark с credentials при необходимости.
