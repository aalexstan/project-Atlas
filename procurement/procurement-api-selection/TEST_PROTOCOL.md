# Procurement data test protocol

[Русская версия](TEST_PROTOCOL.ru.md)

Use only public, synthetic or otherwise authorized data. Do not submit forms or use credentials without permission.

- Choose a fixed sample of notices, lots, protocols and contracts from public official pages.
- Include current, changed, cancelled, completed and archived objects where lawful.
- Test lookup by identifiers and filtered retrieval by date, region, category and participant.
- Compare field completeness, source links, document availability, update timestamps and change history.
- Measure latency, error rate, timeout/retry behavior, duplicate rate and reproducibility.
- Verify full versus delta semantics, pagination, ordering, encoding and schema version.
- Record whether results may be stored, shown to customers, redistributed or used in SaaS.
- Do not treat a successful public-page fetch as API verification or an SLA.
