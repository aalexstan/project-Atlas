# Procurement data-rights checklist

[Русская версия](DATA_RIGHTS.ru.md)

Obtain written answers on:

- source ownership and attribution;
- long-term storage and backups;
- caching and derived datasets;
- customer-facing display and exports;
- redistribution, resale and affiliate use;
- SaaS embedding and internal analytics;
- document downloads and copied source links;
- personal data, retention and deletion;
- security incident and breach notification;
- termination, migration and deletion obligations.
