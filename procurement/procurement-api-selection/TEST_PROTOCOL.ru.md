# Протокол теста закупочных данных

[English version](TEST_PROTOCOL.md)

Используйте только публичные, синтетические или иным образом разрешённые данные. Не отправляйте формы и не используйте credentials без разрешения.

- Сформируйте фиксированную выборку извещений, лотов, протоколов и контрактов с публичных официальных страниц.
- Законно включите текущие, изменённые, отменённые, завершённые и архивные объекты.
- Проверьте поиск по идентификаторам и фильтры по дате, региону, категории и участнику.
- Сравните полноту полей, ссылки на источники, наличие документов, timestamps обновления и историю изменений.
- Измерьте latency, error rate, timeout/retry behavior, duplicates и воспроизводимость.
- Проверьте full/delta semantics, pagination, ordering, encoding и schema version.
- Зафиксируйте, можно ли хранить, показывать клиентам, перераспределять результаты или использовать их в SaaS.
- Успешная загрузка публичной веб-страницы не является API verification или SLA.
