# RFP для API маршрутизации

[English version](RFP.md)

Попросите поставщика отдельно ответить по route details, matrix, traffic и логистической оптимизации:

- матрица продуктов и методов; режимы транспорта; лимиты точек и матриц;
- base URL, authentication, форматы запросов/ответов и versioning;
- traffic, ETA, платные дороги, ограничения грузовиков и временные окна;
- multi-stop optimization, batch, асинхронные задания и webhooks;
- география, актуальность и источники карт/данных;
- цена API, minimum commitment, overage и batch billing;
- production quotas, rate limits, SLA, support и incident communication;
- хранение, caching, показ клиентам, attribution, SaaS, redistribution и resale;
- связь с картой и возможность показа результатов без карты поставщика;
- персональные данные, DPA, retention и трансграничная обработка;
- changelog, deprecation и breaking-change policy;
- sandbox credentials для разрешённого синтетического benchmark.
