# Routing operations checklist

[Русская версия](CHECKLIST.ru.md)

- Define route, matrix, ETA or optimization before requesting quotes.
- Record geography, modes, vehicle restrictions, stop count and peak volume.
- Separate API price from web maps, SDK, on-premise and logistics product pricing.
- Obtain written storage, caching, display, SaaS, attribution and redistribution terms.
- Require a sandbox or test key and a versioned test window.
- Confirm SLA, support, incident communication, quotas and overage behavior.
- For self-hosting, budget data import, updates, hardware, monitoring, backups and licence compliance.
