# Протокол benchmark маршрутизации

[English version](TEST_PROTOCOL.md)

Используйте только синтетические, публичные или иным образом разрешённые данные. Не отправляйте персональные или клиентские данные.

- Проверьте Москву, Санкт-Петербург, региональные города и хотя бы один межрегиональный маршрут.
- Проверьте маршруты между точками, несколько остановок, матрицы расстояний и повторные запросы.
- Включите пеший, автомобильный и, если документировано, грузовой режим.
- Включите неоднозначные координаты, несвязанные точки, платные дороги и длинные маршруты.
- Фиксируйте класс запроса, версию поставщика, код ответа, distance, duration, варианты маршрута и статус сопоставления.
- Измеряйте percentiles latency, error rate, timeouts, пропущенные маршруты, false positives и воспроизводимость.
- Сравнивайте порядок координат, единицы, формат geometry, traffic assumptions и поведение в разное время.
- Публичный demo endpoint не является production SLA или live verification Atlas.
