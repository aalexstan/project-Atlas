# Операционный чеклист маршрутизации

[English version](CHECKLIST.md)

- Сначала определите route, matrix, ETA или optimization.
- Зафиксируйте географию, режимы, ограничения транспорта, число остановок и пиковую нагрузку.
- Отделяйте цену API от веб-карт, SDK, on-premise и цены логистического продукта.
- Получите письменные условия хранения, caching, показа, SaaS, attribution и redistribution.
- Попросите sandbox или test key и версионированное окно теста.
- Подтвердите SLA, support, incident communication, quotas и overage.
- Для self-hosting заложите импорт, обновления, hardware, monitoring, backups и соблюдение лицензии.
