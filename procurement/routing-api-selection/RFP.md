# Routing API RFP

[Русская версия](RFP.ru.md)

Ask each provider to answer separately for route details, matrix, traffic and logistics optimization:

- product and method matrix; route modes; waypoint and matrix limits;
- base URL, authentication, request/response formats and versioning;
- traffic, ETA, tolls, truck restrictions and time windows;
- multi-stop optimization, batching, asynchronous jobs and webhooks;
- geography, freshness and map/data sources;
- public API price, minimum commitment, overage and batch billing;
- production quotas, rate limits, SLA, support and incident communication;
- storage, caching, customer-facing display, attribution, SaaS, redistribution and resale;
- map coupling and whether results may be shown without the provider map;
- personal data, DPA, retention and cross-border processing;
- changelog, deprecation and breaking-change policy;
- sandbox credentials for a permitted synthetic benchmark.
