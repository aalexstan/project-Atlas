# Commerce Operations API Selection Kit

[Русская версия](README.ru.md)

This kit helps compare an ERP-style operational core with marketplace seller APIs. It is designed for MoySklad JSON API, Wildberries Seller API and Ozon Seller API, but can be reused for other channels.

- [RFP](RFP.md)
- [Test protocol](TEST_PROTOCOL.md)
- [Data and rights checklist](CHECKLIST.md)
- [Scenario scorecard](SCORING.md)

The kit does not send requests, use credentials or create a vendor ranking. It separates documented facts, provider answers, measured observations and unknowns.
