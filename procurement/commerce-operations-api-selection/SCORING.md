# Commerce Operations Scenario Scorecard

[Русская версия](SCORING.ru.md)

Score each candidate separately from 0 to 3 using evidence, not preference:

| Criterion | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Core data coverage | unknown | partial | documented | tested in permitted scope |
| Order and inventory workflow | unknown | partial | documented | tested in permitted scope |
| Integration contract | unknown | partial docs | clear docs | reproducible test |
| Limits and operations | unknown | examples only | documented | measured in permitted scope |
| Data rights | unknown | provider answer pending | written terms | reviewed for scenario |
| Support and SLA | unknown | support channel only | written commitment | measured incident process |

Do not sum into an Atlas Score. Use the rows to expose blockers and choose a scenario-specific shortlist.
