# Сценарный scorecard API торговых операций

[English version](SCORING.md)

Оценивайте каждого кандидата отдельно от 0 до 3 по доказательствам, а не по предпочтению:

| Критерий | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Покрытие основных данных | неизвестно | частично | документировано | проверено в разрешённом scope |
| Заказы и остатки | неизвестно | частично | документировано | проверено в разрешённом scope |
| Интеграционный контракт | неизвестно | частичная документация | ясная документация | воспроизводимый тест |
| Лимиты и эксплуатация | неизвестно | только примеры | документировано | измерено в разрешённом scope |
| Права на данные | неизвестно | ждём ответ поставщика | письменные условия | проверено для сценария |
| Поддержка и SLA | неизвестно | только канал поддержки | письменное обязательство | измеренный процесс инцидента |

Не складывайте баллы в Atlas Score. Используйте строки, чтобы видеть блокеры и выбирать shortlist под конкретный сценарий.
