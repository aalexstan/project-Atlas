# Пакет выбора API торговых операций

[English version](README.md)

Пакет помогает сравнить ERP-подобное операционное ядро с seller API маркетплейсов. Он рассчитан на MoySklad JSON API, Wildberries Seller API и Ozon Seller API, но может применяться и к другим каналам.

- [RFP](RFP.ru.md)
- [Протокол тестирования](TEST_PROTOCOL.ru.md)
- [Чеклист данных и прав](CHECKLIST.ru.md)
- [Сценарный scorecard](SCORING.ru.md)

Пакет не отправляет запросы, не использует credentials и не создаёт рейтинг поставщиков. Он разделяет документированные факты, ответы поставщика, измеренные наблюдения и неизвестные параметры.
