# RFP для weather API

[English version](RFP.md)

1. Какой точный продукт, модели, endpoints и юридическое лицо входят в предложение?
2. Дайте field matrix для current, forecast, historical, climate, air quality и alerts.
3. Разделите фактические station observations и model output; объясните semantics historical.
4. Дайте coordinates, timezone, grid/resolution, update frequency и freshness по регионам.
5. Дайте forecast horizons, aggregation rules, backfill/revision behavior и versioning.
6. Дайте API key/authentication, OpenAPI/SDK, quotas, rate limits, batch и bulk options.
7. Дайте public и negotiated price, minimums, overage, VAT и storage/egress costs.
8. Подтвердите commercial use, storage, caching, customer display, derived data, redistribution и attribution.
9. Дайте SLA, support, incident communication, status history и deprecation policy.
10. Укажите разрешённые и запрещённые сценарии для logistics, insurance, safety, agriculture и regulated decisions.
