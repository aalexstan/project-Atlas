# Weather API RFP

[Русская версия](RFP.ru.md)

1. Which exact product, models, endpoints and legal entity are included?
2. Provide current weather, forecast, historical, climate, air-quality and alert field matrix.
3. Clarify actual station observations versus model output and historical data semantics.
4. Provide coordinates, timezone, grid/resolution, update frequency and freshness by region.
5. Provide forecast horizons, aggregation rules, backfill/revision behavior and versioning.
6. Provide API key/authentication, OpenAPI/SDK, quotas, rate limits, batch and bulk options.
7. Provide public and negotiated price, minimums, overage, VAT and data egress/storage costs.
8. Confirm commercial use, storage, caching, customer display, derived data, redistribution and attribution.
9. Provide SLA, support, incident communication, status history and deprecation policy.
10. Provide permitted use and exclusions for logistics, insurance, safety, agriculture and regulated decisions.
