# Закупка данных о недвижимости и кадастре

[English version](README.md)

Используйте этот kit при выборе official EGRN access, integration route НСПД или commercial enrichment provider.

1. Определите, должен ли результат быть юридически значимым.
2. Заполните [RFP](RFP.ru.md).
3. Проведите [протокол теста](TEST_PROTOCOL.ru.md) только с законным доступом и без чувствительных данных.
4. Письменно проверьте storage, display, redistribution и automated-decision rights.

Не сравнивайте цену выписки с ценой API enrichment call как одинаковые продукты.
