# Real-estate and Cadastral Data Procurement

[Русская версия](README.ru.md)

Use this kit when selecting official EGRN access, an NSPD integration route or a commercial enrichment provider.

1. Define whether the output must be legally significant.
2. Complete the [RFP](RFP.md).
3. Run the [test protocol](TEST_PROTOCOL.md) only with lawful access and non-sensitive samples.
4. Review storage, display, redistribution and automated-decision rights in writing.

Do not compare an extract fee with an API enrichment call as if they were the same product.
