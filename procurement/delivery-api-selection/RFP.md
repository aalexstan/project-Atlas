# Delivery API RFP

[Русская версия](RFP.ru.md)

- Confirm whether the product is tracking, order creation, dispatch or carrier aggregation.
- Request supported carriers, geography, shipment types, status model, freshness and history.
- Request authentication, sandbox, schemas, webhooks, polling, batch limits and idempotency.
- Request API-specific price, production quotas, SLA, support and incident handling.
- Obtain written storage, customer display, SaaS, redistribution and personal-data terms.
