# RFP для API доставки

[English version](RFP.md)

- Подтвердите, является ли продукт tracking, order creation, dispatch или carrier aggregation.
- Запросите перевозчиков, географию, типы отправлений, status model, freshness и историю.
- Запросите authentication, sandbox, schemas, webhooks, polling, batch limits и idempotency.
- Запросите цену API, production quotas, SLA, support и incident handling.
- Получите письменные условия storage, показа клиентам, SaaS, redistribution и персональных данных.
