# Протокол теста API доставки

[English version](TEST_PROTOCOL.md)

Используйте только разрешённые test data и accounts. Проверьте последовательность статусов, timestamps событий, дубликаты/события не по порядку, неверные идентификаторы, retries, batch limits, webhook delivery и показ статуса клиенту. Фиксируйте latency, errors, пропущенные события и воспроизводимость. Не заявляйте live test Atlas, пока evidence не сохранены.
