# Протокол тестирования платёжного API

[English version](TEST_PROTOCOL.md)

Используйте только синтетические или разрешённые поставщиком тестовые данные. Не используйте реальные номера карт, персональные данные и production funds.

Для каждого кандидата проверьте одинаковые сценарии:

- создание платежа и получение статуса;
- успех, отказ, timeout, повторный запрос и retry;
- доставка webhook, проверка подписи/аутентификации, duplicate webhook и replay;
- полный и частичный возврат;
- отмена и подтверждение two-stage, если поддерживаются;
- payload чека и передача в фискализацию;
- consent и отмена recurring payment, если поддерживаются;
- платёжная ссылка и mobile/redirect flow.

Записывайте timestamp запроса, correlation/idempotency key, response code, финальное состояние, webhook latency, число retries, результат возврата и классификацию ошибки. Публикуйте только измеренные результаты с датой и окружением. В этом репозитории результаты тестов не заявляются.
