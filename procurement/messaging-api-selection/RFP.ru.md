# RFP для messaging API

[English version](RFP.md)

1. Какой точный продукт, юридическое лицо и каналы сообщений входят в предложение?
2. Дайте API reference, base URL, аутентификацию, SDK, versioning и deprecation policy.
3. Опишите send, status, delivery report, callback/webhook, retry, idempotency и error flows.
4. Для SMS дайте страны/операторов, sender approval, encoding, multipart и DLR semantics.
5. Для Telegram/chat опишите consent, user initiation, broadcast restrictions и bot/business scope.
6. Дайте production throughput, quotas, burst limits, queueing, latency guidance и SLA.
7. Дайте цену по маршруту, оператору, длине, sender, OTP/voice и failed delivery; укажите VAT и минимумы.
8. Подтвердите opt-out, персональные данные, retention, deletion, security, DPA и incident notification.
9. Подтвердите customer display, SaaS, redistribution, reselling и multi-tenant use.
10. Дайте support, escalation, delivery reports, changelog и срок уведомления breaking changes.
