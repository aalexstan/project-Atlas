# Atlas Procurement Kit: Counterparty APIs

[Русская версия](README.ru.md)

A practical selection kit for:

- DaData;
- Kontur.Focus API;
- Seldon.Basis API;
- direct Russian FTS EGRUL/EGRIP integration.

## Purpose

The kit does not declare a winner in advance. It creates comparable evidence:

1. commercial quotation;
2. technical and production limits;
3. legal rights to store and use data;
4. results from the same evaluation sample;
5. complete three-year TCO;
6. weighted scorecard with visible unknowns.

## Main File

`workbook/atlas-counterparty-procurement-kit.xlsx`

Sheets:

- **Dashboard** — results and decision gates;
- **Provider Inputs** — quotes and internal assumptions;
- **TCO Calculator** — three-year known-cost model;
- **Scorecard** — 14 weighted criteria;
- **Test Cases** — 20 shared evaluation scenarios;
- **Test Results** — 80 provider/test rows;
- **RFP Tracker** — 30 procurement questions;
- **Sources** — official research sources;
- **Lists** — dropdown values.

## Rules

- A blank is not zero.
- Do not score a criterion without evidence.
- Web-product pricing is not API pricing.
- Marketed functionality is not tested functionality.
- Do not submit confidential customer identifiers without a lawful basis.
- A low TCO with low input completeness is not an advantage.
- A decision remains blocked while critical RFP gaps remain.

## Expected Outcome

The process should produce scenario-based conclusions:

- best for fastest implementation;
- best for deep risk control;
- best for relationship and procurement analysis;
- best for a self-managed bulk registry warehouse;
- unsuitable because of legal or operational restrictions.
