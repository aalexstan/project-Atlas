# Atlas Procurement Kit: API проверки контрагентов

[English version](README.md)

Практический комплект для выбора между:

- DaData;
- Контур.Фокус API;
- Seldon.Basis API;
- прямой интеграцией ФНС с ЕГРЮЛ/ЕГРИП.

## Что решает комплект

Он не объявляет победителя заранее. Он заставляет собрать сопоставимые доказательства:

1. коммерческое предложение;
2. технические и production-лимиты;
3. юридические права на хранение и использование данных;
4. результаты одинаковой тестовой выборки;
5. полный трёхлетний TCO;
6. взвешенную scorecard с видимыми пробелами.

## Основной файл

`workbook/atlas-counterparty-procurement-kit.xlsx`

Листы:

- **Dashboard** — итоговые показатели и decision gates;
- **Provider Inputs** — тарифы и внутренние затраты;
- **TCO Calculator** — известный трёхлетний TCO;
- **Scorecard** — 14 критериев с весами;
- **Test Cases** — единая выборка из 20 сценариев;
- **Test Results** — 80 строк для четырёх поставщиков;
- **RFP Tracker** — 30 обязательных и дополнительных вопросов;
- **Sources** — официальные источники;
- **Lists** — справочники выпадающих значений.

## Правила использования

- Пустое поле не означает ноль.
- Нельзя оценивать критерий без доказательства.
- Цена веб-версии не считается ценой API.
- Маркетинговая функциональность не считается протестированной.
- Нельзя передавать поставщику конфиденциальных клиентов без правового основания.
- Низкий TCO при низкой полноте исходных данных не является преимуществом.
- Решение блокируется, пока остаются критические RFP-пробелы.

## Результат процесса

Процесс должен закончиться не фразой «этот API лучший», а выводами по сценариям:

- лучший для быстрого внедрения;
- лучший для глубокого риск-контроля;
- лучший для связей и закупочной аналитики;
- лучший для массового собственного хранилища;
- вариант, который нельзя использовать из-за юридических или эксплуатационных ограничений.
