# Политика тестовой выборки

[English version](SAMPLE_POLICY.md)

## Цель

Выборка должна обнаруживать различия поставщиков, а не подтверждать заранее выбранный вывод.

## Состав

Рекомендуемые типы:

- активное крупное юридическое лицо;
- филиал;
- ИП;
- ликвидация;
- реорганизация;
- банкротство;
- недавнее изменение адреса;
- отсутствующая отчётность;
- суды и исполнительные производства;
- закупки и РНП;
- СНГ или другая целевая страна;
- неоднозначный поиск по названию;
- неверный идентификатор;
- batch с частичной ошибкой.

## Безопасность

Разрешены:

- публичные идентификаторы организаций;
- идентификаторы из официальной документации;
- синтетические неверные значения.

Не включаются без отдельного основания:

- клиентская база;
- персональные идентификаторы;
- закрытые расследования;
- данные, переданные под NDA.

## Замораживание

Перед первым сравнительным запуском:

1. заполнить все обязательные строки;
2. сохранить дату;
3. зафиксировать expected checks;
4. запретить замену неудобных тестов после получения результатов.
