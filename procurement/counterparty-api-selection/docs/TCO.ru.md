# Методика TCO

[English version](TCO.md)

## Что считает модель

Для каждого поставщика рассчитываются:

- годовая лицензия;
- setup fee;
- стоимость превышения включённого объёма;
- ежегодная плата за методы;
- часы внедрения;
- инфраструктура;
- поддержка;
- внутренние операционные часы;
- рост нагрузки;
- итог за три года.

## Формула года 1

`лицензия + setup + методы + usage + внедрение + инфраструктура + поддержка + внутренние операции`

Годы 2 и 3 не включают первоначальное внедрение, но учитывают рост запросов.

## Known-Cost TCO

Пустые денежные поля технически считаются нулём, чтобы модель оставалась вычислимой. Поэтому результат называется **Known-Cost TCO**, а не гарантированной полной стоимостью.

Обязательно проверяются:

- Completeness;
- Evidence Status;
- TCO Confidence;
- Decision Warning.

## Что нужно добавить вручную

- НДС, если применим;
- курс валют;
- скидки;
- стоимость закупочной процедуры;
- безопасность и legal review;
- миграция;
- простой;
- стоимость выхода;
- цена хранения и истории;
- резервный поставщик.

## Важное ограничение

Цена API должна браться из API-предложения. Нельзя подставлять цену веб-кабинета, пользовательского тарифа или отдельного модуля.
