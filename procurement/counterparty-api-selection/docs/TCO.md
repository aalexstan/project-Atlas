# TCO Methodology

[Русская версия](TCO.ru.md)

## Model Components

Per provider the workbook models:

- annual license;
- setup fee;
- overage usage;
- annual method fees;
- implementation hours;
- infrastructure;
- support;
- internal operational hours;
- request growth;
- three-year total.

## Year 1

`license + setup + methods + usage + implementation + infrastructure + support + internal operations`

Years 2 and 3 exclude initial implementation and apply request growth.

## Known-Cost TCO

Blank monetary inputs are technically treated as zero so formulas remain usable. The result is therefore **Known-Cost TCO**, not guaranteed complete cost.

Always review:

- Completeness;
- Evidence Status;
- TCO Confidence;
- Decision Warning.

## Add Manually

- taxes;
- currency changes;
- discounts;
- procurement overhead;
- security and legal review;
- migration;
- outage cost;
- exit cost;
- storage and history;
- backup provider.

## Important Limitation

Use an API quotation for API cost. Do not substitute web-dashboard, user-seat, or separate module pricing.
