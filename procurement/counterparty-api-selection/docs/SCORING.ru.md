# Методика scorecard

[English version](SCORING.md)

## Принцип

Оценка не является мнением автора и не заполняется заранее. Балл вводится только после появления доказательства.

## Шкала

- **0** — отсутствует или неприемлемо;
- **1** — очень слабое соответствие;
- **2** — слабое;
- **3** — достаточное;
- **4** — сильное;
- **5** — отличное соответствие задаче.

`Unknown` не равен нулю. При неизвестном значении поле Score остаётся пустым.

## Формула

Взвешенный балл рассчитывается только по заполненным критериям:

`Σ(вес × балл) / Σ(вес заполненных критериев)`

Рядом обязательно показывается **Scored Weight Coverage**. Балл нельзя использовать для решения, если покрыто менее 75% веса.

## Critical Criteria

Критическими считаются:

- прозрачность и моделируемость цены;
- достаточность лимитов;
- покрытие обязательных данных;
- свежесть;
- SLA;
- хранение;
- показ и распространение;
- breaking changes.

Один нерешённый критический вопрос может блокировать решение независимо от общего балла.

## Почему нет общего рейтинга Atlas

Один и тот же поставщик может быть:

- лучшим для формы регистрации;
- слишком дорогим для массовой обработки;
- лучшим для риск-контроля;
- юридически непригодным для SaaS.

Поэтому scorecard оценивает соответствие конкретному сценарию, а не «качество вообще».
