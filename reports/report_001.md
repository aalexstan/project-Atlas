# Report 001

Дата: 2026-06-23
Тема: старт Project Atlas и первичный проход по API Portal

## Что исследовано

- Создана структура Project Atlas.
- Исследован API Portal как стартовый каталог: https://apiportal.ru/catalog/
- Из первой страницы каталога выбраны первые источники с высокой ценностью для будущей базы:
  - API Portal как мета-источник
  - ГЛОБАС.API
  - API Seldon.Basis
  - API Seldon.Tenders
  - API Портала открытых данных города Москвы
  - API ФИАС

## Что найдено

- API Portal содержит обширный каталог API с фильтрами по поставщикам, категориям, отраслям, типу тарификации и интегратору.
- В каталоге много источников данных, пригодных для долгосрочной базы знаний: контрагенты, закупки, открытые данные, адреса, финтех, государственные сервисы.
- ГЛОБАС.API и Seldon.Basis покрывают проверку контрагентов и комплаенс.
- Seldon.Tenders покрывает закупки, контракты, протоколы, участников и документы.
- API открытых данных Москвы покрывает государственные городские наборы данных.
- API ФИАС покрывает адресную базу и проверку адресов.

## Какие вопросы появились

- Кто юридически владеет API Portal и как проверяются карточки?
- Где актуальная официальная документация Seldon.Basis и Seldon.Tenders?
- Является ли `kladr-api.ru` актуальным и официальным источником для API ФИАС?
- Какие лицензии разрешают хранение, перепродажу, SaaS и обучение ИИ на данных каждого источника?
- Какие API имеют Swagger/OpenAPI?
- Можно ли получить полный экспорт каталога API Portal без парсинга HTML?

## Что исследовать дальше

- Продолжить первую страницу API Portal и добавить оставшиеся карточки.
- Проверить Seldon через официальный сайт и документы, а не только через API Portal.
- Проверить портал открытых данных Москвы: форматы, лимиты, ключи, лицензии.
- Проверить официальный ФИАС и альтернативные официальные способы получения адресных данных.
- Отдельно исследовать рынок контрагентских API: Глобас, Seldon, SpectrumData, Репутация, Актион.

## Итог

Первый запуск создал рабочую базу знаний и подтвердил, что API Portal подходит как стартовая карта рынка данных. Однако каталог нужно использовать осторожно: он полезен для обнаружения источников, но не заменяет официальную документацию, договоры и лицензии поставщиков.
