# Glossary

[Русская версия](GLOSSARY.ru.md)

- **API:** A defined interface that allows software systems to exchange commands or data.
- **API Profile:** The primary Atlas research document for one API product or clearly bounded API family.
- **Provider:** The organization responsible for offering, operating, or distributing an API.
- **User Need:** A concrete problem, such as geocoding an address or verifying a company.
- **Comparison:** A task-oriented evaluation of multiple realistic API options.
- **Alternative:** Another API or access method capable of solving substantially the same need.
- **Dataset:** A structured collection of data exposed, transformed, or used by an API.
- **Endpoint:** A callable API operation or resource address.
- **Authentication:** The mechanism used to identify and authorize a caller.
- **Rate Limit:** A restriction on request frequency over a time window.
- **Quota:** A total allowed usage amount for a billing period or other interval.
- **Free Tier:** A continuing no-cost allowance, different from a time-limited trial.
- **Sandbox:** A test environment separated from normal production behavior or billing.
- **SDK:** A software development kit that simplifies integration.
- **Webhook:** An HTTP callback sent when an event occurs.
- **SLA:** A service-level agreement with measurable service commitments.
- **Evidence:** A source or reproducible observation supporting a fact.
- **Verification:** Checking a claim against evidence at a recorded date.
- **Maturity Level:** The completeness of Atlas research: Discovered, Verified, Reviewed, Compared, or Gold.
- **Verdict:** A scenario-based recommendation derived from facts and explicit analysis.
- **Commercial Use:** Use in a revenue-generating product, paid service, or business process.
- **Redistribution:** Providing raw or transformed API outputs to another party.
- **Material Change:** A change affecting selection, integration, cost, legality, availability, or operation.
