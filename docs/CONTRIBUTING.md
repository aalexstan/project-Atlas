# Contributing

[Русская версия](CONTRIBUTING.ru.md)

Atlas welcomes new profiles, corrections, source updates, change reports, comparisons, translation improvements, and validation tooling.

## Minimum Standards

A contribution should:

- use the current template;
- prefer primary sources;
- include source URLs and verification dates;
- separate facts from analysis;
- preserve unknown states;
- avoid promotional language;
- disclose conflicts of interest;
- use clear English or Russian.

## Bilingual Policy

Main public navigation documents are maintained in English and Russian. New API research may begin in one language when necessary, but the missing version must be marked as pending. Machine translation requires review.

## Recommended Paths

```text
apis/<provider-or-product-slug>/
    README.md
    README.ru.md
    evidence.md
    changes.md

comparisons/<task-slug>/
    README.md
    README.ru.md
```

## Updating Facts

When changing a factual claim:

1. cite the new evidence;
2. record the verification date;
3. explain material differences;
4. preserve useful historical context.

## Conflicts of Interest

Disclose employment, sponsorship, referral arrangements, free provider access, or other material relationships.

## Review Questions

- Does this help someone make a decision?
- Is each important claim traceable?
- Are unknowns visible?
- Is analysis separated from fact?
- Are the alternatives realistic?
- Is the content current enough to publish?
