# Глоссарий

[English version](GLOSSARY.md)

- **API:** Определённый интерфейс, позволяющий программным системам обмениваться командами или данными.
- **Карточка API:** Основной исследовательский документ Atlas для одного API-продукта или чётко ограниченного семейства API.
- **Поставщик:** Организация, предлагающая, эксплуатирующая или распространяющая API.
- **Задача пользователя:** Конкретная проблема, например геокодирование адреса или проверка компании.
- **Сравнение:** Оценка нескольких реалистичных API вокруг одной задачи.
- **Альтернатива:** Другой API или способ доступа, способный решить по существу ту же задачу.
- **Dataset / Набор данных:** Структурированная совокупность данных, которую API предоставляет, преобразует или использует.
- **Endpoint:** Вызываемая операция API или адрес ресурса.
- **Авторизация:** Механизм идентификации и предоставления прав клиенту.
- **Rate Limit:** Ограничение частоты запросов за заданный период.
- **Квота:** Общий разрешённый объём использования за период.
- **Free Tier:** Постоянно доступный бесплатный объём, отличный от временного trial.
- **Sandbox:** Тестовая среда, отделённая от обычного production-поведения или оплаты.
- **SDK:** Набор инструментов разработки, упрощающий интеграцию.
- **Webhook:** HTTP callback, отправляемый при наступлении события.
- **SLA:** Соглашение об уровне сервиса с измеримыми обязательствами.
- **Доказательство:** Источник или воспроизводимое наблюдение, подтверждающее факт.
- **Проверка:** Сопоставление утверждения с доказательством на зафиксированную дату.
- **Уровень зрелости:** Полнота исследования Atlas: Discovered, Verified, Reviewed, Compared или Gold.
- **Вывод:** Рекомендация по сценариям на основе фактов и явно обозначенного анализа.
- **Коммерческое использование:** Использование в продукте, платной услуге или бизнес-процессе.
- **Распространение:** Передача сырых или преобразованных результатов API третьей стороне.
- **Существенное изменение:** Изменение, влияющее на выбор, интеграцию, стоимость, законность, доступность или эксплуатацию.
