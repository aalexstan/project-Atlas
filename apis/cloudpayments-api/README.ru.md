# API CloudPayments

[English version](README.md)

## Краткий вывод

**Подходит для:** интернет-эквайринга с криптограммами карт, одно- и двухстадийными платежами, возвратами, подписками и уведомлениями.

**Нельзя принимать решение без заявки, если:** нужны публичная цена API, production quotas или подтверждённый SLA.

**Итог:** официальная документация ясно описывает границы шлюза и основные операции. Коммерческие условия и часть операционных гарантий нужно получать у поставщика.

## Технический доступ

| Поле | Значение |
|---|---|
| Base URL | `https://api.cloudpayments.ru` |
| Формат | POST; JSON или form encoding; ответы JSON |
| Аутентификация | HTTP Basic Auth с Public ID и API Secret |
| Webhooks | Документированы уведомления о платежах, возвратах и чеках |
| Sandbox | Документирован метод `/test`; нужны credentials |
| OpenAPI | В проверенных официальных источниках не найден |

## Коммерческие ограничения

В проверенных официальных источниках не найден полный публичный API-specific тариф. Письменно подтвердить комиссию, минимумы, зачисления, production limits, SLA, storage, SaaS и redistribution rights.

## Рекомендация по сценарию

- Выбирать CloudPayments, если архитектуре нужны криптограммы, двухстадийные операции и подписки.
- Сравнивать с ЮKassa, если важнее публичная OpenAPI-спецификация и широта документации.
- Сравнивать с Т‑Банком, если важны банковские отношения, зачисления или интеграция с T‑API.
