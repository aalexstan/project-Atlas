# Evidence

[Русская версия](evidence.ru.md)

- Russian Post defines the service as an API for sender information systems to receive tracking information: [FAQ](https://tracking.pochta.ru/support/faq/service_about).
- The FAQ specifies single access of 100 requests/day and batch requests of up to 3,000 tracking numbers under a contract.
- The official specification documents SOAP 1.2, WSDL, authentication and history methods: [specification](https://tracking.pochta.ru/specification).
- No Atlas live test was performed.
