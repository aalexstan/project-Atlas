## Краткий вывод

**Подходит для:** получения истории регистрируемых отправлений Почты России.

Документированный единичный API использует SOAP 1.2 и поддерживает 100 запросов в сутки для зарегистрированного пользователя. Contracted batch access поддерживает до 3 000 трек-номеров в запросе. Это не общий carrier aggregator и не API создания заказов.

См. [evidence](evidence.ru.md) и [research log](../../research/delivery-tracking/2026-08-22-russian-post.ru.md).
