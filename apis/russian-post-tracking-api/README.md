## Quick Verdict

**Best for:** retrieving history for registered Russian Post items.

The documented single-access API uses SOAP 1.2 and supports 100 requests/day for a registered user. Contracted batch access supports up to 3,000 tracking numbers per request. It is not a general carrier aggregator or order-creation API.
