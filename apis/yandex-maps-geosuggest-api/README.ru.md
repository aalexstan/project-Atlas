## Краткий вывод

**Лучше всего подходит:** для пользовательского autocomplete адресов и организаций, если продукт уже совместим с лицензированием и требованиями показа Яндекс Карт.

**Не подходит:** когда нужна backend-нормализация адресов, проверка по официальному реестру, прямое/обратное геокодирование без отдельного вызова Geocoder, маршрутизация или массовое offline-обогащение.

**Итог:** Geosuggest — отдельный продукт API Яндекс Карт. Его нужно рассматривать как слой подсказок, а не как замену [`Yandex Maps Geocoder API`](../yandex-maps-geocoder-api/README.ru.md) или API чистки адресов.

## Граница продукта

Профиль покрывает:

- подсказки по фрагментам адресов и геообъектов;
- подсказки названий организаций в рамках возможностей Geosuggest;
- ограничение выдачи по локации, bounding box, стране и типу объекта;
- связь с Geocoder API через возвращаемый `uri`.

Профиль не покрывает:

- прямое и обратное геокодирование;
- полноценный поиск организаций или enrichment справочника;
- маршрутизацию и матрицы;
- нормализацию российских адресов до качества реестра.

## Сценарии

| Сценарий | Fit | Почему |
|---|---|---|
| Адресные подсказки в продукте на Яндекс Картах | Strong | Документация описывает Geosuggest как специальный API подсказок. |
| Autocomplete названия организации | Medium | Geosuggest поддерживает подсказки организаций, но полноценный поиск организаций — отдельный продукт. |
| Геокодирование после выбора подсказки | Medium | `attrs=uri` может вернуть URI для запроса в Geocoder API. |
| Backend-чистка адресов | Weak | Для Geosuggest не описан workflow чистки и стандартизации. |
| Массовое enrichment | Weak | Autocomplete-семантика и лицензия требуют отдельного подтверждения. |
| Маршрутизация | Not applicable | Маршрутизация — отдельная семья API Яндекс Карт. |

## Технический доступ

| Поле | Значение |
|---|---|
| Protocol | HTTP GET |
| Endpoint | `https://suggest-maps.yandex.ru/v1/suggest` |
| Обязательные параметры | `apikey`, `text` |
| Authentication | API key в query-параметре `apikey` |
| Формат ответа | JSON |
| Default result count | 7 |
| Maximum result count | 10 |
| Основные фильтры | `lang`, `ll`, `spn`, `bbox`, `countries`, `types`, `strict_bounds` |
| Фильтры типов | `biz`, `geo`, `street`, `metro`, `district`, `locality`, `area`, `province`, `country`, `house`, `entrance` |
| OpenAPI / Swagger | Не найдено в публичных документах |

## Коммерческие и юридические замечания

- Тарифная страница разделяет Standard и Extended licenses; права хранения нужно проверять в выбранной лицензии.
- К API-ключам и использованию данных применяются общие условия API Яндекс Карт.
- Показ клиентам, хранение, кэширование, SaaS embedding и redistribution требуют договорного review.
- Geosuggest не доказывает включение отдельного поиска организаций или маршрутизации.

## Альтернативы

| Альтернатива | Когда лучше | Главный компромисс |
|---|---|---|
| [`DaData Address APIs`](../dadata-address-api/README.ru.md) | Главная задача — российские адресные формы и backend-нормализация | Глубина по России; разные endpoint тарифицируются по-разному. |
| [`Yandex Maps Geocoder API`](../yandex-maps-geocoder-api/README.ru.md) | Выбранный адрес/объект нужно превратить в координаты или координаты в адрес | Это не API подсказок. |
| [`2GIS Suggest API`](../2gis-suggest-api/README.ru.md) | UI строится вокруг поиска и каталога 2GIS | Нужно проверить права хранения/кэширования и ecosystem fit. |
| [`FIAS/GAR Data Integration`](../fias-gar-data-integration/README.ru.md) | Нужен официальный российский адресный реестр | Нужна собственная поисковая и matching-инфраструктура. |

## Сценарная рекомендация

Включайте Yandex Geosuggest в shortlist, когда UX ввода адреса связан с Яндекс Картами или полезны подсказки организаций/геообъектов Яндекса. Отдельно принимайте решения по геокодированию, чистке адресов, поиску мест и правам хранения данных.
