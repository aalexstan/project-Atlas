## Краткий вывод

**Подходит для:** бесплатных публичных функций расписаний: рейсов по станции и между станциями.

API документирован через HTTPS GET с JSON/XML и API-key access. Определяющими являются опубликованные условия: бесплатный публичный use с attribution, только временный caching и запрет платных/закрытых проектов без письменного соглашения.
