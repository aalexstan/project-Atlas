# Веб-сервис курсов валют Банка России

[English version](README.md)

Банк России публикует официальные данные о курсах валют через общедоступные XML web services. Этот профиль охватывает ежедневные курсы и связанные справочники кодов валют.

## Статус исследования

| Поле | Значение |
|---|---|
| Уровень | Verified |
| Последняя проверка | 2026-08-23 |
| Класс продукта | Официальный web service данных центрального банка |
| Протокол | HTTP/HTTPS XML |
| Authentication | Общедоступный доступ; требование credentials для этого маршрута не найдено |
| Live testing | Не проводился |

## Подходит для

- Ежедневной загрузки официальных курсов рубля.
- Финансовых панелей, отчётности и обогащения исторических данных.
- Прототипов, которые умеют работать с XML и принимают feed-подобный интерфейс.

## Границы

Это официальный data web service, а не универсальный market-data API, торговый поток или гарантированный real-time quote service. Rate limits, SLA, change policy и коммерческие права redistribution в этой проверке не подтверждены.
