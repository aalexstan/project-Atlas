# Доказательства

[English version](evidence.md)

- 2GIS указывает, что Routing API строит маршруты на транспорте или пешком: [обзор](https://docs.2gis.com/api/navigation/routing/overview).
- В обзоре описаны маршрут для набора точек и маршруты для нескольких пар начало-конец.
- В официальном обзоре описаны облачный и on-premise варианты.
- История изменений отделяет развитие Routing API от старого Public Transport API: [release notes](https://docs.2gis.com/en/api/navigation/routing/releases).
- Live test Atlas не проводился.
