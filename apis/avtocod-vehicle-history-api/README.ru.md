## Краткий вывод

**Подходит для:** B2B-процессов, которым нужно заказывать и получать отчёты по истории автомобиля после commercial и legal review.

Автокод документирует JSON HTTPS GET/POST, token access, создание/получение отчёта, Swagger UI и публичные схемы отчётов. Не используйте Swagger UI бездумно: вызовы с аккаунтом клиента создают реальные отчёты и списывают баланс.

См. [evidence](evidence.ru.md) и [research log](../../research/vehicle-history/2026-08-23-avtocod.ru.md).
