# Доказательства

[English version](evidence.md)

- Автокод документирует HTTPS GET/POST, JSON responses, base URL и Swagger UI: [обзор](https://b2bapi.avtocod.ru/docs/about/overview).
- Quick start документирует account onboarding, token use, balance checks и создание/получение отчёта: [быстрый старт](https://b2bapi.avtocod.ru/docs/using-api/quick-start).
- Публичны спецификации полей отчёта, JSON Schema и пример: [спецификации](https://b2bapi.avtocod.ru/docs/reference/specs).
- Документированы дневные, месячные и общие квоты, HTTP `402`, frequency limit по report type и HTTP `429`: [квоты](https://b2bapi.avtocod.ru/docs/using-api/quote), [ошибки](https://b2bapi.avtocod.ru/docs/reference/errors).
- Отчёты обычно доступны шесть месяцев; чтение бесплатно, а FORCE regeneration платная. Доставка webhook не гарантируется: [управление отчётами](https://b2bapi.avtocod.ru/docs/using-api/report).
- Публичные B2B-цены включают Автозаполнение за 10 RUB и Автозаполнение плюс за 11 RUB/отчёт, индивидуальные условия от 10 000 отчётов: [тарифы](https://avtocod.ru/for-business-tariffs).
- Avtocod заявляет более 100 источников и продвигает insurance, lending, leasing, integrator и scoring scenarios. Это provider claims, не замена contract/legal review: [данные для бизнеса](https://avtocod.ru/for-business-data), [интеграторам](https://avtocod.ru/for-business-cooperation-integrators).
- Live test или платный отчёт Atlas не выполнялись.
