## Краткий вывод

**Подходит для:** деталей маршрута и матриц расстояний в продукте, ориентированном на Яндекс Карты.

**Нельзя автоматически считать:** этот профиль полноценным optimizer маршрутов транспорта. Яндекс Маршрутизация является отдельным продуктом.

Тариф, traffic behavior, квоты, хранение, кэширование и права показа нужно подтвердить для выбранного продукта и договора.
