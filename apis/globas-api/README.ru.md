## Краткий вывод

**Лучше всего подходит:** организациям, которые рассматривают ГЛОБАС как enterprise-источник данных и хотят получать сведения о контрагентах внутри CRM, ERP, ЭДО, риск-систем, мониторинга портфеля или внутренней аналитики.

**Не подходит как быстрый self-service:** если нужны публичная техническая документация API, прозрачные цены по методам, опубликованные лимиты или подтвержденная sandbox-среда до контакта с поставщиком.

**Итог:** ГЛОБАС.API — реалистичный дополнительный enterprise-кандидат для интеграции контрагентских данных, но пока не reference-grade developer profile. Перед закупкой нужно запросить спецификацию API, модель авторизации, матрицу полей, batch-правила, цены по методам, SLA и права использования данных.

## Что делает продукт

Официальная страница ГЛОБАС.API представляет продукт как способ интегрировать данные ГЛОБАС в корпоративные системы. На странице описаны сценарии: поддержание актуальных данных о контрагентах в базе пользователя, мониторинг изменений портфеля, массовая проверка контрагентов, создание автоматически обновляемой клиентской базы, дополнение собственной базы сведениями о компаниях из ГЛОБАС, обновление по заданным полям, верификация данных, сохранение архивов и автоматическое обновление больших баз данных по контрагентам.

Atlas считает эти утверждения **официальным provider-reported позиционированием**. В проверенных публичных страницах не найден детальный каталог endpoint-ов или schema-level документация.

## Цена и тестовый доступ

В проверенных официальных страницах не найдены публичная API-specific цена, цена метода, batch billing, minimum commitment, overage model или публичный SLA.

На сайте ГЛОБАС есть форма трехдневного тестового доступа к системе ГЛОБАС. Atlas **не считает это API trial**, пока Credinform прямо не подтвердит API credentials, sandbox/API access или эквивалентные условия технического теста.

## Граница продукта

У Credinform есть отдельная официальная страница продукта/модуля «Санкционный комплаенс». Atlas **не предполагает**, что «Санкционный комплаенс» включен в стандартный scope ГЛОБАС.API. Покупателю нужно отдельно запросить границу между:

- стандартным ГЛОБАС.API;
- «Санкционным комплаенсом»;
- «Портфелем» / мониторингом;
- иностранными справками или отчетами;
- кастомной доставкой данных.

## Сильные стороны

- Есть официальная продуктовая страница API.
- Продукт позиционируется для интеграции с корпоративными системами, а не только для ручной работы в веб-интерфейсе.
- Официальные страницы описывают массовую проверку, мониторинг портфеля, обогащение внутренней базы, обновление по полям, верификацию, архивы и обновление больших баз.
- Страницы об источниках ГЛОБАС дают полезный контекст о broader data platform.

## Слабые места и blockers

- Не найден публичный каталог endpoint-ов.
- Не найдены публичные условия авторизации и sandbox.
- Не найдены публичные форматы запросов/ответов и схемы.
- Не найдены публичная цена API, batch billing, лимиты и SLA.
- Права хранения, caching, redistribution, показ данных клиентам, affiliate use, SaaS embedding и model training требуют письменного подтверждения.

## Альтернативы

- **DaData:** более быстрый self-service старт, публичная API-документация и цены для реквизитов и autocomplete.
- **Kontur.Focus API:** основной enterprise shortlist candidate для due diligence, мониторинга и risk controls.
- **Seldon.Basis API:** основной enterprise shortlist candidate для связей, закупочного контекста, CIS coverage и configurable methods.
- **FTS EGRUL/EGRIP integration:** первичный реестровый поток для организаций, которые готовы строить и эксплуатировать собственный ETL.
