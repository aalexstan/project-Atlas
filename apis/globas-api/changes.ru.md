# Изменения профиля ГЛОБАС.API

[English version](changes.md)

| Дата | Изменение | Влияние |
|---|---|---|
| 2026-07-28 | Создан двуязычный API-first профиль по официальным страницам Credinform | Добавляет ГЛОБАС.API как активного reviewed enterprise-кандидата |
| 2026-07-28 | REST-утверждение API Portal сохранено только как legacy provenance | Не повышает вторичный технический claim до verified |
| 2026-07-28 | Публичные API specification, auth, schemas, limits, SLA и API price отмечены как unknown | Делает procurement blockers явными |
| 2026-07-28 | Трехдневный тест системы ГЛОБАС отделен от API trial | Не заявляет live/API test access без доказательств |
| 2026-07-28 | «Санкционный комплаенс» выделен как отдельная граница до подтверждения поставщиком | Не расширяет compliance scope без evidence |

## Следующая обязательная проверка

Цель: после ответа Credinform на provider-request checklist или до **2026-10-28**, если ответа не будет.

## Триггеры ранней проверки

- публикация API specification, OpenAPI/Swagger или developer documentation;
- публикация API pricing, limits, SLA или contract terms;
- подтверждение Credinform о API sandbox/credentials;
- изменение структуры или названия продуктовой страницы;
- подтверждение включения или исключения Sanctions Compliance, Portfolio или foreign reports из стандартного API.
