# Ozon Seller API

[English version](README.md)

Ozon Seller API — интерфейс для продавцов, который позволяет связывать операции Ozon с внешними системами. В проверенных официальных материалах упоминаются процессы продавца вокруг товаров, цен, остатков, заказов, отправлений, поставок, аналитики и финансов.

## Статус исследования

| Поле | Значение |
|---|---|
| Maturity | Reviewed |
| Последняя проверка | 2026-08-23 |
| Класс продукта | API интеграции продавца с маркетплейсом |
| Base URL | `https://api-seller.ozon.ru` |
| Аутентификация | Client ID + API key; OAuth 2.0 для приложений описан в официальных материалах для разработчиков |
| Live testing | Не проводился |

## Для чего подходит

- Синхронизация каталога, цен и остатков продавца.
- Обработка заказов, отправлений, поставок и возвратов.
- Интеграция аналитики и финансовых данных продавца.
- Добавление Ozon как канала к более широкой операционной системе, например MoySklad.

## Границы и уровень уверенности

Это API продавца, а не публичный API поиска товаров для покупателей. Официальная документация доступна по адресу seller API Ozon, но в этом исследовании она не открылась стабильно из-за redirect loop в среде исследования. Поэтому профиль оставлен на уровне `reviewed`, а не `verified`.

Текущие лимиты методов, наличие sandbox, цена API, SLA и права использования данных остаются открытыми. Credentials и живые запросы не использовались.
