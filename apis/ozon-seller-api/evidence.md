# Evidence: Ozon Seller API

[Русская версия](evidence.ru.md)

## Confirmed from official materials

- Ozon maintains an official Seller API documentation route at `docs.ozon.ru/api/seller/`.
- Official Ozon developer materials identify the seller API base URL as `https://api-seller.ozon.ru`.
- Official developer materials describe seller authentication with Client ID and API key.
- Official Ozon developer guidance discusses OAuth token access for applications.
- Official developer-community materials reference seller methods for products, stocks, analytics, orders and postings.

## Confidence limits

- The main documentation route could not be fetched reliably in this review because of a redirect loop in the research environment.
- The complete current method matrix, quotas, sandbox and machine-readable specification were not independently confirmed.
- API pricing, SLA and downstream data rights are unknown.
- No credentials or live requests were used.
