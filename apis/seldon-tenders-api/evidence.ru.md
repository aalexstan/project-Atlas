[English version](evidence.md)

- Seldon описывает API.Seldon.Tenders как веб-сервис программного доступа к закупочным данным и интеграции с CRM: [официальная страница продукта](https://seldongroup.ru/system/1.7/api).

- Общая страница API Seldon описывает order-based модель: клиент заказывает расчёт фильтров и позднее получает результат: [официальная страница](https://seldongroup.ru/system/api).
- В проверенных официальных материалах нет полного публичного endpoint/auth/schema/limits/SLA/price contract.
- Live test Atlas не проводился.
