**Best for:** creating delivery orders, estimating delivery and keeping a customer-facing order status current in a Yandex Delivery workflow.

The official reference documents bearer-token access, order lifecycle, status retrieval, courier-location and ETA operations. Commercial price, quotas, SLA and data rights remain account or contract questions.
