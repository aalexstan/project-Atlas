## Краткий вывод

**Подходит для:** создания заказов, предварительной оценки и поддержания актуального статуса заказа клиента в процессе Яндекс Доставки.

Официальный справочник документирует Bearer-token access, жизненный цикл заказа, получение статуса, локацию курьера и ETA operations. Цена, квоты, SLA и права данных остаются вопросами account или contract.

См. [evidence](evidence.ru.md) и [research log](../../research/delivery-tracking/2026-08-22-yandex-delivery.ru.md).
