## Краткий вывод

**Подходит для:** команд, которым нужен контроль над инфраструктурой маршрутизации и которые готовы поддерживать импорт, обновление OSM и надёжность сервиса.

OSRM не является бесплатным hosted production API. Публичный demo endpoint не является SLA. В документированном API есть route, table, trip, match и nearest services.
