# Evidence: MoySklad JSON API

[English version](evidence.md)

## Подтверждено официальной документацией

- «МойСклад» представляет JSON API как интерфейс интеграции внешних систем и автоматизации бизнес-операций.
- Официальная документация описывает JSON API 1.2 и аутентификацию через Basic Auth или access token.
- На сайте разработчиков указано, что доступ к JSON API бесплатен, работает на тарифах и имеет ограничения на тарифах «Бесплатный» и «Старт».
- API охватывает сущности сервиса «МойСклад», включая товары, остатки, документы и контрагентов.
- «МойСклад» документирует Vendor API и модель серверных решений для создания и публикации приложений для пользователей.

## Не подтверждено

- Точные лимиты выбранного endpoint и тарифа.
- Текущие правила публикации, проверки и коммерческие условия публичного приложения.
- Договорные права хранения данных, SaaS и перераспределения.
- Успешность живого запроса: аккаунт и credentials не использовались.
