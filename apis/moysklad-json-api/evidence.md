# Evidence: MoySklad JSON API

[Русская версия](evidence.ru.md)

## Confirmed from official documentation

- MoySklad presents JSON API as an interface for integrating external systems and automating business operations.
- Official documentation describes JSON API 1.2 and authentication through Basic Auth or an access token.
- The developer site states that JSON API access is free, works across plans and has some restrictions on the Free and Start plans.
- The API covers entities available in the MoySklad service, including products, stock, documents and counterparties.
- MoySklad documents a Vendor API and server-solution model for building and publishing applications for users.

## Not confirmed

- Exact rate limits for a selected endpoint and tariff.
- Current publication, review and commercial terms for a public application.
- Contract-specific data storage, SaaS and redistribution rights.
- Live request success: no account or credentials were used.
