# MoySklad JSON API

[Русская версия](README.ru.md)

MoySklad JSON API is an official integration interface for connecting the MoySklad cloud business system to external applications and automating business workflows. The official developer site describes use with products, stock, orders, documents, counterparties and other entities available in the service.

## Best For

- Connecting an online store or marketplace to inventory and orders.
- Automating catalog, warehouse and document workflows.
- Building dashboards and external business tools for MoySklad users.
- Publishing a reusable integration through the MoySklad application model.

## Why It Is More Useful Than a Narrow Seller API

The profile covers a business system that can be used as the operational core for several sales channels. A future product can connect one company’s website, marketplaces, delivery and reporting tools to a single inventory and document model.

## Boundaries

Official materials state that JSON API access is free and available across plans with some restrictions, but the API is not an unlimited free data source. Exact limits, tariff restrictions, publication rules and commercial terms depend on the account and the integration model. No credentials were obtained and no live request was made.
