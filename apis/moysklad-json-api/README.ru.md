# MoySklad JSON API

[English version](README.md)

MoySklad JSON API — официальный интерфейс интеграции облачной бизнес-системы «МойСклад» с внешними приложениями и автоматизации рабочих процессов. На официальном сайте разработчиков описана работа с товарами, остатками, заказами, документами, контрагентами и другими сущностями сервиса.

## Для чего подходит

- Связать интернет-магазин или маркетплейс с остатками и заказами.
- Автоматизировать каталог, складские и документные процессы.
- Создавать дашборды и внешние бизнес-инструменты для пользователей «МоегоСклада».
- Публиковать повторно используемую интеграцию через модель приложений «МоегоСклада».

## Почему это полезнее узкого seller API

Профиль описывает бизнес-систему, которая может стать операционным ядром для нескольких каналов продаж. Будущий продукт может связать сайт компании, маркетплейсы, доставку и отчётность с единой моделью остатков и документов.

## Границы профиля

Официальные материалы указывают, что доступ к JSON API бесплатен и работает на разных тарифах с некоторыми ограничениями, но API не является безлимитным бесплатным источником данных. Точные лимиты, тарифные ограничения, правила публикации и коммерческие условия зависят от аккаунта и модели интеграции. Credentials не получались, живой запрос не выполнялся.
