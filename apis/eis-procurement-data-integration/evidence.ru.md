# Доказательства

[English version](evidence.md)

- Казначейство России описывает ЕИС / `zakupki.gov.ru` как официальный сайт свободного доступа к информации о закупках и формирования, обработки и хранения этой информации: [официальная страница](https://roskazna.gov.ru/gis/eis-zakupki-gov-ru).
- Казначейство публикует маршрут форматов информационного взаимодействия: [официальная страница](https://roskazna.gov.ru/gis/ehlektronnyj-byudzhet/formaty-informacionnogo-vzaimodejstviya).
- В ЕИС есть раздел технической информации: [официальная страница](https://zakupki.gov.ru/epz/main/public/document/view.html?sectionId=1252).
- Эти источники сами по себе не подтверждают полный public REST API catalog, quotas или authentication.
- Live test Atlas не проводился.
