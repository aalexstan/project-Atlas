# Evidence

[Русская версия](evidence.ru.md)

- The Russian Treasury describes EIS / `zakupki.gov.ru` as an official site for free access to procurement information and for forming, processing and storing that information: [official page](https://roskazna.gov.ru/gis/eis-zakupki-gov-ru).
- The Treasury publishes a route for formats of information interaction: [official page](https://roskazna.gov.ru/gis/ehlektronnyj-byudzhet/formaty-informacionnogo-vzaimodejstviya).
- EIS exposes a technical-information hub: [official page](https://zakupki.gov.ru/epz/main/public/document/view.html?sectionId=1252).
- These sources do not by themselves prove a complete public REST API catalog, quotas or authentication.
- No Atlas live test was performed.
