## Краткий вывод

**Подходит для:** российского бизнеса, который уже использует или рассматривает Т‑Бизнес и хочет связать платежи с сайтом, приложением, CRM или ИТ-системой.

**Нельзя принимать решение без подключения, если:** нужна полностью публичная method-level спецификация, sandbox, таблица квот и SLA до onboarding.

**Итог:** Т‑Банк ясно описывает бизнес-маршрут интеграции и webhooks, но точные условия acquiring API зависят от подключения и настроек магазина.

## Технический доступ

| Поле | Значение |
|---|---|
| Portal | `https://developer.tbank.ru/eacq/` и портал T‑API |
| Интеграция | Интеграция API с сайтом, приложением, CRM и ИТ-системой документирована |
| Webhooks | Статус платежа и другие события T‑API; требуется подключение поставщиком |
| Sandbox | В проверенных публичных материалах неизвестен |
| Аутентификация | Точный contract acquiring API требует подтверждения |
| OpenAPI | В портале есть связанные OpenAPI-материалы; точный набор методов требует подтверждения |

## Возможности

| Возможность | Статус |
|---|---|
| Приём платежей | Документирован |
| Холдирование и подтверждение | Документированы в справке для бизнеса |
| Отмена и возврат | Документированы |
| Рекуррентные платежи | Документированы |
| Платёжные ссылки | Документированы |
| Webhook статуса платежа | Документирован; нужно подключение |
| Остальные банковские операции T‑API | В этот профиль не входят |

## Коммерческие ограничения

В официальной справке указаны отсутствие абонентской платы, индивидуальная комиссия с успешных платежей и фиксированная комиссия за неуспешную авторизацию. Точные ставки и условия бизнеса не являются универсальной ценой API и требуют заявки/договора.

## Рекомендация по сценарию

- Выбирать маршрут, если зачисления и интеграция с расчётным счётом Т‑Банка входят в решение.
- Предпочесть ЮKassa или CloudPayments, если важнее нейтральное сравнение публичных API и более автономная документация для разработчика.
- До разработки получить точный API contract, аутентификацию, quotas, SLA и права использования данных.
