# Доказательства по адресным API DaData

[English version](evidence.md)

| Утверждение | Источник | Проверено | Статус | Примечание |
|---|---|---|---|---|
| Подсказки ищут адреса по любой части адреса и почтовому индексу. | https://dadata.ru/api/suggest/address/ | 2026-07-29 | verified | Сценарий интерактивного ввода. |
| Подсказки покрывают все страны минимум до города; Россию до квартиры; Беларусь, Казахстан и Узбекистан до дома. | https://dadata.ru/api/suggest/address/ | 2026-07-29 | provider_reported | Atlas не проводил независимый benchmark. |
| Подсказки возвращают гранулярные части адреса и поля ФИАС/ГАР/КЛАДР там, где доступны. | https://dadata.ru/api/suggest/address/ | 2026-07-29 | verified | Поля зависят от записи и тарифа. |
| Подсказки не предназначены для автоматической обработки файлов или баз адресов. | https://dadata.ru/api/suggest/address/ | 2026-07-29 | verified | Для автоматической обработки нужна Стандартизация. |
| Endpoint Подсказок: `POST https://suggestions.dadata.ru/suggestions/api/4_1/rs/suggest/address`. | https://dadata.ru/api/suggest/address/ | 2026-07-29 | verified | Аутентификация token. |
| Лимит Подсказок: 30 запросов/секунду с IP и 60 новых соединений/минуту с IP. | https://dadata.ru/api/suggest/address/ | 2026-07-29 | verified | Дневной лимит зависит от тарифа. |
| Стандартизация раскладывает поля, рассчитывает индекс, определяет координаты и возвращает реестровые/налоговые коды; только Россия. | https://dadata.ru/api/clean/address/ | 2026-07-29 | verified | Серверная нормализация. |
| Endpoint Стандартизации: `POST https://cleaner.dadata.ru/api/v1/clean/address`. | https://dadata.ru/api/clean/address/ | 2026-07-29 | verified | Token + `X-Secret`. |
| Стандартизация принимает один адрес в запросе, 20 запросов/секунду с IP и 60 новых соединений/минуту; browser JavaScript не поддерживается. | https://dadata.ru/api/clean/address/ | 2026-07-29 | verified | Secret key должен оставаться на сервере. |
| Прямое геокодирование определяет координаты по адресу и использует endpoint стандартизации; только Россия. | https://dadata.ru/api/geocode/ | 2026-07-29 | verified | Платный per-record сервис. |
| Обратное геокодирование возвращает ближайшие адреса по координатам; только Россия. | https://dadata.ru/api/geolocate/ | 2026-07-29 | verified | Использует Suggestions host и token auth. |
| Подсказки и обратное геокодирование входят в подписку; стандартизация, прямое геокодирование и кадастровый номер стоят 0,20 руб. за адрес вне подписки. | https://dadata.ru/pricing/ | 2026-07-29 | verified | Нельзя смешивать subscription и per-record units. |
| Бесплатный тариф после регистрации похож на «Легкий» и имеет 10 000 запросов/день. | https://dadata.ru/pricing/ | 2026-07-29 | verified | После исчерпания лимита сервисы подписки отключаются до следующего дня. |
| Один ввод адреса в Подсказках обычно тратит 10-30 запросов. | https://dadata.ru/pricing/ | 2026-07-29 | provider_reported | Использовать как предупреждение для расчёта, не как benchmark. |
| DaData сообщает, что данные, обработанные через API стандартизации, не сохраняются; загруженные файлы хранятся до одного дня. | https://dadata.ru/clean/ | 2026-07-29 | provider_reported | Для регулируемых данных подтвердить договором. |
