## Краткий вывод

**Подходит для:** ботов, интерактивных уведомлений, поддержки, chat-интерфейсов и Telegram Mini Apps.

**Не подходит, если:** нужны carrier-grade SMS, доставка по номеру телефона или нейтральный канал уведомлений.

**Итог:** Telegram Bot API — интерфейс платформы, а не замена SMS или универсальному transactional messaging provider.

## Технический доступ

| Поле | Значение |
|---|---|
| Base URL | `https://api.telegram.org/bot<token>/METHOD_NAME` |
| Формат | HTTPS; JSON, form encoding, multipart для файлов |
| Аутентификация | Bot token |
| Updates | Long polling или webhooks |
| Local option | Документирован официальный local Bot API server |
| OpenAPI | В проверенных официальных источниках не найден |

## Рекомендация по сценарию

Выбирать Telegram, если пользователь может сам начать диалог с ботом или вступить в него. Для доставки по номеру телефона и carrier status использовать SMSC или SMS.RU. Документация Bot API не доказывает гарантированную доставку и универсальный охват.
