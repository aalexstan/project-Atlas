# Wildberries Seller API

[English version](README.md)

Wildberries предоставляет API для продавцов, которое позволяет связывать операции маркетплейса с ERP, WMS, OMS и CRM-системами. Официальная документация разделена по категориям сервисов и публикуется в формате Swagger/OpenAPI.

## Статус исследования

| Поле | Значение |
|---|---|
| Maturity | Verified |
| Последняя проверка | 2026-08-23 |
| Класс продукта | API интеграции продавца с маркетплейсом |
| Аутентификация | Учётная запись продавца и API-токен; в инструкции подключения также упоминаются OAuth 2.0 scopes |
| Sandbox | Документирован для поддерживаемых тестовых scopes |
| Live testing | Не проводился |

## Для чего подходит

- Работа с каталогом продавца, ценами и скидками.
- Интеграции аналитики, статистики и продвижения.
- Процессы поставок, возвратов, документов, финансов и операций продавца.
- Подключение данных Wildberries к внутренним ERP/WMS/OMS/CRM-системам.

## Границы профиля

Это интерфейс для интеграции продавца, а не общий публичный API маркетплейса и не API поиска товаров для покупателей. Набор методов зависит от категории сервиса и прав токена. Лимиты зависят от метода; в профиле приведены только примеры, явно видимые в официальной документации.

Цена API, SLA, production-квоты, хранение, встраивание в SaaS и права перераспределения в этом исследовании не подтверждены. Credentials не использовались, живые запросы не выполнялись.
