# Evidence: Wildberries Seller API

[English version](evidence.md)

## Подтверждено официальной документацией

- Wildberries описывает API продавца для интеграции операций продавца с внешними бизнес-системами.
- API предоставляется через REST/HTTP-категории сервисов, а официальная документация доступна в формате Swagger/OpenAPI.
- Для доступа продавцу нужны учётная запись и API-токен; категории токена и права определяют доступ к группам сервисов.
- Для поддерживаемых scopes описана официальная тестовая среда с синтетическими данными, а не с данными реальных продавцов.
- В официальной документации приведены примеры лимитов отдельных методов, включая `ping` и получение информации о продавце. Эти примеры не являются общей квотой для всех методов.

## Не подтверждено

- Цена API, SLA и обязательства поддержки.
- Полный набор методов и полей для конкретной учётной записи продавца.
- Права хранения, SaaS-встраивания, перераспределения и показа клиентам.
- Успешность живого запроса: credentials не использовались.
