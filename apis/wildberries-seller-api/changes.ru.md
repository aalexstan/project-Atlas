# Изменения и открытые вопросы

[English version](changes.md)

## 2026-08-23

- Добавлен первый профиль Atlas для API интеграции продавца Wildberries.
- Зафиксированы официальные сведения о REST/HTTP, Swagger/OpenAPI, токенах, sandbox и примерах лимитов отдельных методов.
- Цена API, SLA, production-квоты и права использования данных оставлены неизвестными до получения условий для конкретного сценария.
- Live testing по-прежнему не проводился.

## Следующая проверка

- Получить scope нужной учётной записи продавца и матрицу методов.
- Запросить или проверить production-цены, квоты, SLA, поддержку и права использования данных.
- Проводить тест только с разрешёнными credentials и синтетическими либо допустимыми данными.
