## Краткий вывод

**Лучше всего подходит для:** приложений, которым нужно преобразовывать адрес в координаты или координаты в адрес и которые могут соблюдать условия показа, хранения и лицензирования Яндекс Карт.

**Не подходит, когда:** нужна нормализация адресов, реестровая валидация, поиск организаций, адресные подсказки, маршрутизация или offline/bulk enrichment без явных коммерческих прав.

**Итог:** Yandex Maps Geocoder - настоящий документированный геокодер с публичными тарифами и понятными ограничениями бесплатного использования. Сравнивать его нужно как геокодер, а не как полный продукт очистки адресов или официальный реестр.

## Граница продукта

Yandex Geocoder покрывает:

- прямое геокодирование: адрес/название -> координаты;
- обратное геокодирование: координаты -> адрес;
- metadata и precision геокодера.

В эту карточку не входят:

- адресные подсказки: это [`Yandex Maps Geosuggest API`](../yandex-maps-geosuggest-api/README.ru.md);
- поиск организаций и мест: это отдельные поисковые продукты Яндекса;
- маршрутизация, оптимизация маршрутов и distance matrix.

## Сценарии

| Сценарий | Fit | Почему |
|---|---|---|
| Показать известный адрес на карте Яндекса | Strong | Прямое геокодирование - основной документированный сценарий. |
| Найти адрес рядом с точкой на карте | Strong | Обратное геокодирование прямо описано в документации. |
| Коммерческий картографический продукт с лицензированным хранением | Medium | Есть Standard и Extended лицензии; конкретный договор нужно проверять. |
| Нормализация адресов перед импортом в CRM | Weak | Geocoder возвращает геокодинговые metadata, а не полный workflow очистки. |
| Реестровая валидация адреса | Weak | Precision геокодера не равен проверке адреса по официальному реестру. |
| Поиск организаций и мест | Not in scope | Нужны отдельные продукты поиска Яндекса. |
| Маршрутизация | Not in scope | Routing API отделены. |

## Технический доступ

| Поле | Значение |
|---|---|
| Протокол | HTTP GET |
| Endpoint | `https://geocode-maps.yandex.ru/v1` |
| Обязательные параметры | `apikey`, `geocode`, `lang` |
| Аутентификация | API key в query-параметре `apikey` |
| Формат ответа | JSON |
| Прямое геокодирование | Адрес/название в `geocode` |
| Обратное геокодирование | Координаты в `geocode`; опционально `kind` |
| Количество результатов | По умолчанию 10, максимум 50 |
| Ошибки | 400, 403, 429 |
| TLS | Клиент должен поддерживать SNI |
| OpenAPI / Swagger | Не найден в публичных docs |

## Коммерческие и правовые заметки

- Бесплатные условия привязывают Геокодер к показу на Яндекс Картах и запрещают показ результатов на сторонних картах.
- Общие условия Maps API ограничивают хранение, обработку и изменение данных сервиса, кроме ограниченного временного кэширования, если иное не согласовано.
- Тарифная страница различает Standard и Extended; права хранения нужно подтверждать в подписанном договоре.
- Bulk/offline geocoding, SaaS embedding и redistribution требуют явного коммерческого подтверждения.

## Альтернативы

| Альтернатива | Когда лучше | Главный trade-off |
|---|---|---|
| [`DaData Address APIs`](../dadata-address-api/README.ru.md) | Нужны российские подсказки адреса и серверная стандартизация | Фокус на России; прямое геокодирование оплачивается per-record. |
| [`Yandex Maps Geosuggest API`](../yandex-maps-geosuggest-api/README.ru.md) | Пользовательскому вводу нужны подсказки адресов/геообъектов Яндекса до геокодирования | Это autocomplete, не direct/reverse geocoding. |
| [`2GIS Geocoder API`](../2gis-geocoder-api/README.ru.md) | Продукт строится вокруг карты/каталога 2GIS | Places и Suggest - отдельные продукты; кэширование нужно проверять. |
| [`FIAS/GAR Data Integration`](../fias-gar-data-integration/README.ru.md) | Цель - собственная официальная адресная база РФ | Нужны ETL и инфраструктура поиска/индекса. |

## Рекомендация по сценарию

Выбирайте Yandex Geocoder, когда геокодирование естественно связано с показом на Яндекс Картах и лицензия подходит вашей модели хранения/показа. Если задача в качестве адреса, канонических полях или владении адресной базой, смотрите API нормализации или интеграцию с реестром.
