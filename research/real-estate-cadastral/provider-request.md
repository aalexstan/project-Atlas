# Rosreestr and Roskadastr Integration Clarification

[Русская версия](provider-request.ru.md)

Please clarify the supported integration options for a commercial information service:

1. Does `Request via access to FGIS EGRN` support unattended integration or only personal-account use?
2. Is there an officially supported API and method catalog for non-government legal entities?
3. How are access keys issued, authenticated, rotated and revoked?
4. Which extract types and fields are available through package access?
5. What prices, validity periods, quotas, concurrency and rate limits apply?
6. What SLA, support and schema-change notice apply?
7. Which NSPD services are documented for external automated use?
8. Which JSON, XML and CSV schemas and versions are supported?
9. Which interfaces are limited to government, inter-agency or SMEV participants?
10. May outputs be stored, cached, indexed, enriched and shown to customers?
11. Are SaaS, redistribution, resale, valuation, scoring and model training permitted?
12. Which personal-data, restricted-information, attribution and audit rules apply?
