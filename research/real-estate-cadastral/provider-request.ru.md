# Уточнение интеграции с Росреестром и Роскадастром

[English version](provider-request.md)

Просим уточнить supported integration options для commercial information service:

1. Поддерживает ли `Запрос посредством доступа к ФГИС ЕГРН` unattended integration или только personal-account use?
2. Есть ли officially supported API и method catalog для негосударственных юридических лиц?
3. Как выдаются, аутентифицируются, ротируются и отзываются access keys?
4. Какие типы выписок и поля доступны через package access?
5. Какие prices, validity periods, quotas, concurrency и rate limits действуют?
6. Какие SLA, support и schema-change notice предусмотрены?
7. Какие сервисы НСПД документированы для external automated use?
8. Какие JSON, XML и CSV schemas и versions поддерживаются?
9. Какие interfaces доступны только для government, inter-agency или СМЭВ participants?
10. Можно ли outputs хранить, кэшировать, индексировать, обогащать и показывать клиентам?
11. Разрешены ли SaaS, redistribution, resale, valuation, scoring и model training?
12. Какие personal-data, restricted-information, attribution и audit rules действуют?
