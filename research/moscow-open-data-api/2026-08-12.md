## Findings

### Verified Facts:
- API endpoints: `/v1/datasets/{id}/features` and `/v1/features/{id}`
- Supported query parameters: `$top`, `$skip`, `versionNumber`, `releaseNumber`, `bbox`
- Response format: FeatureCollection with GeoJSON features, each feature containing geometry (Point) and properties including datasetId, versionNumber, releaseNumber, rowId, and Attributes (key-value pairs)
- Default response limit: 1000 records; for larger datasets, use `$skip` and `$top` parameters
- Can get record count via `/datasets/{id}/count` endpoint
- Example use case demonstrated: accessing dataset of outdoor ice rinks
- API access requires unique API key obtained through authorization/registration in personal cabinet
- "Try API" section allows exploring API methods without obtaining personal API key
- API key usage statistics available in developer cabinet
- All materials on data.mos.ru are open data per Russian Government Resolution No. 583 from July 10, 2013
- Materials can be reproduced in any media or internet without volume or time limitations
- License: Creative Commons Attribution 4.0 International (CC BY 4.0) with requirement to link to primary source
- Technical support contact: opendata@mos.ru
- Data request contact: Хунас Амин Касиевич
