# Moscow Open Data API Research Log — 2026-07-29

## Scope

This research log checks whether the legacy Moscow Open Data API material is ready to become an active API-first Atlas profile.

Legacy material reviewed:

- [catalog/api-open-data-moscow.md](../../catalog/api-open-data-moscow.md)
- [datasets/moscow_city_open_data.md](../../datasets/moscow_city_open_data.md)
- [providers/government_of_moscow.md](../../providers/government_of_moscow.md)
- [access_methods/moscow_city_open_data_access.md](../../access_methods/moscow_city_open_data_access.md)

Official URLs attempted:

- https://data.mos.ru/
- https://data.mos.ru/developers/documentation
- https://data.mos.ru/opendata/60562

API Portal was treated only as legacy discovery context, not as final source of truth.

## Result

Do not create an active API-first profile in this pass.

## Findings

| Finding | Status | Evidence |
|---|---|---|
| Legacy Atlas material identifies `data.mos.ru` as the Moscow open-data portal and `data.mos.ru/developers/documentation` as API documentation | legacy_reported | Legacy Atlas cards and API Portal discovery context |
| Current official documentation content was not accessible during this pass | observed | Attempts to open official `data.mos.ru` URLs timed out or did not return usable documentation content in the available environment |
| Current official endpoint, authentication, response formats, current operational status, limits and reuse terms could not be verified | unknown | Official documentation unavailable in this pass |

## Required Evidence for an Active Profile

Atlas should create an active API profile only after official materials confirm:

- official current product identity;
- active official endpoint or documentation;
- authentication model;
- supported request and response formats;
- API purpose and intended use;
- current product/service status;
- license or reuse terms;
- sufficient official evidence for at least Verified maturity.

## Blockers

- Official developer documentation was not accessible.
- Current endpoint and authentication were not confirmed.
- Current formats were not confirmed.
- Current status was not confirmed.
- Current limits, quotas, SLA and support process were not confirmed.
- Reuse terms for commercial, SaaS, redistribution, storage and model-training scenarios were not confirmed.

## Editorial Decision

Keep the Moscow Open Data API material as legacy/supporting research for now. Do not rely on API Portal or old Atlas cards as final truth. Reopen the profile only after `data.mos.ru` or another official Moscow Government source provides accessible current API documentation.
