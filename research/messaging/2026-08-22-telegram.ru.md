# Исследование Telegram Bot API

[English version](2026-08-22-telegram.md)

## Область проверки

Проверка официального Telegram Bot API для ботов, интерактивных уведомлений, webhooks и Mini Apps.

## Подтверждённые факты

- Telegram Bot API — HTTPS-интерфейс для ботов с JSON-ответами.
- Запросы используют bot token в URL; токен нужно хранить в секрете.
- Updates можно получать через long polling или webhooks; режимы взаимоисключающие.
- API поддерживает сообщения, клавиатуры, медиа, команды, платежи и другие операции бота.
- Документирован локальный Bot API server с другими возможностями файлов и webhooks.
- Бот не может сам начать диалог с пользователем: пользователь должен сначала взаимодействовать с ботом или добавить его.

## Unknowns и блокеры

- Production limits и условия paid broadcasts.
- Retention, customer display, SaaS и compliance для конкретного сценария.
- Доставка Telegram-сообщения не равна гарантии доставки SMS оператора.
