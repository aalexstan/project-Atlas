# Исследование API SMS.RU

[English version](2026-08-22-smsru.md)

## Область проверки

Проверка официального API SMS.RU для SMS, проверки стоимости и баланса, статусов доставки, лимитов, sender names, callbacks и голосовой авторизации.

## Подтверждённые факты

- SMS.RU публикует HTTP API для SMS и связанных операций.
- Официальные документы описывают отправку, стоимость, баланс, статусы, регистрацию sender, дневные лимиты, webhooks и голосовую авторизацию.
- В документации отправки указан HTTPS endpoint и паттерн запроса с API identifier/token.
- На официальной странице указано обновление документации 23.06.2026.

## Unknowns и блокеры

- Актуальные цены операторов, throughput, sender approval, delivery SLA, DLR timing и production contract.
- Retention, персональные данные, opt-out и enterprise support для конкретного аккаунта.
