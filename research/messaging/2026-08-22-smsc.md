# SMSC API Research Log

[Русская версия](2026-08-22-smsc.ru.md)

## Scope

Review the official SMSC API for SMS, OTP/verification messages, delivery status, cost checks, and callbacks.

## Official sources reviewed

- https://smsc.ru/api/http/
- https://smsc.ru/api/smtp/
- https://smsc.ru/api/smpp/

## Confirmed facts

- SMSC documents HTTP/HTTPS, SMTP and SMPP integration routes.
- The HTTP documentation provides send endpoints including `https://smsc.ru/rest/send/`.
- Authentication can use login/password or an API key.
- The API documentation describes sending messages, checking cost and status, and working with callbacks.
- The documentation describes message length and multi-part SMS behavior.

## Provider-reported claims

- SMSC presents its API as a route for sending messages from projects and services.

## Unknowns and blockers

- Current country/operator price matrix, sender approval, throughput, delivery SLA and DLR semantics for a production account.
- Data processing, retention, opt-out, sender-name and regulated OTP requirements for a specific use case.

## Live testing

Not performed. No credentials or phone numbers are stored.

## Decision

Create an active reviewed profile as an SMS gateway route, with pricing and carrier delivery terms left open.
