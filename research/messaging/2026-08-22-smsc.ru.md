# Исследование API SMSC

[English version](2026-08-22-smsc.md)

## Область проверки

Проверка официального API SMSC для SMS, OTP, статусов доставки, проверки стоимости и callbacks.

## Подтверждённые факты

- SMSC документирует HTTP/HTTPS, SMTP и SMPP-маршруты.
- HTTP-документация указывает endpoint отправки `https://smsc.ru/rest/send/`.
- Доступна аутентификация login/password или API key.
- Документация описывает отправку, проверку стоимости и статуса, а также callbacks.
- Описаны длина сообщения и разбиение длинного SMS.

## Unknowns и блокеры

- Актуальные цены по странам/операторам, sender approval, throughput, delivery SLA и DLR для production.
- Обработка данных, retention, opt-out, имя отправителя и требования к OTP.
