# Telegram Bot API Research Log

[Русская версия](2026-08-22-telegram.ru.md)

## Scope

Review the official Telegram Bot API for bots, interactive notifications, webhooks, and Mini App entry points.

## Official sources reviewed

- https://core.telegram.org/bots/api
- https://core.telegram.org/bots
- https://core.telegram.org/bots/tutorial
- https://core.telegram.org/api/bots/webapps

## Confirmed facts

- Telegram Bot API is an HTTPS interface for bots and returns JSON responses.
- Requests use a bot token in the API URL; tokens must be kept secret.
- Updates can be received through long polling or webhooks; these modes are mutually exclusive.
- The API supports sending messages, keyboards, media, commands, payments, and other bot operations.
- Telegram documents a local Bot API server option with different file and webhook capabilities.
- Telegram bots cannot start a conversation with a user; a user must interact with or add the bot first.

## Provider-reported claims

- Telegram describes the bot platform as free for users and developers, while some higher-volume or business features may have separate conditions.

## Unknowns and blockers

- Production message limits by scenario and current paid-broadcast conditions.
- Data retention, customer-facing display, commercial SaaS and jurisdiction-specific compliance for a particular use case.
- Delivery guarantees are not equivalent to SMS carrier delivery guarantees.

## Live testing

Not performed. No token or user data is stored.

## Decision

Create an active reviewed profile as a bot platform API, not as a generic transactional messaging provider.
