# SMS.RU API Research Log

[Русская версия](2026-08-22-smsru.ru.md)

## Scope

Review the official SMS.RU API for SMS sending, cost and balance checks, delivery status, limits, sender names, callbacks, and voice verification.

## Official sources reviewed

- https://sms.ru/docs/api
- https://sms.ru/docs/api/api_group_sms/send
- https://sms.ru/docs/api/api_group_sms/status
- https://sms.ru/docs/api/api_group_webhook

## Confirmed facts

- SMS.RU provides HTTP API documentation for SMS sending and related operations.
- Official docs describe sending, cost checks, balance, message status, sender registration, daily-limit information, webhooks and voice authorization flows.
- The send documentation provides an HTTPS endpoint and API identifier/token-based request pattern.
- The documentation was updated on 2026-06-23 according to the official page.

## Provider-reported claims

- SMS.RU describes the API as a developer integration route for automated SMS and verification workflows.

## Unknowns and blockers

- Current operator pricing, throughput, sender approval, delivery SLA, DLR timing and contract terms for production.
- Data retention, personal-data processing, opt-out and enterprise support terms for a particular account.

## Live testing

Not performed. No API identifiers, phone numbers, or personal data are stored.

## Decision

Create an active reviewed profile as a Russian SMS and verification API route.
