# 2GIS Routing API research

## Scope

Проверка официального Routing API 2ГИС. Suggest, Places, Geocoder и отдельные навигационные продукты не объединяются с маршрутизацией.

## Official sources reviewed

- [Routing API overview](https://docs.2gis.com/api/navigation/routing/overview)
- [Routing API release notes](https://docs.2gis.com/en/api/navigation/routing/releases)
- [Route planner reference](https://docs.2gis.com/en/api/navigation/route-planner/reference/route-planner)
- [2GIS API platform for server](https://docs.2gis.com/api/navigation/routing/overview)

## Confirmed facts

- Routing API строит маршруты на транспорте или пешком.
- Для немассового общественного транспорта и остальных способов движения документация описывает отдельные endpoints, включая `/routing/7.0.0/global`.
- API поддерживает маршрут для набора точек и несколько пар начальных/конечных точек; это закрывает сценарий матрицы/пар, но не доказывает полноценную оптимизацию delivery routes.
- Документация указывает облачный вариант через публичные endpoints и on-premise вариант через API-платформу 2ГИС.
- Для доступа используется ключ разработчика; тарифы и лимиты следует сверять в актуальной инструкции и договоре.

## Unknowns and blockers

- Не подтверждены единый public SLA, batch billing, storage/caching, redistribution, SaaS и customer-facing display rights.
- Не проводился credentialed live test; точность, latency, traffic and truck benchmark отсутствуют.
- Route Planner и базовый Routing API могут иметь разные коммерческие границы; их нельзя считать одним продуктом.

## Decision

Создать reviewed profile `2gis-routing-api` для базового Routing API. Route Planner, Suggest, Places и Geocoder оставить отдельными related products.
