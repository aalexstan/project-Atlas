# Исследование 2GIS Routing API

[English version](2026-08-22-2gis.md)

## Область

Проверка официального Routing API 2ГИС. Suggest, Places, Geocoder и отдельные навигационные продукты не объединяются с маршрутизацией.

## Проверенные официальные источники

- [Обзор Routing API](https://docs.2gis.com/api/navigation/routing/overview)
- [История изменений Routing API](https://docs.2gis.com/en/api/navigation/routing/releases)
- [Справочник Route Planner](https://docs.2gis.com/en/api/navigation/route-planner/reference/route-planner)

## Подтверждённые факты

- Routing API строит маршруты на транспорте или пешком.
- Документация описывает маршрут для набора точек и несколько пар начальных/конечных точек.
- Указаны облачный вариант через публичные endpoints и on-premise вариант через API-платформу 2ГИС.
- Для доступа используется ключ разработчика; тарифы и лимиты нужно сверять в актуальной инструкции и договоре.

## Неизвестные параметры и блокеры

- Не подтверждены единый public SLA, batch billing, storage/caching, redistribution, SaaS и customer-facing display rights.
- Credentialed live test не проводился; benchmark точности, latency, traffic и truck-сценариев отсутствует.
- Route Planner и базовый Routing API могут иметь разные коммерческие границы.

## Решение

Создать reviewed profile `2gis-routing-api` для базового Routing API. Route Planner, Suggest, Places и Geocoder оставить отдельными related products.
