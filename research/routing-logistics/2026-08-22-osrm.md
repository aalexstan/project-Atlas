# OSRM research

## Scope

Проверка OSRM как open-source routing engine и его HTTP/API surface. Публичный demo endpoint не рассматривается как production commitment.

## Official sources reviewed

- [OSRM API documentation](https://project-osrm.org/docs/)
- [OSRM HTTP server](https://project-osrm.org/docs/v26.4.0/http)
- [OSRM Node.js API](https://project-osrm.org/docs/v26.4.0/nodejs/api)
- [OSRM routed service](https://project-osrm.org/docs/v26.4.0/routed)

## Confirmed facts

- OSRM предоставляет route, table, match, trip, nearest и tile services через HTTP API.
- Table service возвращает матрицы времени и расстояния; Trip service помогает упорядочивать stops в round trip.
- Self-hosting требует подготовки `.osrm.*` dataset из OSM PBF и эксплуатации routed service/data pipeline.
- Параметры маршрутизации зависят от profile и подготовленных данных; это не hosted commercial API with provider SLA.

## Unknowns and blockers

- Нет единой публичной коммерческой цены, SLA или hosted production guarantee в upstream OSRM documentation.
- Остаются операционные вопросы: импорт и обновление OSM data, hardware, monitoring, privacy, licensing and attribution.
- Не проводился live test; публичный demo endpoint не является доказательством production suitability.

## Decision

Создать profile `osrm-routing-engine` с product class `open_source_routing_engine`. Сценарий рекомендовать командам, готовым владеть инфраструктурой и OSM data operations.
