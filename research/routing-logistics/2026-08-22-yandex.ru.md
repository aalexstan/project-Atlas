# Исследование маршрутизации Yandex Maps

[English version](2026-08-22-yandex.md)

## Область

Проверка официальных API Яндекс Карт для построения маршрутов и расчёта расстояний. Геокодер, Геосаджест, поиск организаций и отдельная система Яндекс Маршрутизация рассматриваются как соседние продукты.

## Проверенные официальные источники

- [Документация API Яндекс Карт](https://yandex.ru/maps-api/docs)
- [Получение деталей маршрута](https://yandex.ru/maps-api/docs/ru/concepts/route-details)
- [Матрица расстояний](https://yandex.ru/maps-api/docs/ru/concepts/matrix)
- [Документация Яндекс Маршрутизации](https://yandex.ru/routing/doc/ru/)

## Подтверждённые факты

- Документация API Карт отдельно перечисляет получение деталей маршрута и матрицу расстояний.
- Маршрутные результаты требуют координат или иных входных точек; геокодирование остаётся отдельной задачей.
- Яндекс Маршрутизация описывается как отдельная система для автоматизированного планирования логистических задач, мониторинга и экспресс-доставки.
- В публичной документации, проверенной для этого research log, не подтверждены единые публичные тарифы, SLA, production RPS, права долговременного хранения и offline/bulk использования для целевого сценария.

## Неизвестные параметры и блокеры

- Нужно зафиксировать конкретный продукт и договор: Maps API route details/matrix или Yandex Routing.
- Не подтверждены единые условия кэширования, показа клиентам, redistribution, SaaS и построения маршрутов вне карты Яндекса.
- Credentialed live test не проводился; качество, latency, traffic semantics и ограничения для грузового транспорта не измерялись.

## Решение

Создать reviewed profile для Yandex Maps Routing API как сценарного API деталей маршрута и матрицы расстояний. Не выдавать его за полноценный optimizer маршрутов транспорта и не смешивать с системой Яндекс Маршрутизация.
