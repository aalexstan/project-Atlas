# Исследование OSRM

[English version](2026-08-22-osrm.md)

## Область

Проверка OSRM как open-source routing engine и его HTTP/API surface. Публичный demo endpoint не рассматривается как production commitment.

## Проверенные официальные источники

- [Документация OSRM API](https://project-osrm.org/docs/)
- [HTTP server OSRM](https://project-osrm.org/docs/v26.4.0/http)
- [Node.js API OSRM](https://project-osrm.org/docs/v26.4.0/nodejs/api)
- [Сервис osrm-routed](https://project-osrm.org/docs/v26.4.0/routed)

## Подтверждённые факты

- OSRM предоставляет route, table, match, trip, nearest и tile services через HTTP API.
- Table service возвращает матрицы времени и расстояния; Trip service помогает упорядочивать stops в round trip.
- Self-hosting требует подготовки `.osrm.*` dataset из OSM PBF и эксплуатации routed service/data pipeline.
- Параметры маршрутизации зависят от profile и подготовленных данных; это не hosted commercial API с SLA поставщика.

## Неизвестные параметры и блокеры

- В upstream-документации нет единой публичной коммерческой цены, SLA или hosted production guarantee.
- Остаются операционные вопросы: импорт и обновление OSM data, hardware, monitoring, privacy, licensing и attribution.
- Live test не проводился; публичный demo endpoint не доказывает production suitability.

## Решение

Создать profile `osrm-routing-engine` с product class `open_source_routing_engine`. Рекомендовать его командам, готовым владеть инфраструктурой и OSM data operations.
