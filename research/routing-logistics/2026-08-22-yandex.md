# Yandex Maps routing research

## Scope

Проверка официальных API Яндекс Карт для построения маршрутов и расчёта расстояний. Геокодер, Геосаджест, поиск организаций и отдельная система Яндекс Маршрутизация рассматриваются как соседние продукты.

## Official sources reviewed

- [Yandex Maps API documentation](https://yandex.ru/maps-api/docs)
- [Route details](https://yandex.ru/maps-api/docs/router-api/index.html)
- [Distance matrix](https://yandex.ru/maps-api/docs/distancematrix-api/index.html)
- [Yandex Routing documentation](https://yandex.ru/routing/doc/ru/)

## Confirmed facts

- Документация API Карт отдельно перечисляет получение деталей маршрута и матрицу расстояний.
- Маршрутные результаты требуют координат или иных входных точек; геокодирование остаётся отдельной задачей.
- Яндекс Маршрутизация описывается как отдельная система для автоматизированного планирования логистических задач, мониторинга и экспресс-доставки.
- В публичной документации, проверенной для этого research log, не подтверждены единые публичные тарифы, SLA, production RPS, права долговременного хранения и offline/bulk использования для целевого сценария.

## Provider-reported claims

- Яндекс сообщает о планировании маршрутов с большим числом параметров и отдельных сервисах мониторинга/экспресс-доставки в документации Яндекс Маршрутизации.

## Unknowns and blockers

- Нужна фиксация конкретного продукта и договора: Maps API route details/matrix или Yandex Routing.
- Не подтверждены единые условия кэширования, customer-facing display, redistribution, SaaS и построения маршрутов вне карты Яндекса.
- Не проводился credentialed live test; качество, latency, traffic semantics и truck restrictions не измерялись.

## Decision

Создать reviewed profile для Yandex Maps Routing API как сценарного API деталей маршрута и матрицы расстояний. Не выдавать его за полноценный vehicle-routing optimizer и не смешивать с системой Яндекс Маршрутизация.
