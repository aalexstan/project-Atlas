# OpenCage Geocoding API Research Log — 2026-07-29

## Scope

This research checks whether OpenCage Geocoding API should become an active Atlas API profile as an additional hosted open-data geocoding route.

It covers product boundary, official docs, pricing, authentication, rate limits, storage/caching wording, source licenses, batch boundaries and open questions.

It does not perform credentialed requests, spreadsheet uploads, live testing, benchmark, contract review or legal review.

## Confirmed Facts

| Fact | Status | Evidence |
|---|---|---|
| OpenCage publishes a Geocoding API product with worldwide forward and reverse geocoding based on open data. | verified | Official API docs |
| Authentication uses an API key in the `key` query parameter. | verified | Official API docs |
| Current API version is `v1`; request pattern is `https://api.opencagedata.com/geocode/VERSION/FORMAT?parameters`. | verified | Official API docs |
| Supported response formats include JSON, GeoJSON, XML and Google-compatible JSON. | verified | Official API docs |
| Free trial is 2,500 requests/day and 1 request/second for testing. | verified | Official pricing/docs |
| Paid pricing examples and limits are public on the pricing page. | verified | Official pricing page |
| The reviewed pricing page displayed prices in `zł`; Atlas did not convert currencies. | verified | Official pricing page as rendered in this pass |
| OpenCage says API results can be cached/stored permanently. | provider_reported | Official API docs and pricing FAQ |
| Terms require users to respect returned data licenses, especially OpenStreetMap ODbL. | verified | Terms and credits pages |
| Geocoding API is not fuzzy autocomplete; OpenCage points autocomplete/typeahead users to Geosearch. | verified | Official API docs |
| API does not allow multiple locations per request. | verified | Official API docs |
| OpenAPI specification link exists in official docs. | observed | Atlas did not download/test the spec |

## Provider-Reported Claims

- Worldwide coverage and open-data geocoding quality.
- Permanent storage-friendly positioning.
- High-volume operation through parallel requests and paid plan tiers.
- Custom enterprise limits, terms and SLAs.

## Unknowns and Blockers

- ODbL, attribution and derived-database implications for the target buyer's exact use case.
- Redistribution, resale, API proxying, white-label SaaS and affiliate-use rights.
- Exact enterprise SLA/support terms and incident communication.
- Benchmark quality for target geographies, languages, house-level precision, false positives and latency.
- DPA/security details for customer-specific address and coordinate data.
- Whether OpenCage Geosearch should be evaluated as a separate autocomplete product.
- Fit of one-location-per-request model for large batch procurement workflows.

## Contradictions or Cautions

- Storage wording is favorable, but terms still assign responsibility for data-license compliance to users.
- Public pricing is official API pricing, but displayed currency may vary by environment; Atlas records the reviewed display without conversion.
- Free trial is for testing, not a production free tier.
- OpenCage geocoding and Geosearch/autosuggest are separate product boundaries.

## Live Testing Status

No credentialed request, benchmark, spreadsheet upload or live API test was performed.

## Profile Decision

Create active profile `apis/opencage-geocoding-api/` at `reviewed` maturity. OpenCage has enough official evidence for product identity, API boundary, authentication, formats, public pricing, limits and key rights notes. Keep legal review, benchmarks, SLA and redistribution/SaaS rights as blockers.
