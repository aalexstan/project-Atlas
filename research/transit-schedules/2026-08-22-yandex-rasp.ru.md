# Исследование API Яндекс Расписаний

[English version](2026-08-22-yandex-rasp.md)

## Область

Проверка официального API Яндекс Расписаний для междугородних расписаний пассажирского транспорта. City routing, city stops и real-time public transport - отдельные задачи.

## Подтверждённые факты

- API даёт программный доступ к данным о маршрутах и расписании междугороднего пассажирского транспорта.
- API работает в REST-подобной модели через HTTPS GET и возвращает JSON или XML.
- Нужен активированный API key, передаваемый как `apikey` или в заголовке Authorization.
- Документированы списки станций, расписание по станции и рейсы между станциями; JSON списка станций около 40 MB.
- Документация рекомендует перейти с `api.rasp.yandex.net` на `api.rasp.yandex-net.ru`, потому что доступность старого домена не гарантируется.
- Проверенные условия разрешают использование только в бесплатных публично доступных сайтах или мобильных приложениях, требуют attribution и ограничивают хранение/обработку/изменение данных, кроме временного кэша.

## Неизвестные параметры и блокеры

- Не подтверждены public quotas, production SLA, support commitment и коммерческие условия за пределами опубликованных free-use terms.
- API key, live call и benchmark качества расписаний не использовались.

## Решение

Создать reviewed-профиль для бесплатных публичных функций расписаний. Не рекомендовать его для платного/закрытого SaaS или долгосрочной базы расписаний без письменного соглашения с Yandex.
