# Исследование: риск ссылок документации в API Portal

Дата исследования: 2026-06-23
Статус: первичное исследование риска

## Цель

Зафиксировать случаи, когда ссылка на документацию из API Portal не может быть сразу принята как надежный официальный источник.

## Подтвержденные наблюдения

### Seldon

- API Portal указывает `http://www.api-seldon.ru/` как документацию для API Seldon.Basis и API Seldon.Tenders.
- При проверке домен был перенаправлен/открыл нерелевантный контент с заголовком про онлайн-казино.
- Вывод: ссылка требует повторной проверки, а карточки Seldon нельзя переводить в статус `проверено` без официального сайта Seldon или актуального документа.

### ФИАС / KLADR API

- API Portal указывает `https://kladr-api.ru/docs` как документацию для API ФИАС.
- При проверке корневого домена `kladr-api.ru` был обнаружен нерелевантный контент.
- Вывод: связь этого домена с официальным ФИАС или актуальным адресным API не подтверждена.

### Портал открытых данных Москвы

- API Portal указывает `https://data.mos.ru/developers/documentation`.
- В этом запуске прямая проверка документации завершилась таймаутом.
- Вывод: ссылка выглядит официальной по домену `data.mos.ru`, но требуется повторная проверка доступности и условий API.

## Рекомендации

- Для каждой карточки API хранить поле `статус документации`.
- Не считать ссылку официальной только потому, что она опубликована в каталоге.
- Проверять домен, владельца, HTTPS, редиректы и актуальность страницы.
- Для сомнительных ссылок искать официальный сайт компании, GitHub, OpenAPI/Swagger или документы в личном кабинете поставщика.

## Следующие действия

- Найти официальный сайт Seldon через независимые официальные источники.
- Найти актуальную документацию Seldon.Basis и Seldon.Tenders.
- Найти официальный источник ФИАС и условия доступа к адресным данным.
- Повторно проверить `data.mos.ru/developers/documentation`.
