# 2GIS Search APIs Research Log

## Scope

This log reviews 2GIS Geocoder API as the address/geocoding candidate and records product boundaries with 2GIS Places API and Suggest API.

## Confirmed Facts

| Fact | Status | Evidence |
|---|---|---|
| 2GIS Geocoder API performs direct and reverse geocoding. | verified | Geocoder API overview |
| The documented request model is HTTP GET with query parameters and JSON response. | verified | Geocoder API overview |
| Example endpoint uses `https://catalog.api.2gis.com/3.0/items/geocode` with `q` for direct geocoding or `lat`/`lon` for reverse geocoding and `key=YOUR_KEY`. | verified | Geocoder API overview |
| Access requires a 2GIS Platform key; users can create a demo key or buy a subscription through Platform Manager. | verified | Search overview and key management docs |
| Search service billing is based on successful requests; successful API request status is represented by `meta.code` 200 or 204. | verified | Pricing and billing docs |
| Geocoder API public prices are published by package size, starting at 10,000 units. | verified | Pricing and billing docs |
| Search APIs have a published per-minute limit of 600 units for Places, Geocoder, Suggest, Categories, Regions and Markers. | verified | Pricing and billing docs |
| Demo keys have a total Search-service request limit of 1,000 for Places, Geocoder, Suggest, Categories, Regions and Markers. | verified | Pricing and billing docs |
| Places API is the product for searching organizations, buildings and places by a range of criteria. | verified | Places API overview and subscription services docs |
| Suggest API is a separate product for real-time suggestions while a search request is typed. | verified | Subscription services docs |
| Some Places, Geocoder and Suggest fields are available on demand for extra cost. | verified | Subscription services docs |
| The WebAPI offer says extracting, storing and further using products/data outside the contract is prohibited and caching is not provided. | verified | Official WebAPI offer |

## Observations

- 2GIS is strong where geocoding should be tied to the 2GIS map/catalog ecosystem.
- 2GIS Geocoder and Places are separate products. Organization search should not be assigned to Geocoder.
- The public pricing model is clearer than many enterprise-only vendors, but some fields and methods still require sales contact.
- Storage and caching restrictions are a material blocker for internal database enrichment and offline processing.

## Unknowns

- Public OpenAPI/Swagger specification for Geocoder.
- SLA and support tiers for production packages.
- Contractual terms for SaaS embedding, redistribution, offline storage and customer-facing display.
- Whether address normalization and registry-level validation are supported beyond geocoder matching.
- Batch/asynchronous delivery support.

## Contradictions

- None found in reviewed official sources. The main risk is product-boundary confusion between Geocoder, Places and Suggest.

## Commercial Blockers

- Suggest API starts at larger packages in the public tariff table, while Geocoder has lower package tiers.
- Some fields and methods require additional paid access.
- Limits are per subscription/service and may need Platform Manager configuration.

## Legal and Data-Rights Blockers

- Official offer restrictions make storage, caching, modification and redistribution contract-sensitive.
- Procurement must ask whether a specific use case is allowed rather than infer permission from API availability.

## Live Testing Status

No credentialed live API test was performed. No Atlas benchmark results are claimed.

## Profile Decision

Create an active `2gis-geocoder-api` profile for direct and reverse geocoding. Do not create a separate Places API profile in this pass; record Places API as a related product for organization/place search.
