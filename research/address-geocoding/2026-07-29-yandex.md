# Yandex Maps Geocoder API Research Log

## Scope

This log reviews the official Yandex Maps Geocoder API for direct and reverse geocoding. It also records boundaries with Geosuggest, Organization Search and routing APIs.

## Confirmed Facts

| Fact | Status | Evidence |
|---|---|---|
| Yandex Maps Geocoder API performs forward geocoding from address/name to coordinates and reverse geocoding from coordinates to address. | verified | Official Geocoder documentation |
| The request endpoint is `https://geocode-maps.yandex.ru/v1` with required `apikey`, `geocode` and `lang` parameters. | verified | Request format documentation |
| The API supports JSON response format. | verified | Request format documentation |
| `geocode` can contain either an address/name or coordinates; this determines direct or reverse geocoding. | verified | Request format documentation |
| Reverse geocoding can restrict object type with `kind` values such as house, street, metro, district and locality. | verified | Request format documentation |
| `results` defaults to 10 and has a documented maximum of 50. | verified | Request format documentation |
| Error documentation includes 400, 403 and 429 cases. | verified | Response format documentation |
| API access requires an API key from the developer dashboard. | verified | Terms and request documentation |
| Under free-use terms, Geocoder has a 1,000 requests/day limit and results are tied to Yandex Maps display restrictions. | verified | Yandex Maps API terms |
| General free-use terms restrict storage/processing/modification of service data except temporary caching for up to 30 days for improving functionality within service capabilities. | verified | Yandex Maps API terms |
| Commercial Geocoder tariffs include Standard and Extended license variants; Extended is associated with data storage. | verified | Geocoder tariff page |
| The official product documentation separates Geocoder from Geosuggest, Organization Search and routing/navigation services. | verified | Yandex Maps API documentation index |

## Observations

- Yandex Geocoder is a geocoding API, not a full address normalization or registry-quality validation API.
- Address entry suggestions are a separate Yandex product, Geosuggest.
- Organization/place search is a separate Yandex product.
- Routing and distance matrix tasks must not be merged into geocoding decisions.
- Legal and display restrictions may dominate technical fit: free use requires Yandex Maps coupling and limits third-party map display.

## Unknowns

- Public SLA and support response terms for the selected commercial plan.
- Whether an OpenAPI/Swagger specification is publicly available for Geocoder.
- Detailed production requests-per-second limit for paid plans without contacting Yandex.
- Batch/offline geocoding rights for large datasets and non-map workflows.
- Whether the desired SaaS embedding and customer-facing display model is allowed under the target license.

## Contradictions

- No direct contradictions found. The main ambiguity is that free-use conditions and paid licensing differ materially; Atlas must not treat free terms as universal commercial terms.

## Commercial Blockers

- Minimum annual and monthly payments are material for production use.
- Free tier is limited and has map-display constraints.
- Storage rights depend on license type.

## Legal and Data-Rights Blockers

- Displaying Geocoder results on third-party maps is prohibited under free-use terms.
- General data storage and modification restrictions require legal review for caching, analytics, SaaS and internal database enrichment.

## Live Testing Status

No credentialed live API test was performed. No Atlas quality or latency benchmark is claimed.

Create an active `yandex-maps-geocoder-api` profile for direct and reverse geocoding. Do not include Geosuggest, Organization Search or routing as capabilities of this profile; reference them only as related Yandex products.
