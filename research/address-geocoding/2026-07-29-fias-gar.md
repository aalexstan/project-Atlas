# FIAS / GAR Data Integration Research Log

## Scope

This log reviews official FNS and FIAS/GAR sources for using the State Address Register as an address registry and data-integration source. It does not treat unofficial KLADR/FIAS wrappers as official access.

| Source | URL | Use |

## Observations

- FIAS/GAR is the primary registry route, not a commercial turnkey address-suggestions service.
- Official access appears to include file downloads, SMEV and API services, but public details for API methods, auth, schemas, quotas and SLA are incomplete in the reviewed public pages.
- A FIAS/GAR integration requires loading, indexing, search and quality logic in the adopter's own system unless a specific official API flow is obtained.
- KLADR should be treated as legacy/decreasing priority compared with GAR.

## Unknowns

- Current public download package formats and exact update cadence from official static pages.
- Public API service method catalog, base URL, authentication, schemas, quotas and SLA.
- Licensing conditions for commercial SaaS redistribution of registry-derived address data.
- Whether all users can access API services or whether access depends on registration, role or government integration channel.
- Production support process and incident communication.

## Contradictions

- No direct contradiction found. The main ambiguity is the public portal exposing "API services" while detailed API documentation is not visible in the reviewed pages.

## Commercial Blockers

- Direct registry access may avoid per-request vendor API fees, but total cost includes ETL, data storage, search index, address parsing, quality scoring, update handling and support.
- It cannot be compared to commercial APIs by subscription price alone.

## Legal and Data-Rights Blockers

- GAR is public and official, but exact redistribution, SaaS embedding and customer-facing use rules should be reviewed for the target use case.
- SMEV access may have eligibility and regulatory constraints.

## Live Testing Status

No live integration or download verification was performed. No Atlas benchmark results are claimed.

## Profile Decision

Create an active `fias-gar-data-integration` profile as an official registry/data-integration route. Do not present it as a normal REST geocoding API.
