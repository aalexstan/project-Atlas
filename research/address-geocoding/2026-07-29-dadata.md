# DaData Address APIs Research Log

## Scope

This log reviews DaData address-related API capabilities for address suggestions, address cleaning, direct geocoding, reverse geocoding, and address data rights. It intentionally separates address products from the existing company/counterparty DaData profile.

## Confirmed Facts

| Fact | Status | Evidence |
|---|---|---|
| DaData provides address suggestions by arbitrary address fragment and postal code. | verified | Address suggestions API page |
| Address suggestions cover all countries at least at city level, Russia to apartment level, and Belarus/Kazakhstan/Uzbekistan to house level. | provider_reported | Address suggestions API page |
| Address suggestions return FIAS/GAR/KLADR identifiers, coordinates, postal code and granular address fields where available. | verified | Address suggestions API page |
| DaData states Suggestions are not suitable for automatic processing of address files or databases; Standardization should be used for automatic processing. | verified | Address suggestions API page and support article |
| Address suggestions use `POST https://suggestions.dadata.ru/suggestions/api/4_1/rs/suggest/address` with token authentication. | verified | Address suggestions API page |
| Address suggestions have a 300-character `query` limit, daily plan limits, 30 requests/second per IP and 60 new connections/minute per IP. | verified | Address suggestions API page |
| Address cleaning/standardization is documented for Russia only. | verified | Address cleaning API page |
| Address cleaning uses `POST https://cleaner.dadata.ru/api/v1/clean/address` with API token and `X-Secret`. | verified | Address cleaning API page |
| Address cleaning accepts one address per request, has 20 requests/second per IP and 60 new connections/minute per IP, and is not supported from browser JavaScript because the secret key would be exposed. | verified | Address cleaning API page |
| Direct geocoding is implemented through the address cleaning endpoint and costs 20 kopecks per record. | verified | DaData geocoding API page and pricing page |
| Reverse geocoding is documented as an address-by-coordinates API for Russian houses, streets and cities. | verified | DaData geolocation API page |
| Reverse geocoding is included in subscription address methods, while direct geocoding and address standardization are outside subscription and charged per record. | verified | DaData pricing page |
| The free tier is similar to Light but has a 10,000 requests/day limit; paid annual plans start from Light with 50,000 requests/day. | verified | DaData pricing page |
| DaData states API-processed standardization data is not stored; file uploads are stored for up to one day. | provider_reported | DaData standardization product page |

## Observations

- DaData is two product families for this need: interactive suggestions and backend cleaning/geocoding.
- Address suggestions and company suggestions should not be conflated. They share provider, account and subscription model, but they solve different user tasks.
- Direct geocoding is priced and authenticated like address cleaning, not like subscription Suggestions.
- Reverse geocoding is part of the subscription address method set.

## Unknowns

- Public SLA for address APIs.
- Contract-level redistribution and resale rights for generated address data beyond visible offer/support statements.
- Whether higher-volume batch import has a documented asynchronous API beyond one-record cleaning calls.
- Enterprise or boxed deployment terms for address APIs.
- Current formal OpenAPI coverage for each address endpoint should be checked before Gold maturity.

## Contradictions

- None found in reviewed official sources. The main risk is boundary confusion between Suggestions, Standardization, direct geocoding and reverse geocoding.

## Commercial Blockers

- Suggestions consume one request per typed character, so form usage can spend 10-30 requests for one completed address according to DaData pricing/support text.
- Direct geocoding and standardization are pay-per-record even when the customer has a subscription.
- Annual subscription minimum applies to standard paid plans.

## Legal and Data-Rights Blockers

- Suggestions are explicitly positioned as human-assisted input, not unattended batch processing.
- Storage, caching, redistribution, SaaS embedding and resale rights should be confirmed for the exact contract before procurement.

## Live Testing Status

No credentialed live API test was performed. No Atlas benchmark results are claimed.

## Profile Decision

Create an active `dadata-address-api` profile. The existing `apis/dadata/` profile remains the broad DaData reference profile; the new profile is scoped to address suggestions, address cleaning, direct geocoding and reverse geocoding.
