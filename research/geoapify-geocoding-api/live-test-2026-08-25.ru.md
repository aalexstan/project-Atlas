# Live-тест Geoapify — 2026-08-25

[English version](live-test-2026-08-25.md)

## Цель

Провести первый address/geocoding live-test Atlas для Geoapify по предварительно зарегистрированному списку из четырёх измерений. Тест ограничен тремя одиночными запросами и не включает batch, bulk или production throughput.

## Проверенные официальные источники

- [Тарифы Geoapify](https://www.geoapify.com/pricing/)
- [Документация forward geocoding](https://apidocs.geoapify.com/docs/geocoding/forward-geocoding/)
- [Документация reverse geocoding](https://apidocs.geoapify.com/docs/geocoding/reverse-geocoding/)
- [Terms and Conditions](https://www.geoapify.com/terms-and-conditions/)
- [Copyright OpenStreetMap](https://www.openstreetmap.org/copyright)

## Доступ и безопасность

- Credential был предоставлен пользователем для этого теста и не записан в репозиторий, raw payloads или отчёт.
- Персональные и конфиденциальные данные не отправлялись; использованы публичные данные Москвы и одна синтетическая неизвестная строка.
- Выполнены три одиночных запроса с интервалом примерно 2,2 секунды.
- Batch, bulk, autocomplete load, scraping, исчерпание квоты и parallel traffic не выполнялись.
- Точные условия, принятые для конкретного аккаунта, отдельно не зафиксированы; коммерческие права остаются blocker для review.

## Среда теста

- Дата: 2026-08-25
- Клиент: `curl --silent --show-error --max-time 30`
- Семейство endpoints: `https://api.geoapify.com/v1/geocode/`
- Key: передан во время выполнения и удалён из всех repository artifacts
- Raw payloads: [live-test-2026-08-25-raw](live-test-2026-08-25-raw/)

## Запросы и наблюдения

### 1. Прямое геокодирование

Публичный запрос: `Red Square, Moscow`.

Наблюдение: HTTP `200`, content type `application/json; charset=utf-8`, latency `1.150038 s`, один результат. В ответе были `lat`, `lon`, `formatted`, `result_type` и компоненты адреса. Также присутствовали `datasource.attribution: © OpenStreetMap contributors` и `datasource.license: Open Database License`.

Raw payload: [forward.json](live-test-2026-08-25-raw/forward.json)

### 2. Обратное геокодирование

Публичные координаты: `55.7539, 37.6208`.

Наблюдение: HTTP `200`, content type `application/json; charset=utf-8`, latency `1.630592 s`, один результат. В ответе были `lat`, `lon`, `formatted`, `street`, `housenumber`, `postcode`, `result_type` и `distance`. В результате присутствовали те же поля attribution OpenStreetMap и Open Database License.

Raw payload: [reverse.json](live-test-2026-08-25-raw/reverse.json)

### 3. Неизвестный ввод

Синтетический запрос: `__atlas_geoapify_unknown_20260825__`.

Наблюдение: HTTP `200`, content type `application/json; charset=utf-8`, latency `0.807609 s` и `results: []`. Для этой точной синтетической строки стороннее совпадение не возвращено.

Raw payload: [unknown.json](live-test-2026-08-25-raw/unknown.json)

## Findings

1. Проверенные forward и reverse endpoints приняли предоставленный credential и вернули JSON с координатами и полями адреса/результата.
2. Неизвестная строка вернула empty result, а не совпадение.
3. В непустых raw responses были поля attribution OpenStreetMap и сигнал Open Database License.
4. Порог 5 requests/second или 3 000 credits/day не измерялся; billing behavior и SLA не подтверждены.
5. Accuracy, house-level precision, storage, caching, redistribution, customer display, SaaS и model-training rights не подтверждены.
6. Условия, принятые для конкретного аккаунта, не сохранены как raw evidence; commercial use зависит от review terms.

## Decision gate

Maturity остаётся `reviewed`. `live_tested` остаётся `false`, а `live_tested_on` / `live_test_valid_until` намеренно не установлены до human review evidence и access/terms gate. Автоматического повышения нет.

Тест является техническим и эмпирическим evidence только для проверенных форм запросов. Это не quality benchmark и не юридическое заключение.

## Граница воспроизведения

Повторять только три класса одиночных запросов с законным free-plan key, публичными/синтетическими входами и консервативной задержкой. Не добавлять batch, bulk, load или quota-threshold testing.
