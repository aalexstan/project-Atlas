# Geoapify Live Test — 2026-08-25

[Русская версия](live-test-2026-08-25.ru.md)

## Purpose

Run the first Atlas address/geocoding live test for Geoapify using the pre-registered four-dimension claim list. The test is limited to three individual requests and does not test batch, bulk or production throughput.

## Official sources reviewed

- [Geoapify pricing](https://www.geoapify.com/pricing/)
- [Forward geocoding documentation](https://apidocs.geoapify.com/docs/geocoding/forward-geocoding/)
- [Reverse geocoding documentation](https://apidocs.geoapify.com/docs/geocoding/reverse-geocoding/)
- [Terms and Conditions](https://www.geoapify.com/terms-and-conditions/)
- [OpenStreetMap copyright](https://www.openstreetmap.org/copyright)

## Access and safety

- The credential was supplied by the user for this test and was not written to the repository, raw payloads or report.
- No personal or confidential data was submitted; queries used public Moscow data and one synthetic unknown string.
- Three individual requests were made with approximately 2.2 seconds between requests.
- No batch, bulk, autocomplete load, scraping, quota exhaustion or parallel traffic was performed.
- The account's exact accepted terms were not independently recorded in this run; commercial rights remain a review blocker.

## Pre-registered core claims

| ID | Dimension | Claim | Result classification |
|---|---|---|---|
| C1 | Identity/purpose | Geoapify provides hosted forward and reverse geocoding; autocomplete and Places are separate or related capabilities. | `observed` for the tested forward/reverse endpoint behavior; product boundary remains `provider_reported` from docs. |
| C2 | Response contract | Authenticated individual forward, reverse and unknown-input requests return a machine-readable JSON result or empty-result shape with coordinate/address fields. | Compare request-by-request below. |
| C3 | Rate-limit/policy | The reviewed free plan publishes 3,000 credits/day and up to 5 requests/second; ordinary spaced requests should be accepted without measuring the threshold. | HTTP responses observed; quota and threshold not tested. |
| C4 | Licensing/attribution | Response/documentation identifies attribution and source-license requirements, including OpenStreetMap attribution where applicable. | Attribution and Open Database License fields observed in both non-empty responses; rights to storage, caching, redistribution and SaaS remain unknown. |

## Test environment

- Date: 2026-08-25
- Client: `curl --silent --show-error --max-time 30`
- Endpoint family: `https://api.geoapify.com/v1/geocode/`
- Key: supplied at runtime and redacted from all repository artifacts
- Raw payloads: [live-test-2026-08-25-raw](live-test-2026-08-25-raw/)

## Requests and observations

### 1. Forward geocoding

Public query: `Red Square, Moscow`.

Observed: HTTP `200`, content type `application/json; charset=utf-8`, latency `1.150038 s`, one result. The response contained `lat`, `lon`, `formatted`, `result_type` and address components. The result also contained `datasource.attribution: © OpenStreetMap contributors` and `datasource.license: Open Database License`.

Raw payload: [forward.json](live-test-2026-08-25-raw/forward.json)

### 2. Reverse geocoding

Public coordinates: `55.7539, 37.6208`.

Observed: HTTP `200`, content type `application/json; charset=utf-8`, latency `1.630592 s`, one result. The response contained `lat`, `lon`, `formatted`, `street`, `housenumber`, `postcode`, `result_type` and `distance`. The result contained the same OpenStreetMap attribution and Open Database License fields.

Raw payload: [reverse.json](live-test-2026-08-25-raw/reverse.json)

### 3. Unknown input

Synthetic query: `__atlas_geoapify_unknown_20260825__`.

Observed: HTTP `200`, content type `application/json; charset=utf-8`, latency `0.807609 s`, and `results: []`. No unrelated match was returned for this exact synthetic string.

Raw payload: [unknown.json](live-test-2026-08-25-raw/unknown.json)

## Findings

1. The tested forward and reverse endpoints accepted the supplied credential and returned JSON responses with coordinates and address/result fields.
2. The tested unknown string returned an empty result rather than a match.
3. The raw non-empty responses exposed OpenStreetMap attribution and an Open Database License signal.
4. The test did not measure the 5 requests/second or 3,000 credits/day threshold, and did not confirm billing behavior or SLA.
5. The test did not confirm address accuracy, house-level precision, storage, caching, redistribution, customer display, SaaS or model-training rights.
6. The account-specific accepted terms were not captured as raw evidence; commercial use remains subject to terms review.

## Decision gate

Maturity remains `reviewed`. `live_tested` remains `false` and `live_tested_on` / `live_test_valid_until` are intentionally unset until human review accepts the evidence and the access/terms gate. No automatic promotion is made.

This test is technical and empirical evidence for the tested request shapes only. It is not a quality benchmark or legal opinion.

## Reproduction boundary

Reproduce only the three individual request classes with a lawful free-plan key, public/synthetic inputs and a conservative delay. Do not add batch, bulk, load or quota-threshold testing.
