# Исследовательский журнал Wildberries Seller API

[English version](2026-08-23.md)

## Объём

Проверить, является ли официальное API продавца Wildberries самостоятельным и полезным API-first профилем для операций маркетплейса и интеграции с внутренними бизнес-системами.

## Проверенные официальные источники

- [Информация об API](https://dev.wildberries.ru/docs/openapi/api-information)
- [Инструкция подключения токена](https://dev.wildberries.ru/knowledge-base/articles/019d49a0-f9f7-79a4-b5ee-df5dabe9cff4)
- [Документация sandbox](https://dev.wildberries.ru/en/openapi-other/sandbox-environment)

## Подтверждённые факты

- Официальная документация описывает API для продавцов и интеграции с ERP, WMS, OMS и CRM-системами.
- Документация разделена по категориям сервисов, включая контент, аналитику, цены и скидки, операции маркетплейса, продвижение, отзывы, поставки, возвраты, документы, финансы и другие процессы продавца.
- Документация API публикуется в формате Swagger/OpenAPI.
- В модели подключения указаны учётная запись продавца и права API-токена.
- Для поддерживаемых scopes описана тестовая среда с синтетическими данными.
- Для отдельных методов приведены примеры ограничений частоты запросов и burst-поведения.

## Утверждения поставщика

Перечень сервисов, сценарии интеграции и описание тестовой среды являются опубликованными Wildberries описаниями. Atlas самостоятельно не измерял полноту, доступность или production-производительность.

## Неизвестные параметры и блокеры

- Цена API и коммерческие обязательства.
- Полная матрица методов и полей для целевой учётной записи продавца.
- Production-квоты за пределами приведённых примеров.
- SLA, время реакции поддержки и порядок уведомления об инцидентах.
- Права хранения, показа клиентам, SaaS-встраивания и перераспределения.
- Гарантии версионирования и breaking changes для каждой категории сервисов.

## Наблюдение и решение

Это целостный активный профиль для интеграций продавца. Его следует оценивать по категориям методов и scope токена, а не считать одним равномерным и безлимитным API. Создан профиль уровня `verified` для документированного базового контракта, а коммерческие и эксплуатационные условия явно оставлены открытыми.

Не проводился. Atlas не использовал credentials, данные продавца или тестовые запросы.
