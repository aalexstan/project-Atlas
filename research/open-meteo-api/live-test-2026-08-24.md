# Open-Meteo Public Live Test — 2026-08-24

[Русская версия](live-test-2026-08-24.ru.md)

## Purpose

Reproducibly test the Open-Meteo public API without provider approval, paid credentials or production tokens.

## Authorization and safety

- Only publicly reachable free endpoints were used.
- No API key, account credential, paid customer endpoint or personal data was used.
- All requests were safe HTTP GET requests. No write, batch, purchase or destructive method was called.
- The rate-limit threshold was not stress-tested; this record only captures whether a small normal request series was limited.

## Pre-test core claims

This list was frozen before executing the requests.

| ID | Core claim | Profile reference | Why core |
|---|---|---|---|
| C1 | Public coordinate forecast returns documented JSON | `api.json` `authentication`, `sources`; README Technical Access | Forecast is the primary API purpose |
| C2 | Historical route returns a separate historical JSON response | `api.json` `sources`; README Technical Access | Historical research is a named use case |
| C3 | Invalid input produces an actionable HTTP/JSON error | `api.json` `open_questions`; README Technical Access | Error behavior is required for safe integration |
| C4 | Free-tier quota and commercial-use boundary are provider-reported constraints | `api.json` `pricing`, `rate_limits`, `open_questions` | Procurement and legal blockers must be explicit even when not measurable publicly |

## Terms of Service check

The test used the public free endpoint described by the provider's public pricing/documentation. No account or key was created. The public pricing page was reviewed for the free/non-commercial boundary; commercial use and customer-endpoint terms remain provider-reported and were not used for this test.

## Test environment

- Date: 2026-08-24
- Client: `curl --http1.1`
- Coordinates: Moscow `55.75, 37.62`
- Requests: 4 total, 3 valid and 1 intentionally invalid
- Latency: curl `time_total`, full request time in seconds

## Requests and raw responses

### 1. Forecast with current conditions

`GET https://api.open-meteo.com/v1/forecast?latitude=55.75&longitude=37.62&current=temperature_2m,wind_speed_10m&timezone=Europe%2FMoscow`

Observed: HTTP `200`, `0.215519 s`, no rate-limit response.


## Rate-limit observation

The four-request sequence did not receive HTTP `429`, `Retry-After` or another rate-limit response. This is not a measured daily quota or threshold. The profile's `10,000 calls/day` value remains provider-reported and was not stress-tested.

## Decision

The test confirms the tested public endpoint and error-shape claims. It does not prove quota, accuracy, SLA, commercial rights or production suitability. Keep maturity at `reviewed`; do not promote automatically to `verified`. The evidence is valid until `2026-11-22` under the 90-day pricing/limits cadence unless a material provider change requires earlier review.
