# Публичный live test Open-Meteo — 2026-08-24

[English version](live-test-2026-08-24.md)

## Цель

Показать воспроизводимую эмпирическую проверку основного публичного API Open-Meteo без согласования с поставщиком, платных credentials и production-токенов.

## Авторизация и безопасность

- Использовались только публичные бесплатные endpoints.
- API key, credentials аккаунта, платный customer endpoint и персональные данные не использовались.
- Все запросы были безопасными HTTP GET. Методы записи, batch, покупки и удаления не вызывались.
- Порог rate limit намеренно не выбивался; зафиксировано только поведение небольшой штатной серии.

Этот список был зафиксирован до выполнения запросов.

| ID | Core claim | Ссылка в профиле | Почему это core |

## Проверка Terms of Service

Использовался публичный free endpoint, описанный в публичных материалах поставщика. Аккаунт и key не создавались. Публичная страница тарифов проверена на границу free/non-commercial; commercial use и условия customer endpoint остаются сообщениями поставщика и в этом тесте не использовались.

## Наблюдение rate limit

В серии из четырёх запросов не было HTTP `429`, `Retry-After` или другого ответа о rate limit. Это не измеренный дневной порог. Значение `10,000 calls/day` в профиле остаётся сообщением поставщика и не подвергалось нагрузочному тесту.

## Решение

Тест подтверждает протестированные public endpoint и форму ошибок. Он не доказывает квоту, точность, SLA, коммерческие права или production-пригодность. Maturity остаётся `reviewed`; автоматического повышения до `verified` нет. Доказательство действительно до `2026-11-22` по 90-дневному cadence для цен и лимитов, если существенное изменение поставщика не потребует более раннего ревью.

См. [pre-merge ревью](../../reviews/open-meteo-live-test-2026-08-24.ru.md).
