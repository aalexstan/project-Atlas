## Цель

Проверить ограниченный набор утверждений о запросах и ответах WeatherAPI.com с авторизованным free-tier key, предоставленным пользователем. Это эмпирическое доказательство для проверенных форм запросов, а не проверка квоты, SLA, точности или юридических прав.

## Авторизация и безопасность

- Key предоставлен пользователем и использован по одному разу для каждого запроса.
- Значение key не записывается в репозиторий, логи или raw payloads.
- Платный credential, production secret и персональные данные не использовались.
- Выполнено пять безопасных HTTP GET-запросов; нагрузочное тестирование и исчерпание квоты не проводились.
- До теста изучены официальная документация и [условия API](https://www.weatherapi.com/terms.aspx). Эта запись не подтверждает тариф или договорные права аккаунта пользователя.

## Запросы и наблюдения

### 1. Current weather с выбором полей

`GET https://api.weatherapi.com/v1/current.json?key=<redacted>&q=Moscow&current_fields=temp_c,wind_kph`

Наблюдение: HTTP `200`, `0.258207 с`, matched location `Moscow`, Russia. Ответ содержал `temp_c` и `wind_kph`, но также много других current-weather полей. Поэтому фактическое сужение ответа через этот параметр не считается подтверждённым; требуется уточнение плана или документации.

Raw payload: [current.json](live-test-2026-08-24-raw/current.json)

### 2. Forecast на три дня

`GET https://api.weatherapi.com/v1/forecast.json?key=<redacted>&q=Moscow&days=3&aqi=no&alerts=no`

Наблюдение: HTTP `200`, `0.683815 с`, matched location `Moscow`, `3` forecast days. JSON содержит объекты `location`, `current` и `forecast.forecastday`.

Raw payload: [forecast.json](live-test-2026-08-24-raw/forecast.json)

### 3. Search/autocomplete

`GET https://api.weatherapi.com/v1/search.json?key=<redacted>&q=Moscow`

Наблюдение: HTTP `200`, `0.180209 с`, два результата. В каждом наблюдаемом результате были `id`, `name`, `region`, `country`, `lat`, `lon` и `url`.

Raw payload: [search.json](live-test-2026-08-24-raw/search.json)

### 4. Похожая на неизвестную строка локации

`GET https://api.weatherapi.com/v1/current.json?key=<redacted>&q=atlas-invalid-location-zzzz`

Наблюдение: HTTP `200`, `0.323943 с`, но сервис разрешил строку в `Atlas`, Eskisehir, Turkey. Это существенный риск интеграции: клиент должен проверять matched location и не считать HTTP 200 подтверждением точного совпадения с исходной строкой.

Raw payload: [unknown-location.json](live-test-2026-08-24-raw/unknown-location.json)

### 5. Отсутствующий обязательный query parameter

`GET https://api.weatherapi.com/v1/current.json?key=<redacted>&q=`

Наблюдение: HTTP `400`, `0.288702 с`, JSON error code `1003`, message `Parameter q is missing.`

Raw payload: [empty-q.json](live-test-2026-08-24-raw/empty-q.json)

## Решение

Тест подтверждает ограниченный технический доступ, JSON-ответы, формы запросов current/forecast/search и структурированную ошибку отсутствующего параметра. Также обнаружены два интеграционных риска: выбор полей не дал видимого сужения ответа, а fuzzy location resolution может вернуть другое место с HTTP 200.

Maturity остаётся `reviewed`. `live_tested: true` относится только к этому окну доказательств; повышать профиль до `verified` нельзя. Срок действия evidence: `2026-11-22` по кратчайшему 90-дневному cadence для access/limits, если раньше не появится существенное изменение поставщика.
