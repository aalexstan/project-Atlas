# Исследование API Яндекс Доставки

[English version](2026-08-22-yandex-delivery.md)

## Область

Проверка официального business API Яндекс Доставки для жизненного цикла заказа доставки. Это не общий агрегатор трекинга посылок.

## Подтверждённые факты

- Яндекс Доставка использует HTTP-запросы для создания заказов и Bearer-token authentication из business account.
- Официальный справочник перечисляет создание, подтверждение, отмену, информацию и поиск заявок, отслеживание статусов, локацию курьера и ETA-related operations.
- Для части операций есть v1 и v2; новым пользователям рекомендован v2.
- API-интеграция заявлена для автоматического создания заказов, показа цены доставки и обновлений статуса для клиентов.

## Неизвестные параметры и блокеры

- В проверенных источниках не подтверждены публичная цена API, production quotas, rate limits, SLA, storage, customer display, SaaS и redistribution terms.
- Credentials, sandbox call и live delivery order не использовались.

## Решение

Создать reviewed-профиль managed delivery-order API и оставить его отдельным от postal tracking и map-routing API.
