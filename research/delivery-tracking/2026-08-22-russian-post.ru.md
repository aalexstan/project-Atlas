# Исследование API отслеживания Почты России

[English version](2026-08-22-russian-post.md)

## Область

Проверка официального API Почты России для отслеживания регистрируемых почтовых отправлений. Это tracking API, а не API создания отправлений или управления курьерами.

## Подтверждённые факты

- Сервис даёт программный доступ к информации об отслеживании регистрируемых почтовых отправлений.
- Единичный доступ возвращает одно отправление за запрос и доступен зарегистрированным пользователям с лимитом 100 запросов в сутки.
- Пакетный доступ поддерживает до 3 000 трек-номеров в запросе и доступен только клиентам с договором на посылки, письма или EMS.
- Единичный доступ использует SOAP 1.2, а документация указывает методы `getOperationHistory` и `PostalOrderEventsForMail`.
- Документация описывает login/password, языки RUS/ENG и историю операций с временем, местом и операцией.

## Неизвестные параметры и блокеры

- В проверенных публичных источниках не подтверждены цена по договору, production SLA, support, throughput, retry policy, storage и redistribution rights.
- Credentialed live call, benchmark качества данных и batch test не проводились.

## Решение

Создать reviewed-профиль официального postal tracking API и не смешивать его с созданием отправлений, агрегацией перевозчиков и dispatch курьеров.
