# Исследовательский журнал Ozon Seller API

[English version](2026-08-23.md)

## Объём

Проверить, следует ли добавить Ozon Seller API в сравнение торговых операций как отдельный API канала продавца.

## Проверенные официальные источники

- [Документация Ozon Seller API](https://docs.ozon.ru/api/seller/)
- [Сообщество Ozon for Dev](https://dev.ozon.ru/community/)
- [Официальное обсуждение OAuth](https://dev.ozon.ru/community/2154-Avtorizatsiia-cherez-OAuth-token/)

## Подтверждённые факты

- У Ozon есть отдельный маршрут документации Seller API.
- В официальных материалах для разработчиков базовым URL seller API указан `https://api-seller.ozon.ru`.
- В официальных материалах Ozon for Dev описана аутентификация через Client ID и API key.
- В официальных материалах для разработчиков обсуждается доступ приложений через OAuth token.
- В официальном сообществе разработчиков упоминаются операции продавца с товарами, остатками, аналитикой, заказами и отправлениями.

## Утверждения поставщика

Группы возможностей и модель аутентификации опубликованы Ozon. Atlas самостоятельно не проверял их полноту и production-поведение.

## Неизвестные параметры и блокеры

- Основной маршрут документации вернул redirect loop в исследовательской среде.
- Полная актуальная матрица методов и полей и machine-readable specification.
- Актуальные лимиты методов, retry semantics и модель ошибок.
- Наличие sandbox для нужных seller-сценариев.
- Цена API, SLA, поддержка и права использования данных.

## Решение

Создать активный профиль уровня `reviewed` и включить Ozon в сравнение с явной оговоркой об уровне уверенности. Не повышать профиль до verified до повторной проверки основной документации и фиксации базового контракта.

## Live testing

Не проводился. Credentials продавца и клиентские данные не использовались.
