# Ozon Seller API Research Log

[Русская версия](2026-08-23.ru.md)

## Scope

Assess whether Ozon Seller API should be added to the commerce-operations comparison as a distinct seller-channel API.

## Official sources reviewed

- [Ozon Seller API documentation](https://docs.ozon.ru/api/seller/)
- [Ozon for Dev community](https://dev.ozon.ru/community/)
- [Official OAuth discussion](https://dev.ozon.ru/community/2154-Avtorizatsiia-cherez-OAuth-token/)

## Confirmed facts

- Ozon maintains a dedicated Seller API documentation route.
- Official developer materials identify `https://api-seller.ozon.ru` as the seller API base URL.
- Client ID and API key authentication is documented in official Ozon developer material.
- OAuth token access for applications is discussed in official Ozon developer guidance.
- Official developer-community materials reference seller operations around products, stocks, analytics, orders and postings.

## Provider-reported claims

The capability groups and authentication model are published by Ozon. Atlas did not independently test their completeness or production behavior.

## Unknowns and blockers

- The primary documentation route returned a redirect loop in the research environment.
- Complete current method/field matrix and machine-readable specification.
- Current method-level quotas, retry semantics and error model.
- Sandbox availability for the intended seller workflows.
- API price, SLA, support and data-use terms.

## Decision

Create an active `reviewed` profile and include Ozon in the commerce comparison with an explicit confidence caveat. Do not call it verified until the primary reference is rechecked and the core contract is captured.

## Live testing

Not performed. No seller credentials or customer data were used.
