# Исследование: первичная карта API Portal

Дата исследования: 2026-06-23
Статус: первичное исследование

## Цель

Понять, насколько API Portal пригоден как стартовая точка для Project Atlas и какие типы данных он помогает обнаружить.

## Подтвержденные наблюдения

- API Portal содержит каталог API с карточками источников и фильтрами.
- Видны фильтры по поставщикам, категориям, отраслям, типу тарификации и интегратору.
- Каталог включает как коммерческие API, так и государственные источники.
- В категориях заметны крупные блоки: открытые данные, аналитика, выписки, ЕСИА, платежи, утилиты, рассылки, доставка, карты и инфраструктура.
- В отраслях заметны крупные блоки: управление и автоматизация, маркетинг, электронная коммерция, государство, fintech, госуслуги, проверка контрагентов, комплаенс.
- Часть карточек содержит ссылку на документацию, но не все ссылки можно считать проверенными без отдельной валидации.
- Лицензионная информация обычно не раскрыта на уровне, достаточном для решения о хранении, перепродаже, SaaS или обучении ИИ.

## Что найдено в первом наборе карточек

- ГЛОБАС.API: контрагентские данные, мониторинг изменений, массовая проверка, обогащение баз.
- API Seldon.Basis: контрагентские и комплаенс-данные, финансовая состоятельность, аффилированность, правовые проверки.
- API Seldon.Tenders: извещения, протоколы, контракты, участники, ценовые предложения, документы, подбор поставщиков.
- API Портала открытых данных Москвы: более 1000 наборов данных и справочников по Москве.
- API ФИАС: адресные данные России, поиск адресных объектов по названию и кодам связей.

## Предположения

- API Portal может быть полезен как источник первичного списка поставщиков и рынков данных, но не как финальный источник правовой и технической истины.
- Для дальнейшего анализа нужно строить двухуровневую карту: `каталог -> официальный источник -> документация/лицензия`.

## Неизвестно

- Юридический владелец API Portal.
- Полная методология модерации карточек.
- Полный экспорт каталога.
- Условия использования информации из самого каталога.

## Рекомендация

Использовать API Portal как стартовый навигационный слой, но каждую запись переводить в статус `проверено` только после подтверждения на официальном сайте поставщика или в официальной документации.
