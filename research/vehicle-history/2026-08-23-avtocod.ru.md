# Исследование API истории автомобилей Автокод

[English version](2026-08-23-avtocod.md)

## Область

Проверка официального B2B API Автокода для программного получения отчётов по истории транспортных средств. Государственные web checks и SMEV routes не считаются public substitutes этого коммерческого API.

## Подтверждённые факты

- Автокод описывает API как программный интерфейс интеграции для отчётов по ТС, баланса и истории запросов.
- Документированный base URL: `https://b2bapi.avtocod.ru/b2b/api/v1/`; API использует HTTPS GET/POST и JSON responses.
- Quick start документирует onboarding account, tokens, проверку баланса, генерацию и получение отчёта.
- Сервис публикует спецификации полей отчёта, JSON Schema и пример отчёта.
- Swagger UI доступен, но вызовы с аккаунтом клиента создают реальные отчёты и списывают средства с баланса.

## Неизвестные параметры и блокеры

- В этом проходе не подтверждены цена API, матрица типов отчётов, production quotas, rate limits, SLA, source coverage/freshness и data-rights terms.
- Account, token, платный отчёт и live test не использовались.

## Решение

Создать reviewed-профиль коммерческого API истории автомобиля. Не заявлять независимую полноту отчёта и не рекомендовать его для scoring, страховых или кредитных решений без legal, commercial и quality review.
