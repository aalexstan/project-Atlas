# Avtocod vehicle history API research

## Scope

Review the official B2B API Avtocod for programmatic vehicle-history reports. Government web checks and SMEV routes are not treated as public substitutes for this commercial API.

## Official sources reviewed

- [API overview](https://b2bapi.avtocod.ru/docs/about/overview)
- [Quick start](https://b2bapi.avtocod.ru/docs/using-api/quick-start)
- [Public report specifications](https://b2bapi.avtocod.ru/docs/reference/specs)
- [Avtocod public specifications repository](https://github.com/avtocod/specs)

## Confirmed facts

- Avtocod describes its API as a programmatic integration interface for vehicle reports, account balance and request history.
- The documented base URL is `https://b2bapi.avtocod.ru/b2b/api/v1/`; the API uses HTTPS GET/POST and JSON responses.
- The quick start documents account onboarding, tokens, balance checking, report generation and report retrieval.
- The service publishes report-field specifications, JSON Schema and an example report.
- Swagger UI is available, but executing calls there with a customer account generates real reports and charges the account balance.

## Unknowns and blockers

- API-specific price, report-type matrix, production quotas, rate limits, SLA, source coverage/freshness and data-rights terms are not confirmed in this pass.
- No account, token, paid report or live test was used.

## Decision

Create a reviewed commercial vehicle-history API profile. Do not claim independent report completeness or recommend it for scoring, insurance or lending decisions without legal, commercial and quality review.
