# Nominatim Public Instance Live Test - 2026-08-24

[Russian version](live-test-2026-08-24.ru.md)

## Purpose

Run the first Atlas address/geocoding live-test against the public Nominatim instance. The test is deliberately limited to individual geocoding requests and is designed to verify technical behavior together with the public-service policy and attribution boundary.

## Candidate and legal path

Nominatim public instance was selected instead of a hosted commercial provider because its public usage policy is accessible without account registration or credentials. The canonical policy reviewed for this test is the [OSMF Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/). The user-supplied `https://operations.osmforge.org/policies/nominatim/` URL was not reachable during the check; the OSMF canonical host was used instead.

The policy reviewed before testing requires:

- no heavy use and an absolute maximum of one request per second;
- a valid identifying HTTP `User-Agent` or `Referer`, not a stock library user-agent;
- clearly displayed attribution suitable for the medium;
- no client-side autocomplete/search-as-you-type service;
- no large bulk geocoding on the public instance and strict caution for regular scripts.

The [OpenStreetMap copyright page](https://www.openstreetmap.org/copyright) states that OSM data is ODbL and requires credit to OpenStreetMap and its contributors. The test does not establish rights to cache, store, redistribute or build a derived database.

## Authorization and safety

- Public endpoint only; no API key, account credential or paid service was used.
- Three individual geocoding requests were made, each separated by at least two seconds.
- No autocomplete, batch, bulk, periodic, load or reverse-geocoding sequence was performed.
- Queries contain public place/address strings only; no personal or confidential data was submitted.
- The custom `User-Agent` identifies Atlas as `ProjectAtlas-live-test/2026-08-24`; a repository `Referer` was also sent.

## Requests and observations

### 1. Free-form Russian place query

`GET https://nominatim.openstreetmap.org/search?q=%D0%9A%D1%80%D0%B0%D1%81%D0%BD%D0%B0%D1%8F+%D0%BF%D0%BB%D0%BE%D1%89%D0%B0%D0%B4%D1%8C%2C+%D0%9C%D0%BE%D1%81%D0%BA%D0%B2%D0%B0&format=jsonv2&addressdetails=1&limit=1&accept-language=ru`

Observed after the compliant delay: HTTP `200`, `0.843148 s`, one JSONv2 result for `Красная площадь` in Moscow. The raw result included a `licence` value: `Data © OpenStreetMap contributors, ODbL 1.0. http://osm.org/copyright`. The request was a single free-form geocoding lookup, not autocomplete.

Raw payload: [free-form.json](live-test-2026-08-24-raw/free-form.json)

### 2. Structured address query

`GET https://nominatim.openstreetmap.org/search?street=%D0%A2%D0%B2%D0%B5%D1%80%D1%81%D0%BA%D0%B0%D1%8F+%D1%83%D0%BB%D0%B8%D1%86%D0%B0&city=%D0%9C%D0%BE%D1%81%D0%BA%D0%B2%D0%B0&country=%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D1%8F&format=geocodejson&limit=1&accept-language=ru`

Observed after the compliant delay: HTTP `200`, `0.461253 s`, one GeocodeJSON feature for `Тверская улица, Москва`. The raw response included `geocoding.attribution: Data © OpenStreetMap contributors, ODbL 1.0. http://osm.org/copyright` and `geocoding.licence: ODbL`. This is a single structured geocoding lookup.

Raw payload: [structured.json](live-test-2026-08-24-raw/structured.json)

### 3. Unknown query

`GET https://nominatim.openstreetmap.org/search?q=__atlas_nominatim_invalid_20260824__&format=jsonv2&limit=1&accept-language=en`

Observed after the compliant delay: HTTP `200`, `0.198129 s`, and an empty JSON array (`[]`). The service did not return a match for the intentional unknown query. This is an intentional invalid/unknown-input request, not a bulk or autocomplete test.

Raw payload: [unknown.json](live-test-2026-08-24-raw/unknown.json)

## Rate-limit and policy observation

The protocol used three individual requests with a delay of at least two seconds. It did not attempt to measure the threshold, generate load, or provoke a `429`. The one-request-per-second policy is therefore a documented constraint, not an empirically exhausted quota.

## Licensing and attribution observation

The first raw response exposed a `licence` attribution string and the structured GeocodeJSON response exposed both `geocoding.attribution` and `geocoding.licence: ODbL`. The official OSM copyright page requires credit to OpenStreetMap and its contributors and identifies ODbL. A successful response does not prove that a particular storage, cache, redistribution or SaaS design is permitted.

## Decision and review gate

This record supports bounded observations about individual public geocoding requests, JSON/GeocodeJSON response format, empty-result behavior for an unknown query and the attribution/licence signal. It cannot confirm storage, caching, redistribution, SLA, accuracy, production suitability or a quota threshold. Autocomplete and bulk use remain policy-prohibited on the public instance.

`maturity` remains `reviewed`. `live_tested_on` and `live_test_valid_until` are intentionally not set yet: they may be added only after a human reviews this evidence and the paired review file. No automatic promotion is allowed.

See the [paired review](../../reviews/nominatim-geocoder-software-live-test-2026-08-24.md).

## Reproduction

Repeat only the three individual request shapes with the same identifying User-Agent/Referer and a delay of at least two seconds. Do not add autocomplete, batch, bulk, regular polling or load. Do not submit personal/confidential data. Preserve attribution and licence signals and do not infer storage or redistribution rights from HTTP success.
