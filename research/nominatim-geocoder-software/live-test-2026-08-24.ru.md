# Live-test публичного Nominatim - 2026-08-24

[English version](live-test-2026-08-24.md)

## Цель

Провести первый address/geocoding live-test Atlas для public Nominatim. Тест намеренно ограничен отдельными geocoding-запросами и проверяет техническое поведение вместе с policy и attribution boundary публичного сервиса.

## Кандидат и legal path

Выбран public instance Nominatim, а не коммерческий hosted provider, потому что его policy доступна без регистрации аккаунта и credentials. Перед тестом изучена каноническая [OSMF Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/). Указанный пользователем URL `https://operations.osmforge.org/policies/nominatim/` во время проверки не открылся; использован канонический OSMF host.

Изученная policy требует:

- отсутствие heavy use и абсолютный максимум один запрос в секунду;
- валидный идентифицирующий HTTP `User-Agent` или `Referer`, а не стандартный user-agent библиотеки;
- видимую attribution, подходящую для носителя;
- запрет client-side autocomplete/search-as-you-type;
- запрет крупного bulk geocoding на public instance и осторожность с regular scripts.

[Страница copyright OpenStreetMap](https://www.openstreetmap.org/copyright) указывает ODbL и обязательный credit OpenStreetMap и contributors. Тест не устанавливает права на caching, storage, redistribution или создание derived database.

## Авторизация и безопасность

- Использован только public endpoint; API key, account credential и paid service не применялись.
- Выполнены три отдельных geocoding-запроса с паузой не менее двух секунд.
- Autocomplete, batch, bulk, periodic, load и серия reverse-geocoding не проводились.
- В запросах только публичные place/address strings; персональные и конфиденциальные данные не отправлялись.
- Custom `User-Agent` идентифицирует Atlas как `ProjectAtlas-live-test/2026-08-24`; также отправлен Referer репозитория.

## Запросы и наблюдения

### 1. Free-form Russian place query

`GET https://nominatim.openstreetmap.org/search?q=%D0%9A%D1%80%D0%B0%D1%81%D0%BD%D0%B0%D1%8F+%D0%BF%D0%BB%D0%BE%D1%89%D0%B0%D0%B4%D1%8C%2C+%D0%9C%D0%BE%D1%81%D0%BA%D0%B2%D0%B0&format=jsonv2&addressdetails=1&limit=1&accept-language=ru`

Наблюдение после compliant delay: HTTP `200`, `0.843148 с`, один JSONv2 result для `Красная площадь` в Москве. В raw result есть `licence`: `Data © OpenStreetMap contributors, ODbL 1.0. http://osm.org/copyright`. Это отдельный free-form geocoding lookup, а не autocomplete.

Raw payload: [free-form.json](live-test-2026-08-24-raw/free-form.json)

### 2. Structured address query

`GET https://nominatim.openstreetmap.org/search?street=%D0%A2%D0%B2%D0%B5%D1%80%D1%81%D0%BA%D0%B0%D1%8F+%D1%83%D0%BB%D0%B8%D1%86%D0%B0&city=%D0%9C%D0%BE%D1%81%D0%BA%D0%B2%D0%B0&country=%D0%A0%D0%BE%D1%81%D1%81%D0%B8%D1%8F&format=geocodejson&limit=1&accept-language=ru`

Наблюдение после compliant delay: HTTP `200`, `0.461253 с`, один GeocodeJSON feature для `Тверская улица, Москва`. Raw response содержит `geocoding.attribution: Data © OpenStreetMap contributors, ODbL 1.0. http://osm.org/copyright` и `geocoding.licence: ODbL`. Это отдельный structured geocoding lookup.

Raw payload: [structured.json](live-test-2026-08-24-raw/structured.json)

### 3. Unknown query

`GET https://nominatim.openstreetmap.org/search?q=__atlas_nominatim_invalid_20260824__&format=jsonv2&limit=1&accept-language=en`

Наблюдение после compliant delay: HTTP `200`, `0.198129 с` и пустой JSON-массив (`[]`). Сервис не вернул match для intentional unknown query. Это intentional invalid/unknown-input request, не bulk и не autocomplete.

Raw payload: [unknown.json](live-test-2026-08-24-raw/unknown.json)

## Наблюдение rate-limit и policy

Протокол использовал три отдельных запроса с паузой не менее двух секунд. Порог не измерялся, нагрузка не создавалась и `429` не провоцировался. One-request-per-second остаётся documented constraint, а не исчерпанной эмпирической квотой.

## Наблюдение licensing и attribution

В первом raw response есть attribution string в `licence`, а в structured GeocodeJSON есть `geocoding.attribution` и `geocoding.licence: ODbL`. Официальная OSM copyright page требует credit OpenStreetMap и contributors и указывает ODbL. Успешный ответ не доказывает, что конкретная схема storage, cache, redistribution или SaaS разрешена.

## Решение и review gate

Эта запись подтверждает ограниченные наблюдения отдельных public geocoding requests, JSON/GeocodeJSON response format, empty-result behavior для unknown query и attribution/licence signal. Она не подтверждает storage, caching, redistribution, SLA, accuracy, production suitability или quota threshold. Autocomplete и bulk use остаются запрещёнными на public instance.

`maturity` остаётся `reviewed`. `live_tested_on` и `live_test_valid_until` намеренно пока не устанавливаются: они могут быть добавлены только после human review evidence и paired review file. Automatic promotion запрещена.

См. [paired review](../../reviews/nominatim-geocoder-software-live-test-2026-08-24.ru.md).

## Воспроизведение

Повторять только три формы отдельных запросов с тем же идентифицирующим User-Agent/Referer и паузой не менее двух секунд. Не добавлять autocomplete, batch, bulk, regular polling или load. Не отправлять персональные/конфиденциальные данные. Сохранять attribution и licence signals и не выводить права на storage или redistribution из HTTP success.
