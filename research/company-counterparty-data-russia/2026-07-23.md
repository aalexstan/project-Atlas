# Research Log — 2026-07-23

## Objective

Create the first Atlas task-oriented comparison for Russian company and counterparty data APIs.

## Candidates

- DaData;
- Kontur.Focus API;
- Seldon.Basis API;
- official FTS EGRUL/EGRIP integration.

## Key Methodological Decision

The candidates are not treated as interchangeable products. The research separates data autocomplete, due diligence, and primary-registry ingestion.

## Important Findings

1. DaData has the clearest self-service entry and public pricing.
2. Kontur.Focus publicly exposes a broad enterprise feature set, but a comparable final API price requires configuration and a quote.
3. Seldon.Basis publishes broad functionality and a 10,000-requests/day-per-method reference for its individual API plan, but not exact method prices.
4. FTS integration is a bulk XML feed with daily deltas, not a normal request/response API.
5. The FTS format migration scheduled for 2026-08-01 makes an early August recheck mandatory.
6. A fair commercial comparison requires vendor pilots on the same company sample.

## Unresolved

- Kontur authentication, rate limits, and exact method bundles under a current contract.
- Seldon authentication, SLA, storage rights, and exact method prices.
- Comparable monthly cost at defined workloads.
- Measured data completeness and latency.

## Next Work

Create lightweight independent profiles for Kontur.Focus API, Seldon.Basis API, and FTS EGRUL/EGRIP integration, then run a common benchmark when credentials become available.
