# MoySklad JSON API Research Log

[Русская версия](2026-08-23.ru.md)

## Scope

Assess whether MoySklad JSON API is a useful API-first profile for building integrations and reusable business applications rather than only a narrow data connector.

## Official sources reviewed

- [Developer portal](https://dev.moysklad.ru/)
- [JSON API 1.2](https://dev.moysklad.ru/doc/api/remap/1.2/)
- [Vendor API 1.0](https://dev.moysklad.ru/doc/api/vendor/1.0/)

## Confirmed facts

- The official developer portal positions JSON API for external integrations and business automation.
- JSON API 1.2 supports Basic Auth and access-token authentication.
- Official materials state that API access is free, available across plans and subject to restrictions on some plans.
- The API works with many entities exposed by the service, including products, stock, documents and counterparties.
- Vendor API and server-solution documentation supports an application model for solutions intended for MoySklad users.

## Provider-reported claims

The coverage, free-access statement and application-platform model are claims published by MoySklad. Atlas has not independently tested endpoint completeness, plan enforcement or production performance.

## Unknowns and blockers

- Exact endpoint and plan-specific rate limits.
- Current review, publication, billing and support terms for public Vendor solutions.
- Storage, caching, customer-data, SaaS and redistribution rights.
- Long-term versioning and deprecation policy for the intended integration.

## Decision

Create an active `verified` profile for the documented core API contract. This is a strong candidate for Atlas because it can support a reusable integration layer around inventory, orders and documents. Commercial and operational details remain scenario-dependent.

## Live testing

Not performed. No developer account, credentials or customer data were used.
