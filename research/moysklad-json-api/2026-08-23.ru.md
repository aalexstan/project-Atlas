# Исследовательский журнал MoySklad JSON API

[English version](2026-08-23.md)

## Объём

Проверить, является ли MoySklad JSON API полезным API-first профилем для интеграций и повторно используемых бизнес-приложений, а не только узким коннектором данных.

## Проверенные официальные источники

- [Портал разработчиков](https://dev.moysklad.ru/)
- [JSON API 1.2](https://dev.moysklad.ru/doc/api/remap/1.2/)
- [Vendor API 1.0](https://dev.moysklad.ru/doc/api/vendor/1.0/)

## Подтверждённые факты

- Официальный портал разработчиков предназначает JSON API для внешних интеграций и автоматизации бизнеса.
- JSON API 1.2 поддерживает Basic Auth и аутентификацию access token.
- В официальных материалах указано, что доступ к API бесплатен, доступен на тарифах и имеет ограничения на некоторых тарифах.
- API работает со многими сущностями сервиса, включая товары, остатки, документы и контрагентов.
- Документация Vendor API и серверных решений описывает модель приложений для пользователей «МоегоСклада».

## Утверждения поставщика

Охват, заявление о бесплатном доступе и модель платформы приложений опубликованы самим «МоимСкладом». Atlas самостоятельно не проверял полноту endpoint, применение тарифных ограничений и production-производительность.

## Неизвестные параметры и блокеры

- Точные лимиты endpoint и тарифов.
- Актуальные правила проверки, публикации, биллинга и поддержки публичных Vendor-решений.
- Права хранения, кэширования, использования клиентских данных, SaaS и перераспределения.
- Долгосрочная политика версионирования и deprecation для выбранной интеграции.

## Решение

Создать активный профиль уровня `verified` для документированного базового API-контракта. Это сильный кандидат для Atlas, потому что на нём можно строить повторно используемый слой интеграции остатков, заказов и документов. Коммерческие и эксплуатационные детали зависят от сценария.

## Live testing

Не проводился. Аккаунт разработчика, credentials и клиентские данные не использовались.
