# Исследование API CloudPayments

[English version](2026-08-22-cloudpayments.md)

## Область проверки

Проверка официального API CloudPayments для онлайн-приёма платежей, возвратов, двухстадийных операций, подписок, чеков и уведомлений.

## Проверенные официальные источники

- https://developers.cloudpayments.ru/
- https://cloudpayments.ru/info/documents
- https://cloudpayments.ru/help/payments
- https://cloudpayments.ru/help/payments/bills

## Подтверждённые факты

- CloudPayments документирует API по адресу `https://api.cloudpayments.ru`.
- Официальная документация описывает одно- и двухстадийные платежи, возвраты, отмены, рекуррентные подписки, счета и уведомления.
- Аутентификация использует HTTP Basic Auth с Public ID и API Secret из личного кабинета.
- Запросы могут передаваться в JSON или form encoding, ответы имеют JSON-формат.
- Документация описывает тестовый метод `/test` и механизм идентификатора запроса `X-Request-ID`.
- В официальных материалах отдельно описаны интернет-эквайринг, виджет, мобильные SDK, чеки и выплаты по API.

## Заявления поставщика

- CloudPayments заявляет, что checkout помогает не передавать реквизиты карты на сервер продавца, и ссылается на защиту PCI DSS на своей стороне.
- Поставщик перечисляет карты, СБП, T-Pay, SberPay, Mir Pay, рассрочки, подписки и платёжные ссылки; точная доступность зависит от подключения.

## Неизвестные параметры и блокеры

- Публичная API-специфичная комиссия, минимальные обязательства, overage, сроки зачисления и SLA.
- Production rate limits сверх описанной параллельности тестовых терминалов.
- Точные права хранения платёжных данных, показа клиентам, SaaS-встраивания и redistribution.
- Политика версионирования и deprecation для всех методов.
