# Исследование API ЮKassa

[English version](2026-08-22-yookassa.md)

## Область проверки

Проверка официального API ЮKassa для приёма онлайн-платежей, возвратов, чеков, рекуррентных платежей, webhooks и отдельных выплат в России.

## Подтверждённые факты

- ЮKassa документирует API для онлайн-платежей и выплат.
- В документации указан endpoint `https://api.yookassa.ru/v3/`.
- Документация описывает аутентификацию, ключи идемпотентности, JSON, webhooks, возвраты, чеки и OpenAPI YAML.
- В документации приёма платежей перечислены карты, Mir Pay, SberPay, Alfa Pay, T-Pay, СБП и другие способы; доступность зависит от решения и договора.
- ЮKassa документирует ежедневные реестры платежей и возвратов для сверки.
- Для выплат требуется отдельное подключение и схема ЮKassa/ЮBusiness согласно официальной документации.

## Заявления поставщика

- ЮKassa называет это единым API для платежей, чеков, возвратов и других операций.
- В публичной документации указано отсутствие абонентской платы и комиссия с успешных платежей; точные условия определяются договором.

## Неизвестные параметры и блокеры

- Точная комиссия, минимумы, overage, сроки зачисления и SLA для конкретного клиента.
- Производственные rate limits и квоты по каждому платёжному решению.
- Права хранения, кэширования, SaaS-встраивания, redistribution и показа клиентам.
- Доступность всех способов оплаты для конкретного бизнеса и категории деятельности.
