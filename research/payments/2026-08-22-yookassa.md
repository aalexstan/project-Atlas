# YooKassa API Research Log

[Русская версия](2026-08-22-yookassa.ru.md)

## Scope

Review the official YooKassa API as a route for accepting online payments, refunds, receipts, recurring payments, webhooks, and selected payouts in Russia.

## Confirmed facts

- YooKassa documents an API for online payments and payouts.
- The documented API endpoint is `https://api.yookassa.ru/v3/`.
- The API documentation describes request authentication, idempotency keys, JSON interaction, webhooks, refunds, receipts, and an OpenAPI YAML specification.
- The payment acceptance documentation lists cards, Mir Pay, SberPay, Alfa Pay, T-Pay, SBP, and other payment methods; availability depends on the payment solution and contract.
- YooKassa documents daily payment and refund registers for reconciliation.
- The payout route requires separate onboarding and a YooKassa/UBusiness arrangement according to the official payout documentation.

## Provider-reported claims

- YooKassa describes its API as a unified API for payments, receipts, refunds, and other operations.
- Public documentation states there is no subscription fee and that successful-payment commission is charged; the exact conditions are contract-specific.

## Unknowns and blockers

- Exact merchant-specific commission, minimums, overage, settlement terms, and SLA.
- Production rate limits and quotas for each API solution.
- Storage, caching, SaaS embedding, redistribution, and customer-facing display rights for each use case.
- Availability of all payment methods for a particular legal entity and business category.

Not performed. No credentials or test evidence are stored in this repository.

## Decision

Create an active reviewed profile. The official documentation is sufficiently detailed for a scenario profile, while commercial and production-operational terms remain open.
