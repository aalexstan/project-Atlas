# Исследование API интернет-эквайринга Т‑Банка

[English version](2026-08-22-tbank.md)

## Область проверки

Проверка официального API интернет-эквайринга Т‑Банка и его границы относительно более широкой платформы T‑API.

- https://developer.tbank.ru/docs/api

## Подтверждённые факты

- В developer portal Т‑Банка есть отдельный раздел интернет-эквайринга и материалы, связанные с OpenAPI.
- Официальная бизнес-документация описывает интеграцию по API с сайтами, приложениями, CRM и ИТ-системами.
- Для интернет-эквайринга описаны платежи, подтверждение/холдирование, отмена, возврат и рекуррентные платежи.
- Webhooks документированы для статуса платежа и других событий T‑API; подключение webhook требует действий со стороны поставщика.
- Т‑Банк указывает отсутствие абонентской платы и индивидуальный расчёт комиссии; на официальной странице также указана фиксированная комиссия за неуспешную авторизацию.
- Для подключения требуется зарегистрированный бизнес и заявка на интернет-эквайринг.

## Заявления поставщика

- В материалах интернет-эквайринга перечислены карты, T-Pay, SberPay, Alfa Pay, Mir Pay, СБП, платёжные ссылки и другие способы.
- Сроки зачисления и операционные условия описываются в справочных материалах; конкретные условия зависят от настроек и договора.

## Неизвестные параметры и блокеры

- Индивидуальная таблица комиссий, минимальные платежи, сроки зачисления, production quotas и SLA.
- Точный публичный base URL и method-level контракт выбранной интеграции эквайринга.
- Права хранения, кэширования, показа клиентам, SaaS, redistribution и трансграничного использования.
- Одинакова ли модель подключения для всех возможностей T‑API, перечисленных в портале.

## Live testing

Не проводился. Credentials и тестовые доказательства не хранятся.

## Решение

Создать активный профиль именно интернет-эквайринга Т‑Банка, не смешивая его с остальными банковскими операциями T‑API.
