# Исследование OpenWeather

[English version](2026-08-22-openweather.md)

## Область проверки

Проверка current/forecast API OpenWeather и pay-as-you-call маршрута One Call 4.0.

## Подтверждённые факты

- OpenWeather документирует current, forecast, historical, environmental и связанные API.
- Официальные тарифы разделяют self-service subscriptions и One Call 4.0 pay-as-you-call.
- One Call 4.0 имеет дневной бесплатный allowance и плату за дополнительные вызовы по условиям продукта.
- Документированы API keys и REST-доступ по lat/lon.
- Официальные licensing materials различают планы и права использования.

## Неизвестные параметры

- Точная цена выбранного продукта, rate limits, SLA, storage, redistribution и customer-facing display rights.
- Accuracy и пригодность источников для регионов России и historical use.
